# Third-party sources and notices

This inventory identifies bundled or adapted material. Its upstream notices apply to the corresponding portions, including when Lean excerpts appear in the reader. A license for original HRS material does not replace them.

## Vendored Lean modules

The [DGRHS provenance note](lean/external/dgrhs/PROVENANCE.md) identifies the two snapshots supplying 244 vendored modules. The following attributions concern particular files within that collection.

- **StatLean/Stat-Lean, copyright 2024 Junwei Lu.** Four files in [Gaussian/Imported](lean/external/dgrhs/DGRHS/Gaussian/Imported/) adapt the Gaussian L² closure, Gaussian moments, square moment-generating function and isonormal process. The headers of `SixthMoment.lean`, `ScalarTiltedLaplace.lean`, `IndexedGaussianLaw.lean` and `IndexedGaussianTuple.lean` also identify adaptations. [BasisCountability.lean](lean/external/dgrhs/DGRHS/Kernel/Imported/BasisCountability.lean) adapts the countability argument from the same isonormal source. The file headers describe the changes. The [pinned upstream notice](https://github.com/StatLean/Stat-Lean/blob/86b3823f77fc2b0f5a9923f85b588a4f8a65f94c/LICENSE) is reproduced without alteration in [Gaussian/Imported/LICENSE](lean/external/dgrhs/DGRHS/Gaussian/Imported/LICENSE) and [BasisCountability.LICENSE](lean/external/dgrhs/DGRHS/Kernel/Imported/BasisCountability.LICENSE). Its heading names Apache License, Version 2.0, but its text differs from the standard version, including in sections 1, 4 and 9. Consult the supplied text for those portions.
- **Adam Benenson, copyright 2026.** [SpectralBasis.lean](lean/external/dgrhs/DGRHS/Kernel/Imported/SpectralBasis.lean) adapts Hilbert-basis assembly from [compact-spectral](https://github.com/abenenson/compact-spectral/blob/72cd62dbdd4c397d26fc0c5777d60fea2211e938/CompactSpectral/Analysis/InnerProductSpace/CompactSelfAdjoint/SpectralTheorem.lean), using mathlib's compact spectral completeness theorem. [Upstream Apache License, Version 2.0](lean/external/dgrhs/DGRHS/Kernel/Imported/SpectralBasis.LICENSE).
- **FujiHaruka, copyright 2026.** [KernelOperator.lean](lean/external/dgrhs/DGRHS/Kernel/Imported/KernelOperator.lean) adapts the row operator and compactness argument from [information-theory](https://github.com/FujiHaruka/information-theory/blob/95a7a76f9b45e8e58251a442c8e9b60eed48a2dd/InformationTheory/Shannon/TimeBandLimiting/Operator.lean), lines 751–1255. The local version uses a general measurable domain and a finite-measure argument in place of box exhaustion. [Upstream Apache License, Version 2.0](third-party/lean/FujiHaruka-information-theory-LICENSE.txt).
- **The mathlib community.** The package imports [mathlib at its pinned revision](https://github.com/leanprover-community/mathlib4/tree/d13f23b723b8a846827a245b89c10fc7d3f11612). For example, [RieszGaussianNormalization.lean](lean/external/dgrhs/DGRHS/Gaussian/RieszGaussianNormalization.lean) credits mathlib's Gaussian integral proof for its square substitution. The full mathlib checkout is not bundled here. [Upstream Apache License, Version 2.0](third-party/lean/mathlib-LICENSE.txt).
