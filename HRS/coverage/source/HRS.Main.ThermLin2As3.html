23/-- The Gaussian comparison `Y` versus the stationary field `Z_β` (TeX L6969-7011): for the prepared linear process
24`Y` with initial law `ν` on the horizon `a + T` and the stationary Gaussian field `Z`,
25`W_1^{𝒳_{m,T}}(law Y^{a+·}, law Z^{0+·}) ≤ C e^{-ca}(1 + ‖ν‖_{L¹(E_m)})` and
26`W_2^{𝒳_{m,T}}(law Y^{a+·}, law Z^{0+·}) ≤ C e^{-ca}(1 + ‖ν‖_{L²(E_m)})`, with `C, c` independent of `a ≥ 0`, `ν`, `Y`, `Z`. -/
27theorem thermlin_gaussian_comparison_proof (S : PreparedData d) (m : ℝ) (hm : (d : ℝ) + 2 < m) (T : ℝ)
28    (hT : 0 < T) (ρβ : Torus d → ℝ) (hρβ : IsThermalDensity (periodicRiesz d S.s) S.V S.β ρβ) :
29    ∃ C c : ℝ, 0 < C ∧ 0 < c ∧
30      ∀ a : ℝ, 0 ≤ a → ∀ (ν : Measure (NegSobolev d m)) [IsProbabilityMeasure ν]
31        {Ω' : Type} [MeasurableSpace Ω'] (P' : Measure Ω') [IsProbabilityMeasure P']
32        (Y₀ : Ω' → NegSobolev d m) (Y : ℝ → Ω' → NegSobolev d m),
33        IsPreparedLinear S m (a + T) ν P' Y₀ Y →
34      ∀ {Ω'' : Type} [MeasurableSpace Ω''] (P'' : Measure Ω'') [IsProbabilityMeasure P'']
35        (Z : ℝ → Ω'' → NegSobolev d m),
36        IsStationaryGaussianField P'' S.s S.β S.hs0 S.hsd S.hβ S.V ρβ m Z →
37        wassersteinE 1 (law P' (windowPath m T a Y)) (law P'' (windowPath m T 0 Z)) ≤
38          ENNReal.ofReal (C * Real.exp (-c * a)) * (1 + ∫⁻ y, ‖y‖ₑ ∂ν) ∧
39        wassersteinE 2 (law P' (windowPath m T a Y)) (law P'' (windowPath m T 0 Z)) ≤
40          ENNReal.ofReal (C * Real.exp (-c * a)) *
