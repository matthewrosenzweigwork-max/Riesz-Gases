11## Representation decisions
12* Standing regime: `HRS.Sec7.Regime` (see `Sec7Setting.lean`).  The order of `E_r` is fixed to `r = 2d + 6`
13  (hypothesis `hr`), the value used in the proofs (TeX L8504, L9171, L8663); the TeX statements leave `r`
14  implicit.  SUSPECTED ISSUE: the subsection `sec:quadratic-fields` (TeX L8079) begins in the middle of a
15  sentence ("gives the following uniform bounds on our fixed time interval", L8080), so its standing
16  assumptions (the value of `r`, the horizon `T`, the preparation) are not stated in the source text.
17* The quadratic field of the particle system `ℬ_N^t(φ) = N F_N^{h_{∇φ}}(X_N^t, μ^t) - E[·]` is `quadFieldAt`,
18  with `φ` ranging over the real trigonometric basis (`ℬ̃_N^t(e_k) = N F_N^{h_{∇e_k}}`, `F:eq:Bdef`, TeX L8137-8140).
19* Convergence in law is stated twice: against bounded continuous functions (weak convergence) and in
20  `wassersteinE q` (`q ∈ [1,∞)`, values in `ℝ≥0∞`), on the product `C([0,T];E_r) × L²([0,T];E_r)` with the
21  product (max) norm; the TeX does not specify the product metric.
22* The limit objects: for *every* Gaussian solution `η` (`IsGaussianLimitField`) there is a field `ℬ` on the same
23  probability space with `ℬ^t(e_k) = ½ I_2^{𝒞_t}(h_{∇e_k})` (`IsWickQuadraticField`, centred under `μ^t`) for a.e.
24  `t`, and the stated convergence holds.  Uniqueness of `ℬ` (a.s.) is part of the Wick construction.

179/-- The covariance `2q ∫_0^{t_a∧t_b} ∫ √(ρ^v ρ'^v) ∇U^{v,t_a}φ·∇Ū^{v,t_b}ψ dx dv` of the noise parts of two linear
180evolutions (mean-field densities `ρ`, `ρ'`) driven by the *same* cylindrical white noise
181(`H:eq:linear-mild`, TeX L497-500; for `ρ = ρ'` this is `HRS.noiseCovariance`'s cross-covariance). -/
182def crossNoiseCov (D : DynData d) (q : ℝ) (ρ ρ' : ℝ → Torus d → ℝ) (ta tb : ℝ) (φ ψ : Torus d → ℝ) : ℝ :=
183  2 * q * ∫ v in Set.Icc (0 : ℝ) (min ta tb), ∫ x,
184    inner ℝ (Torus.grad (propagator D ρ v ta φ) x) (Torus.grad (propagator D ρ' v tb ψ) x) *
185      Real.sqrt (ρ v x * ρ' v x)

187/-- `(Y, Ys)` (initial fields `Y₀`, `Ys₀`, with mean-field densities `ρ`, `ρ'`) are coupled by the same noise on
188`[0,∞)`, the initial fields being independent of the noise: for finitely many smooth tests at nonnegative times the
189joint vector of noise parts is centred Gaussian with the cross-covariance `crossNoiseCov` and independent of
190`(Y₀,Ys₀)`.  (TeX L9124-9128: "Couple `η` and `ηs` by the same noise on `[0,∞)`".) -/
191def IsSameNoise (D : DynData d) (ρ ρ' : ℝ → Torus d → ℝ) (r : ℝ) {Ω : Type} [MeasurableSpace Ω]
192    (P : Measure Ω) (Y₀ Ys₀ : Ω → NegSobolev d r) (Y Ys : ℝ → Ω → NegSobolev d r) : Prop :=
193  ∀ (p p' : ℕ) (ts : Fin p → ℝ) (φ : Fin p → Torus d → ℝ) (ts' : Fin p' → ℝ) (ψ : Fin p' → Torus d → ℝ),
194    (∀ a, 0 ≤ ts a) → (∀ b, 0 ≤ ts' b) → (∀ a, Torus.IsSmooth (φ a)) → (∀ b, Torus.IsSmooth (ψ b)) →
195    let G : Ω → EuclideanSpace ℝ (Fin p ⊕ Fin p') := fun ω => WithLp.toLp 2 (Sum.elim
196      (fun a => noisePart D ρ Y₀ Y (ts a) (φ a) ω) (fun b => noisePart D ρ' Ys₀ Ys (ts' b) (ψ b) ω))
197    IndepFun (fun ω => (Y₀ ω, Ys₀ ω)) G P ∧
198    law P G = multivariateGaussian 0 (Matrix.of fun i j => match i, j with
199      | Sum.inl a, Sum.inl b => crossNoiseCov D D.invβ ρ ρ (ts a) (ts b) (φ a) (φ b)
200      | Sum.inl a, Sum.inr b => crossNoiseCov D D.invβ ρ ρ' (ts a) (ts' b) (φ a) (ψ b)
201      | Sum.inr a, Sum.inl b => crossNoiseCov D D.invβ ρ' ρ (ts' a) (ts b) (ψ a) (φ b)
202      | Sum.inr a, Sum.inr b => crossNoiseCov D D.invβ ρ' ρ' (ts' a) (ts' b) (ψ a) (ψ b))

240partition `0 = u_0 < ⋯ < u_n = T` with tags `τ_i ∈ [u_i,u_{i+1}]` and mesh `< δ` satisfies
241`|∑_i S(τ_i, u_i, u_{i+1}) - I| < ε`.  Here `S(τ, a, b)` stands for "integrand at the tag `τ` applied to the
242measure of the interval `(a,b]`" (`F:sec:measures`, TeX L8699-8705: "integration ... is defined by
243Riemann--Stieltjes sums"). -/
244def IsRS (T : ℝ) (S : ℝ → ℝ → ℝ → ℝ) (I : ℝ) : Prop :=
245  ∀ ε : ℝ, 0 < ε → ∃ δ : ℝ, 0 < δ ∧ ∀ (n : ℕ) (u : Fin (n + 1) → ℝ) (τ : Fin n → ℝ), StrictMono u →
246    u 0 = 0 → u (Fin.last n) = T → (∀ i : Fin n, u i.castSucc ≤ τ i ∧ τ i ≤ u i.succ) →
247    (∀ i : Fin n, u i.succ - u i.castSucc < δ) →
248    |∑ i : Fin n, S (τ i) (u i.castSucc) (u i.succ) - I| < ε
