20* The standing coefficient hypothesis `B:eq:coeff-hypothesis-rd` is `AdjointRdData` (+ the regime `RdRegimeHolds`
21  for `B:thm:adjoint-rd`, `AdjointLpRegime` for `B:thm:adjoint-lp`); the constants are chosen before the data

24* "`F` solves `B:eq:adjoint-forward` in the distributional sense with `F(0) = φ`" is `IsForwardSolutionRd`: the weak
25  (integrated in time) form against `C_c^∞` tests `ψ`, `d/dτ∫Fψ = ν∫FΔψ - ∫F div(b^τψ) - ∫𝒢^τ[F]ψ`, with
26  `𝒢^τ[F] = ∑_{ij} M^*_{ij} ∂_i g*(μ^{t-τ} ∂_jF)` and the nonlocal term moved onto the test function
27  (`∫ 𝒢[F]ψ = +∑ M^*_{ij} ∫ F ∂_j(μ ∂_i(g*ψ))`, `g*ψ ∈ C^∞`; no derivative of `F` is needed).  Integrability of every
28  term is part of the solution concept.
29* `F(τ)` are functions defined a.e.; "unique" is a.e. equality for every `τ`.  `L^∞([0,t]; H^m_uloc)` is the bound for
30  every `τ`; `C([0,t]; H^{m'}_loc)` is continuity of `τ ↦ χ(·-z)F(τ)` in `H^{m'}` for each `z` (real `m' < m`);
31  `C_w([0,t]; H^m)` is continuity of `τ ↦ ⟨F(τ), h⟩_{H^m}` for every `h ∈ H^m`.
32* `W^{m,p}(ℝ^d)` is `WmpSpace` of `HRS/Whole/AppendixA.lean` (closure of the jets of `C_c^∞` in `L^p`); "`u ∈ W^{m,p}`
33  with norm `‖u‖`" is `wNormE` (`⊤` if `u` is not the zeroth component of an element of `WmpSpace`).
34  `C([0,t]; W^{m',p}_loc)` is for integers `0 ≤ m' < m`.
35* SUSPECTED ISSUE (S.A.12(a), S.A.13, S L10098-10100, L10111-10113): a classical adjoint solution on `ℝ^d` is required to have
36  *bounded* `∂_r f` (`f, ∇f, ∇²f, ∂_rf` bounded and continuous).  For a confining drift `-Qx` (`Q ≠ 0`; `V = |x|²/2`) this

40  `docs/ISSUES.md` §I.

54/-- The nonlocal part of the weak form: `∑_{i,j} M^*_{ij} ∂_j(μ^{τ'} ∂_i(g*ψ))` (`M^*_{ij} = M_{ji}`), the function
55by which `F` is integrated in `∫ 𝒢[F]ψ = +∫ F · nonlocalTestRd` (`∫ ∂_ig*(μ∂_jF) ψ = -∫ μ ∂_jF ∂_i(g*ψ)` since `∂_ig` is
56odd, then integrate by parts in `∂_j`); so `forwardWeakTerm` carries `-∫ F · nonlocalTestRd`. -/
57def nonlocalTestRd (C : WholeCoeff d) (τ' : ℝ) (ψ : Euc d → ℝ) (x : Euc d) : ℝ :=
58  ∑ i : Fin d, ∑ j : Fin d, C.M j i *
59    partialDeriv (fun _ : Fin 1 => j)
60      (fun y => C.ρ τ' y * gradient (convFun (rieszKernel d C.s) ψ) y i) x
61
62/-- The time-`σ` integrand of the weak form of `∂_σF = νΔF + b^σ·∇F - 𝒢^σ[F]` against `ψ`, coefficients at time `t - σ`:
63`ν∫FΔψ - ∫F div(b ψ) - ∫F·nonlocalTestRd`, `b = C.drift (t-σ)`. -/
64def forwardWeakTerm (C : WholeCoeff d) (t : ℝ) (F : ℝ → Euc d → ℝ) (ψ : Euc d → ℝ) (σ : ℝ) : ℝ :=
65  C.ν * (∫ x, F σ x * Laplacian.laplacian ψ x) -
66    (∫ x, F σ x * movDiv (fun y => ψ y • C.drift (t - σ) y) x) -
67    ∫ x, F σ x * nonlocalTestRd C (t - σ) ψ x
68
69/-- `F` solves the forward adjoint equation `B:eq:adjoint-forward` (`∂_τF = νΔF + b^τ·∇F - 𝒢^τ[F]`,
70`b^τ = M∇g*μ^{t-τ} - ∇V`, `𝒢^τ[F] = Div g*(μ^{t-τ}M^*∇F)`) on `[0,t]` in the distributional sense with `F(0) = φ`, in the
71integrated weak form against `ψ ∈ C_c^∞(ℝ^d)` (see the module docstring); every pairing is absolutely convergent and the
72time integrand is integrable. -/
73structure IsForwardSolutionRd (C : WholeCoeff d) (t : ℝ) (φ : Euc d → ℝ) (F : ℝ → Euc d → ℝ) : Prop where
74  integrable_x : ∀ ψ : Euc d → ℝ, IsCcInfty ψ → ∀ σ ∈ Set.Icc (0 : ℝ) t,
75    Integrable (fun x => F σ x * ψ x) ∧ Integrable (fun x => F σ x * Laplacian.laplacian ψ x) ∧
76    Integrable (fun x => F σ x * movDiv (fun y => ψ y • C.drift (t - σ) y) x) ∧
77    Integrable (fun x => F σ x * nonlocalTestRd C (t - σ) ψ x)
78  integrable_σ : ∀ ψ : Euc d → ℝ, IsCcInfty ψ →
79    IntegrableOn (fun σ => forwardWeakTerm C t F ψ σ) (Set.Icc (0 : ℝ) t)
80  eq : ∀ ψ : Euc d → ℝ, IsCcInfty ψ → ∀ τ ∈ Set.Icc (0 : ℝ) t,
81    ∫ x, F τ x * ψ x = (∫ x, φ x * ψ x) + ∫ σ in Set.Icc (0 : ℝ) τ, forwardWeakTerm C t F ψ σ

83/-- The solution class of `B:thm:adjoint-rd`: `F ∈ L^∞([0,t]; H^m_uloc) ∩ C([0,t]; H^{m'}_loc)`, `m' < m`, solving
84`B:eq:adjoint-forward` (`IsForwardSolutionRd`).  `L^∞H^m_uloc`: `‖F(τ)‖_{H^m_uloc} ≤ B` for all `τ ∈ [0,t]`;
85`C([0,t];H^{m'}_loc)`: for every `z` the map `τ ↦ χ(·-z)F(τ)` is continuous into `H^{m'}(ℝ^d)`. -/

87    (F : ℝ → Euc d → ℝ) : Prop where
88  sol : IsForwardSolutionRd C t φ F
89  bounded : ∃ B : ℝ, ∀ τ ∈ Set.Icc (0 : ℝ) t, ulocNormE m χ (F τ) ≤ ENNReal.ofReal B
90  cont : ∀ m' : ℝ, m' < m → ∀ z : Euc d, ∀ τ₀ ∈ Set.Icc (0 : ℝ) t, ∀ ε : ℝ, 0 < ε →
91    ∃ δ : ℝ, 0 < δ ∧ ∀ τ ∈ Set.Icc (0 : ℝ) t, |τ - τ₀| < δ →
92      sobolevNormE m' (fun x => χ (x - z) * (F τ x - F τ₀ x)) ≤ ENNReal.ofReal ε
