28## Representation decisions
29
30* The thermal equilibrium measure is `thermalMeasure d s a β` of `Basic.lean`
31  (`IsThermalEquilibrium`, which covers `s = 0` with `rieszKernel d 0 = -log|x|`).
32* "Invariant probability measure of the diffusion with generator `Δ + b·∇`" (S4.2) is the
33  infinitesimal invariance `∫ (Δφ + b·∇φ) dμ = 0` for `φ ∈ C_c^∞` (`IsInvariantMeasure`);
34  for a globally Lipschitz drift this is equivalent to invariance under the (nonexplosive)
35  diffusion semigroup.
36* `C_b^J` membership is `HRS.MemCb J` (`C^J` with bounded derivatives), so `HRS.cbNorm J` is
37  the honest sum of suprema.  `H^J(dx)` tests are smooth functions with square-integrable
38  derivatives through order `J` and norm `sobolevWNorm J 2` (smooth representatives).
39* `ℓ²`-valued feature vectors live in `SeqL2 = lp (fun _ : ℕ => ℝ) 2`; the Gaussian `Z` is any
40  centered Gaussian law on `SeqL2` with the prescribed coordinate covariances
41  (`IsCenteredGaussianSeq`), its existence being a separate claim.  The metric
42  `d_{C_b²(ℓ²)}` is the project's `HRS.smoothDist 2` (sum norm `‖F‖_∞+‖DF‖_∞+‖D²F‖_∞ ≤ 1`,
43  S line 2533).
44* Sums of suprema `∑_j ‖D^jχ‖_∞ ≤ C` are written as `∀ x : Fin _ → ℝ^d, ∑_j ‖D^jχ(x_j)‖ ≤ C`.

126/-- `μ` is an invariant probability measure of the diffusion with generator `Δ + b·∇`:
127`∫ (Δφ + b·∇φ) dμ = 0` for every `φ ∈ C_c^∞` (infinitesimal invariance; S lines 2196-2197). -/
128def IsInvariantMeasure (b : Euc d → Euc d) (μ : Measure (Euc d)) : Prop :=
129  IsProbabilityMeasure μ ∧ ∀ φ : Euc d → ℝ, ContDiff ℝ ∞ φ → HasCompactSupport φ →
130    ∫ x, Laplacian.laplacian φ x + inner ℝ (b x) (gradient φ x) ∂μ = 0
131
132/-- The Poisson operator `(-Δ - b·∇)χ`. -/
133def poissonOp (b : Euc d → Euc d) (χ : Euc d → ℝ) (x : Euc d) : ℝ :=
134  -Laplacian.laplacian χ x - inner ℝ (b x) (gradient χ x)
135
136/-- `B ∈ C_b^m(ℝ^d;ℝ^d)` with all derivatives of order `≤ m` bounded by `Mb`. -/
137def HasCbBound (m : ℕ) (Mb : ℝ) (B : Euc d → Euc d) : Prop :=
138  ContDiff ℝ m B ∧ ∀ j ≤ m, ∀ x, ‖iteratedFDeriv ℝ j B x‖ ≤ Mb
139
140/-- The conclusions `W:eq:r2-affine-Poisson-bound` (S lines 2199-2207) for a solution `χ`:
141centered, `C²`, solving `(-Δ - b·∇)χ = r`, with `|χ(x)| ≤ C‖r‖_{C_b²}(1+log(2+|x|))` and
142`‖∇χ‖_∞ + ‖D²χ‖_∞ ≤ C‖r‖_{C_b²}`. -/
143def IsPoissonSolution (b : Euc d → Euc d) (μ : Measure (Euc d)) (r : Euc d → ℝ) (C : ℝ)
144    (χ : Euc d → ℝ) : Prop :=
145  ContDiff ℝ 2 χ ∧ Integrable χ μ ∧ ∫ x, χ x ∂μ = 0 ∧ (∀ x, poissonOp b χ x = r x) ∧
146    (∀ x, |χ x| ≤ C * cbNorm 2 r * (1 + Real.log (2 + ‖x‖))) ∧
147    ∀ x y, ‖gradient χ x‖ + ‖iteratedFDeriv ℝ 2 χ y‖ ≤ C * cbNorm 2 r
148
149/-- Lemma S4.2 `W:lem:r2-affine-Poisson` (S lines 2194-2211): `q > 0`, `b(x) = -qx + B(x)`
150with `B ∈ C_b²`, `μ` an invariant probability measure of `Δ + b·∇` with finite second
151moment; for `r ∈ C_b²` with `μ(r) = 0` there is a centered solution of `(-Δ-b·∇)χ = r`
152with the bounds `W:eq:r2-affine-Poisson-bound`.  The constant depends on `q`, the bound `Mb`
153for `B`, and the second moment bound `m₂` of `μ`, on no support radius and on no lower bound
154for the density of `μ` (so `C` is quantified before `B, μ, r`). -/
155theorem affine_poisson (hd : 1 ≤ d) (q Mb m₂ : ℝ) (hq : 0 < q) :
156    ∃ C : ℝ, ∀ B : Euc d → Euc d, HasCbBound 2 Mb B → ∀ μ : Measure (Euc d),
157      IsInvariantMeasure (fun x => -q • x + B x) μ → Integrable (fun x => ‖x‖ ^ 2) μ →
158      ∫ x, ‖x‖ ^ 2 ∂μ ≤ m₂ → ∀ r : Euc d → ℝ, MemCb 2 r → Integrable r μ → ∫ x, r x ∂μ = 0 →
159        ∃ χ : Euc d → ℝ, IsPoissonSolution (fun x => -q • x + B x) μ r C χ := by
160  sorry

162/-- Corollary S4.3 `W:cor:r2-higher-Poisson` (S lines 2327-2334): under the assumptions of
163S4.2, if moreover `B ∈ C_b^m` and `r ∈ C_b^m` for an integer `m ≥ 2`, the same solution
164satisfies `∑_{j=1}^m ‖D^jχ‖_∞ ≤ C_m ‖r‖_{C_b^m}` (`W:eq:r2-higher-Poisson`): there is one
165centered solution with both the S4.2 bounds and the higher bounds. -/
166theorem affine_poisson_higher (hd : 1 ≤ d) (q Mb m₂ : ℝ) (hq : 0 < q) (m : ℕ) (hm : 2 ≤ m) :
167    ∃ C Cm : ℝ, ∀ B : Euc d → Euc d, HasCbBound m Mb B → ∀ μ : Measure (Euc d),
168      IsInvariantMeasure (fun x => -q • x + B x) μ → Integrable (fun x => ‖x‖ ^ 2) μ →
169      ∫ x, ‖x‖ ^ 2 ∂μ ≤ m₂ → ∀ r : Euc d → ℝ, MemCb m r → Integrable r μ → ∫ x, r x ∂μ = 0 →
170        ∃ χ : Euc d → ℝ, IsPoissonSolution (fun x => -q • x + B x) μ r C χ ∧
171          ContDiff ℝ m χ ∧
172          ∀ x : Fin m → Euc d, ∑ j : Fin m, ‖iteratedFDeriv ℝ ((j : ℕ) + 1) χ (x j)‖ ≤ Cm * cbNorm m r := by
173  sorry

200/-- `L = -Δ + β∇(V + g*μ)·∇` (S line 2397) for the thermal measure `μ = μ_{a,β}`. -/
201def thermalGen (d : ℕ) (s a β : ℝ) (χ : Euc d → ℝ) (x : Euc d) : ℝ :=
202  -Laplacian.laplacian χ x +
203    β * inner ℝ (gradient (fun y => confinement a y + convMeasure (rieszKernel d s)
204      (thermalMeasure d s a β) y) x) (gradient χ x)
205
206/-- `A = γ⁻¹ I + K_μ` on `L²_0(μ)` (S line 2396). -/
207def susceptibilityOp (g : Euc d → ℝ) (μ : Measure (Euc d)) (γ : ℝ) (f : Euc d → ℝ) :
208    Euc d → ℝ :=
209  fun x => γ⁻¹ * f x + Kop g μ f x

211/-- The corrector conclusions `W:eq:r2-thermal-corrector` (S lines 2408-2415) at level `k`:
212`χ ∈ L²(μ)` centered, `C^{k+1}`, `Lχ ∈ L²(μ)`, `ALχ = P_μ φ` (`μ`-a.e.),
213`|χ(x)| ≤ C‖φ‖(1 + log(2+|x|))`, `∑_{j=1}^{k+1} ‖D^jχ‖_∞ ≤ C‖φ‖` (for `k = 1`:
214`‖∇χ‖_∞ + ‖D²χ‖_∞ ≤ C‖φ‖`). -/
215def IsThermalCorrector (d : ℕ) (s a β γ : ℝ) (k : ℕ) (φ : Euc d → ℝ) (normφ C : ℝ)
216    (χ : Euc d → ℝ) : Prop :=
217  MemL2Zero (thermalMeasure d s a β) χ ∧ ContDiff ℝ (k + 1) χ ∧
218    MemLp (thermalGen d s a β χ) 2 (thermalMeasure d s a β) ∧
219    (∀ᵐ x ∂(thermalMeasure d s a β),
220      susceptibilityOp (rieszKernel d s) (thermalMeasure d s a β) γ (thermalGen d s a β χ) x =
221        projMean (thermalMeasure d s a β) φ x) ∧
222    (∀ x, |χ x| ≤ C * normφ * (1 + Real.log (2 + ‖x‖))) ∧
223    ∀ x : Fin (k + 1) → Euc d, ∑ j : Fin (k + 1), ‖iteratedFDeriv ℝ ((j : ℕ) + 1) χ (x j)‖ ≤ C * normφ
224
225/-- Lemma S4.4 `W:lem:r2-thermal-corrector` (S lines 2405-2420), `C_b^J` version: for
226`0 ≤ s < d`, `k ≥ 1` and an integer `J > k + 1 + d/2` (`k = 1` is the first assertion,
227`J > d/2 + 2`), for every `φ ∈ C_b^J(ℝ^d)` there is a centered `χ ∈ L²(μ)` with `ALχ = P_μφ`,
228`|χ(x)| ≤ C‖φ‖_{C_b^J}(1+log(2+|x|))` and `∑_{j=1}^{k+1}‖D^jχ‖_∞ ≤ C_k‖φ‖_{C_b^J}`.  The
229constants are independent of the support of `φ` and uniform for `a, β, γ` in compact subsets
230of `(0,∞)` (quantified before them). -/

232    (J : ℕ) (hJ : (k : ℝ) + 1 + (d : ℝ) / 2 < J) (am ap βm βp γm γp : ℝ) (ham : 0 < am)
233    (hβm : 0 < βm) (hγm : 0 < γm) :
234    ∃ C : ℝ, ∀ a ∈ Set.Icc am ap, ∀ β ∈ Set.Icc βm βp, ∀ γ ∈ Set.Icc γm γp,
235      ∀ φ : Euc d → ℝ, MemCb J φ →
236        ∃ χ : Euc d → ℝ, IsThermalCorrector d s a β γ k φ (cbNorm J φ) C χ := by
237  sorry

239/-- `φ ∈ H^J(dx)` (smooth representative): `C^J` with all derivatives through order `J`
