5# Whole-space dynamics: particle system, mean-field equation, adjoint propagator, linear
6fluctuation processes (definitions used by Sections S4.10-S5.7 and the headline Theorem S2.1)
7
8Source: HRS whole-space supplement (S), with the periodic main paper (M) for the objects the
9supplement re-uses.
10
11* Particle system `W:r2:particle-equation` (S lines 200-203),
12  `dx_i = -(∇V(x_i) + N⁻¹ ∑_{j≠i} ∇g(x_i - x_j)) dt + √(2/β) dB_i`; its matrix form
13  `dx_i = (N⁻¹ ∑_{j≠i} M∇g(x_i-x_j) - ∇V(x_i)) dt + √(2ν) dB_i`, `ν = β⁻¹`
14  (M `H:eq:intro-particles`, M lines 170-178); the confined whole-space realization
15  (S lines 9698-9724, `S:sec:particle-realization`).
16* Mean-field equation and weak form `B:eq:mf-weak` on `ℝ^d` ("interpreted with the physical kernel
17  on `ℝ^d`", S lines 9667-9668), force convention `B:eq:nabla-g-convolution` (M lines 10091-10101,
18  stated for `𝔻 ∈ {𝕋^d, ℝ^d}`), backward generator `B:eq:adjoint-def` (M line 1590), classical
19  adjoint solution on `ℝ^d` (`B:rem:def-adjoint-rd`, S lines 10098-10100).
20* Linear fluctuation equation `H:eq:linear-equation`, mild form `H:eq:linear-mild`, noise
21  covariance `2q ∫_0^t μ^r(∇U^{r,t}φ·∇U^{r,t}ψ) dr`.
22
23## Representation decisions (see also `HRS/Dynamics/Setup.lean`, which these mirror)
24
25* All definitions mirror their periodic counterparts of `HRS/Dynamics/Setup.lean` with `ℝ^d`
26  in place of `𝕋^d`; the particle SDE has additive noise and is therefore written pathwise on
27  `ℝ^d` itself (no covering space).
28* The adjoint propagator `U^{r,t}φ` is the classical adjoint solution (`C_b²`, bounded `∂_r f`,
29  `B:rem:def-adjoint-rd`) when it exists (`propagatorW`; `0` otherwise, existence is an input of
30  each statement, never assumed in a definition).
31* A generator is described by a `WholeCoeff`: viscosity `ν`, the *full* drift field
32  `b_t = M∇g*ρ_t - ∇V` (resp. `-Qx + c_t`), the density `ρ_t`, the matrix `M` and the exponent `s`;
33  `generatorW` is `𝓛_t φ = νΔφ + b_t·∇φ - Div g*(ρ_t Mᵀ∇φ)`.  The S5.1/S5.7 operator with a general
34  bounded transport `c` is a `WholeCoeff` whose drift is `-Qx + c`.
35* The linear Gaussian process is characterised by its (jointly Gaussian) finite-dimensional laws,
36  as in the periodic file; the initial field of the linear equation is a *random linear functional*
37  `η₀ : Ω → (ℝ^d → ℝ) → ℝ` on test functions (because the adjoint orbit `U^{0,t}φ_j` of a Hermite
38  function has an algebraic tail and is not in `Σ^m`, S lines 3181-3184, so `Y⁰(U^{0,t}φ)` cannot
39  be a pairing of `Y⁰ ∈ B_m` with an element of `Σ^m`).
40-/

51/-! ### Coefficients of the particle system -/

53/-- Data of the whole-space dynamics: Riesz exponent `s`, constant interaction matrix `M`,
54one-body potential `V` (possibly of linear-gradient growth), and `invβ = β⁻¹ ∈ [0,∞)` (`ν`).
55Gradient dynamics is `M = -1` (`-I`).  The standing constraints `0 ≤ s < d`, `0 ≤ invβ` are
56hypotheses of each statement. -/
57structure WholeDyn (d : ℕ) where
58  s : ℝ
59  M : Matrix (Fin d) (Fin d) ℝ
60  V : Euc d → ℝ
61  invβ : ℝ
62
63/-- The affine-quadratic potential `V(x) = xᵀQx/2 + c·x` (S lines 3203, 3828). -/
64def quadV (Q : Matrix (Fin d) (Fin d) ℝ) (c : Euc d) (x : Euc d) : ℝ :=
65  (1 / 2) * inner ℝ x (Torus.matVec Q x) + inner ℝ c x
66
67/-- The collision set `{X : x_i = x_j for some i ≠ j}` of configurations of `ℝ^d`. -/
68def eucCollisionSet (d N : ℕ) : Set (EucConfig d N) := {X | ∃ i j, i ≠ j ∧ X i = X j}
69
70/-- The particle drift `b_i(X) = N⁻¹ ∑_{j≠i} M∇g(x_i - x_j) - ∇V(x_i)` (M line 171; S lines 200-203
71with `M = -I`). -/
72def particleDriftW (D : WholeDyn d) (X : EucConfig d N) (i : Fin N) : Euc d :=
73  (1 / (N : ℝ)) • ∑ j ∈ Finset.univ.erase i,
74      Torus.matVec D.M (rieszKernelGrad d D.s (X i - X j)) - gradient D.V (X i)
75
76/-- A collision-free strong solution of the whole-space particle system on `[0,T]` driven by `W`
77with initial configuration `X₀`, in integrated (pathwise) form
78`X_t = X_0 + ∫_0^t b(X_s) ds + √(2ν)(W_t - W_0)` (additive noise), continuous, adapted
79(each `X_t` measurable), with no collisions on `[0,T]` a.s. (the whole-space counterpart of
80`B:thm:particle-wp`, S lines 9698-9724). -/
81structure IsWholeStrongSolution {Ω : Type*} [MeasurableSpace Ω] (P : Measure Ω) (D : WholeDyn d)
82    (T : ℝ) (X₀ : Ω → EucConfig d N) (W : ℝ≥0 → Ω → (Fin N → Euc d))
83    (X : ℝ≥0 → Ω → EucConfig d N) : Prop where
84  init : ∀ᵐ ζ ∂P, X 0 ζ = X₀ ζ
85  eqn : ∀ᵐ ζ ∂P, ∀ t : ℝ≥0, (t : ℝ) ≤ T →
86    (∀ i, IntegrableOn (fun s : ℝ => particleDriftW D (X (Real.toNNReal s) ζ) i)
87      (Set.Icc 0 (t : ℝ))) ∧
88    ∀ i, X t ζ i = X 0 ζ i +
89      (∫ s in Set.Icc (0 : ℝ) t, particleDriftW D (X (Real.toNNReal s) ζ) i) +
90      Real.sqrt (2 * D.invβ) • (W t ζ i - W 0 ζ i)
91  cont : ∀ᵐ ζ ∂P, ∀ i, Continuous fun t => X t ζ i
92  adapted : ∀ t : ℝ≥0, Measurable (X t)
93  no_collision : ∀ᵐ ζ ∂P, ∀ t : ℝ≥0, (t : ℝ) ≤ T → X t ζ ∉ eucCollisionSet d N

95/-- Filtration bookkeeping for the whole-space process (`HRS.IsFilteredSolution` on `ℝ^d`; moved here from `HRS.Whole.AppendixA` so that the headline statements can use it): `W'` is a Brownian
96motion for `ℱ` with `W'(t)(i,j) = W_i^j(t)`, and `X` is `ℱ`-adapted and progressively measurable. -/
97structure IsWholeFilteredSolution {Ω : Type*} [mΩ : MeasurableSpace Ω] {N : ℕ} (P : Measure Ω)
98    (ℱ : Filtration ℝ mΩ) (W' : ℝ≥0 → Ω → (Fin N × Fin d) → ℝ) (W : ℝ≥0 → Ω → (Fin N → Euc d))
99    (X : ℝ≥0 → Ω → EucConfig d N) : Prop where
100  brownian : IsBrownianFiltration P ℱ W'
101  coords : ∀ᵐ ζ ∂P, ∀ t i j, W' t ζ (i, j) = W t ζ i j
102  adapted : ∀ t : ℝ≥0, Measurable[ℱ t] (X t)
103  progressive : IsProgressive ℱ (ofNNRealTime X)

105/-! ### Mean-field equation, generator, adjoint solutions -/
106
107/-- The force convolution `G * ρ (x)` by the cancellation convention
108`B:eq:nabla-g-convolution` (M lines 10091-10101, valid for `𝔻 = ℝ^d`; the subtracted constant
109contributes zero by oddness of `G = ∇g`):
110`∫ G(x-y)(ρ(y)-ρ(x)) 1_{|x-y|≤1/4} dy + ∫ G(x-y) ρ(y) 1_{|x-y|>1/4} dy`. -/
111def convGradConvW (G : Euc d → Euc d) (ρ : Euc d → ℝ) (x : Euc d) : Euc d :=
112  ∫ y, (if ‖x - y‖ ≤ 1 / 4 then (ρ y - ρ x) • G (x - y) else ρ y • G (x - y))
113
114/-- The mean-field drift `M ∇g*ρ - ∇V`. -/
115def meanFieldDriftW (D : WholeDyn d) (ρ : Euc d → ℝ) (x : Euc d) : Euc d :=
116  Torus.matVec D.M (convGradConvW (rieszKernelGrad d D.s) ρ x) - gradient D.V x
117
118/-- The symmetrised interaction pairing `½ ∬_{x≠y} (∇ψ(x)-∇ψ(y))·M∇g(x-y) dν(x) dν'(y)`
119(`B:eq:mf-weak`, M line 10104). -/
120def interactionPairingW (D : WholeDyn d) (ψ : Euc d → ℝ) (ν ν' : Measure (Euc d)) : ℝ :=
121  (1 / 2) * ∫ x, ∫ y, (if x = y then 0 else
122    inner ℝ (gradient ψ x - gradient ψ y) (Torus.matVec D.M (rieszKernelGrad d D.s (x - y)))) ∂ν' ∂ν
123
124/-- A weak solution of the whole-space mean-field equation on `[0,T]` (`H:eq:meanfield`,
125`B:eq:mf-weak` "interpreted with the physical kernel on `ℝ^d`", S lines 9667-9668): probability
126densities with a finite second moment (technical: needed for the integrations by parts, S lines
1279668-9670 "the second-moment bound"), and the weak identity for every `ψ ∈ C_b²(ℝ^d)`. -/
128structure IsWholeMeanFieldSolution (D : WholeDyn d) (T : ℝ) (ρ : ℝ → Euc d → ℝ) : Prop where
129  density : ∀ t ∈ Set.Icc 0 T, IsProbDensity (ρ t)
130  second_moment : ∀ t ∈ Set.Icc 0 T, Integrable (fun x => ‖x‖ ^ 2 * ρ t x)
131  weak : ∀ ψ : Euc d → ℝ, MemCb 2 ψ → ∀ t ∈ Set.Icc 0 T,
132    pair (withDensityReal (ρ t)) ψ - pair (withDensityReal (ρ 0)) ψ =
133      ∫ r in Set.Icc 0 t,
134        (pair (withDensityReal (ρ r)) (fun x => D.invβ * Laplacian.laplacian ψ x -
135            inner ℝ (gradient D.V x) (gradient ψ x)) +
136          interactionPairingW D ψ (withDensityReal (ρ r)) (withDensityReal (ρ r)))
137
138/-- Coefficients of a linear (backward) generator on `ℝ^d`: exponent `s` of the kernel,
139interaction matrix `M`, viscosity `ν ≥ 0`, the *full* transport field `b_t`, and the density
140`ρ_t` of the nonlocal term. -/
141structure WholeCoeff (d : ℕ) where
142  s : ℝ
143  M : Matrix (Fin d) (Fin d) ℝ
144  ν : ℝ
145  drift : ℝ → Euc d → Euc d
146  ρ : ℝ → Euc d → ℝ
147
148/-- The coefficients of the dynamics `D` along a mean-field trajectory `ρ`:
149transport `b_t = M∇g*ρ_t - ∇V`. -/
150def WholeDyn.coeff (D : WholeDyn d) (ρ : ℝ → Euc d → ℝ) : WholeCoeff d :=
151  ⟨D.s, D.M, D.invβ, fun t => meanFieldDriftW D (ρ t), ρ⟩
152
153/-- The backward generator `𝓛_t φ = νΔφ + b_t·∇φ - Div g*(ρ_t Mᵀ∇φ)` (`B:eq:adjoint-def`,
154M line 1590; S lines 3213-3215, 3844-3845), with both convolutions by the cancellation
155convention. -/
156def generatorW (C : WholeCoeff d) (t : ℝ) (φ : Euc d → ℝ) (x : Euc d) : ℝ :=
157  C.ν * Laplacian.laplacian φ x + inner ℝ (C.drift t x) (gradient φ x) -
158    ∑ j : Fin d, (convGradConvW (rieszKernelGrad d C.s)
159      (fun y => C.ρ t y * (Torus.matVec C.M.transpose (gradient φ y)) j) x) j
160
161/-- A classical adjoint solution on `[0,t]` with terminal datum `φ` on `ℝ^d`
162(`B:rem:def-adjoint-rd`, S lines 10098-10100): `f`, `∇f`, `∇²f` are bounded and continuous
163(local `C²` continuity in time), `f(t) = φ`, and `-∂_r f = 𝓛_r f` pointwise, with `∂_r f`
164continuous.
165SUSPECTED ISSUE (latent in the TeX): the source (S L10098-10100) asks `∂_r f` to be *bounded*.
166For the confining drift `-Qx·∇` (`Q ≠ 0`) this fails already at `r = t` for a bounded smooth datum
167such as `φ = sin x_i` (`∂_r f = -𝓛 φ` contains `Qx·∇φ`, which grows linearly), so the literal
168notion would make every statement using it vacuous for quadratic `V` (and B:thm:adjoint-rd(a) false
169as written).  The repaired notion used here (`bdd_time_deriv`) asks `∂_r f` to be of at most
170linear growth, `|∂_r f(r,x)| ≤ B(1+|x|)` uniformly on `[0,t]` (the drift is `O(1+|x|)` by
171`B:eq:drift-bounds-rd`, S L10112, and `∇f` is bounded); in the unconfined case (`Q = 0`, bounded
172drift) it is implied by the source's boundedness. -/
173structure IsClassicalAdjointW (C : WholeCoeff d) (t : ℝ) (φ : Euc d → ℝ)
174    (f : ℝ → Euc d → ℝ) : Prop where
175  c2 : ∀ r ∈ Set.Icc 0 t, ContDiff ℝ 2 (f r)
176  bdd : ∀ j ≤ 2, ∃ B : ℝ, ∀ r ∈ Set.Icc 0 t, ∀ x, ‖iteratedFDeriv ℝ j (f r) x‖ ≤ B
177  cont_c2 : ∀ j ≤ 2, Continuous fun p : Set.Icc (0 : ℝ) t × Euc d =>
178    iteratedFDeriv ℝ j (f p.1) p.2
179  terminal : f t = φ
180  time_deriv : ∀ x : Euc d, ∀ r ∈ Set.Ioo 0 t,
181    HasDerivAt (fun r' => f r' x) (-(generatorW C r (f r) x)) r
182  cont_time_deriv : Continuous fun p : Set.Icc (0 : ℝ) t × Euc d => generatorW C p.1 (f p.1) p.2
183  bdd_time_deriv : ∃ B : ℝ, ∀ r ∈ Set.Icc 0 t, ∀ x, |generatorW C r (f r) x| ≤ B * (1 + ‖x‖)

186/-- The adjoint propagator `U^{r,t} φ`: the classical adjoint solution at time `r` when one
187exists (`0` otherwise; existence is an input of the statements, never assumed here). -/
188def propagatorW (C : WholeCoeff d) (r t : ℝ) (φ : Euc d → ℝ) : Euc d → ℝ :=
189  if h : ∃ f, IsClassicalAdjointW C t φ f then h.choose r else 0

191/-- The noise covariance `2q ∫_0^{t∧t'} ∫ ∇U^{r,t}φ·∇U^{r,t'}ψ ρ^r dx dr` of the linear equation
192(`H:eq:linear-mild`, M line 498; `B:eq:surrogate-cov`). -/
193def noiseCovW (C : WholeCoeff d) (q t t' : ℝ) (φ ψ : Euc d → ℝ) : ℝ :=
194  2 * q * ∫ r in Set.Icc 0 (min t t'), ∫ x, inner ℝ (gradient (propagatorW C r t φ) x)
195    (gradient (propagatorW C r t' ψ) x) * C.ρ r x

197/-! ### The linear fluctuation equation -/
198
199/-- A smooth test function in the oscillator space `Σ^m` (so that the pairing
200`OscDual.eval Y φ` of a field `Y ∈ B_m` with it is the genuine pairing, not a junk `tsum`). -/
201def IsOscTest (m : ℝ) (φ : Euc d → ℝ) : Prop := ContDiff ℝ ∞ φ ∧ MemOsc m φ
202
203/-- A solution `Y` of the linear fluctuation equation `H:eq:linear-equation` with noise level
204`q ≥ 0` and prescribed random initial functional `η₀` (`Y⁰(f) = η₀(f)`), on `[0,T]`, in mild form
205(`H:eq:linear-mild`): `Y` is continuous in `B_m` a.s., and for every finite family of times and
206oscillator test functions the vector `(Y^{t_a}(φ_a) - η₀(U^{0,t_a}φ_a))_a` is a centered Gaussian,
207independent of `η₀`, with covariance `noiseCovW`. -/
208structure IsLinearFluctuationSolutionW {Ω : Type*} [MeasurableSpace Ω] (P : Measure Ω)
209    (C : WholeCoeff d) (m q T : ℝ) (η₀ : Ω → (Euc d → ℝ) → ℝ) (Y : ℝ → Ω → OscDual d m) :
210    Prop where
211  cont : ∀ᵐ ζ ∂P, ContinuousOn (fun t => Y t ζ) (Set.Icc 0 T)
212  meas : ∀ t, Measurable (Y t)
213  gaussian_part : ∀ (p : ℕ) (ts : Fin p → ℝ) (φ : Fin p → Euc d → ℝ),
214    (∀ a, ts a ∈ Set.Icc 0 T) → (∀ a, IsOscTest m (φ a)) →
215    let G : Ω → EuclideanSpace ℝ (Fin p) := fun ζ => WithLp.toLp 2 fun a =>
216      OscDual.eval (Y (ts a) ζ) (φ a) - η₀ ζ (propagatorW C 0 (ts a) (φ a))
217    ProbabilityTheory.IndepFun G η₀ P ∧
218    law P G = ProbabilityTheory.multivariateGaussian 0 (Matrix.of fun a b =>
219      noiseCovW C q (ts a) (ts b) (φ a) (φ b))
220
221/-- The linear Gaussian evolution `Z` along `C` with noise level `q` and initial covariance form
222`C₀` (a bilinear form on bounded smooth functions), characterised by its finite-dimensional
223laws: continuous in `B_m`, jointly centered Gaussian on oscillator test functions with
224`Cov(Z^t(φ), Z^{t'}(ψ)) = C₀(U^{0,t}φ, U^{0,t'}ψ) + noiseCovW q t t' φ ψ` (the sum of the
225initial covariance transported by the adjoint orbit and the noise covariance, `H:eq:linear-mild`
226with an independent centered Gaussian initial field). -/
227structure IsLinearGaussianEvolutionW {Ω : Type*} [MeasurableSpace Ω] (P : Measure Ω)
228    (C : WholeCoeff d) (m q T : ℝ) (C₀ : (Euc d → ℝ) → (Euc d → ℝ) → ℝ)
229    (Z : ℝ → Ω → OscDual d m) : Prop where
230  cont : ∀ᵐ ζ ∂P, ContinuousOn (fun t => Z t ζ) (Set.Icc 0 T)
231  meas : ∀ t, Measurable (Z t)
232  gaussian : ∀ (p : ℕ) (ts : Fin p → ℝ) (φ : Fin p → Euc d → ℝ),
233    (∀ a, ts a ∈ Set.Icc 0 T) → (∀ a, IsOscTest m (φ a)) →
234    law P (fun ζ => (WithLp.toLp 2 fun a => OscDual.eval (Z (ts a) ζ) (φ a) :
235        EuclideanSpace ℝ (Fin p))) =
236      ProbabilityTheory.multivariateGaussian 0 (Matrix.of fun a b =>
237        C₀ (propagatorW C 0 (ts a) (φ a)) (propagatorW C 0 (ts b) (φ b)) +
238          noiseCovW C q (ts a) (ts b) (φ a) (φ b))
239
240/-- The covariance `Cov(Z^t(φ), Z^{t'}(ψ))` of `IsLinearGaussianEvolutionW`. -/
241def linearGaussianCov (C : WholeCoeff d) (q : ℝ) (C₀ : (Euc d → ℝ) → (Euc d → ℝ) → ℝ)
242    (t t' : ℝ) (φ ψ : Euc d → ℝ) : ℝ :=
243  C₀ (propagatorW C 0 t φ) (propagatorW C 0 t' ψ) + noiseCovW C q t t' φ ψ

245/-! ### Window paths in `𝓧_T = C([0,T]; B_m)` -/

247open Classical in
248/-- The window `t ↦ f(a + t)`, `t ∈ [0,T]`, as an element of `𝓧_T`; the zero path if it is not
249continuous (the statements below assert measurability/continuity where relevant). -/
250def windowPathOf (m T a : ℝ) (f : ℝ → OscDual d m) : OscPath d m T :=
251  if h : Continuous fun t : Set.Icc (0 : ℝ) T => f (a + t) then
252    (⟨fun t => f (a + t), h⟩ : C(Set.Icc (0 : ℝ) T, OscDual d m))
253  else 0
254
255/-- The mean-field-centered window `η_N^{a+·}` scaled by `σ`: `t ↦ σ(μ_N^{a+t} - μ^{a+t}) ∈ B_m`
256(`σ = √N` is `η_N`, S line 212), for the particle path `X` and the mean-field densities `ρ`. -/
257def flucPathW {Ω : Type*} (m T a σ : ℝ) (X : ℝ≥0 → Ω → EucConfig d N) (ρ : ℝ → Euc d → ℝ) (ζ : Ω) :
258    OscPath d m T :=
259  windowPathOf m T a fun t =>
260    σ • OscDual.ofMeasureDiff m (empirical (X (Real.toNNReal t) ζ)) (withDensityReal (ρ t))
261
262/-- The exactly centered window `ζ_N^{a+·}`, `ζ_N^t = √N(μ_N^t - m_N^t)` with `m_N^t = E μ_N^t` the
263actual first marginal (the law of `X_t` under `P`; S lines 211-213). -/
264def zetaPathW {Ω : Type*} [MeasurableSpace Ω] (m T a : ℝ) (P : Measure Ω)
265    (X : ℝ≥0 → Ω → EucConfig d N) (ζ : Ω) : OscPath d m T :=
266  windowPathOf m T a fun t =>
267    zetaB m (P.map (X (Real.toNNReal t))) (X (Real.toNNReal t) ζ)
268
269/-- The window `Z^{a+·}` of a `B_m`-valued process. -/
270def processWindow {Ω : Type*} (m T a : ℝ) (Z : ℝ → Ω → OscDual d m) (ζ : Ω) : OscPath d m T :=
271  windowPathOf m T a fun t => Z t ζ
