23## Representation decisions
24
25* `H = H^{-Γ}(ℝ^d)` is `HRS.Whole.HNeg d Γ` (`HRS/Whole/SobolevDual.lean`), the duality pairing
26  `⟨φ, F⟩_{H^Γ,H^{-Γ}}` is `HNeg.pairing`; terminal tests are the smooth functions of `H^Γ`
27  (`IsSobolevTest`), because the classical adjoint solution has terminal datum a function.
28* The *selected adjoint density* `(𝒳, Γ)` (S.A.6) is represented by its index `Γ` and the uniform
29  adjoint input `AdjointFieldInput` (the estimate `H^Γ → C_b^1` of `U_N^{0,t}`, S L11213-11217): the
30  constants of the selected density are the constant `K` of that estimate.  The S.A theorem bundles are
31  not defined here.
32* The transported fields `𝓘_{N,emp}^t, 𝓘_N^t` (`B:eq:transported-initial-rd`) are *random elements of
33  `H` representing the functionals* `φ ↦ A_N⟨U_N^{0,t}φ, κ_N Fluc_N^0⟩`, `φ ↦ A_N⟨U_N^{0,t}φ, η°⟩`
34  on the test class (the TeX says "these functionals extend to `H^{-Γ}`-valued random variables"):
35  the statements are for *every* such representative, and existence is part of the conclusion
36  (`W_1` and the moment bound depend only on the laws, which are determined by the representation).
37* `η°` (the Gaussian bridge of `B:ex:iid`) is a random linear functional on `C_b^1` test functions with
38  Gaussian finite-dimensional laws of covariance `μ°(ψφ) - μ°(ψ)μ°(φ)` (`IsGaussianBridgeW`), as the
39  random functional `η₀` of `HRS/Whole/Dynamics.lean`.
40* `A_N = σ_N/κ_N` with `κ_N = √N` and `β_N⁻¹ = invβ N ≥ 0` is `HRS.Ascale` (`≤ 1`).

54/-- The covariance `μ(ψφ) - μ(ψ)μ(φ)` of the Gaussian bridge (`B:ex:iid`, M L10469-10475). -/
55def iidCovW (μ : Measure (Euc d)) (ψ φ : Euc d → ℝ) : ℝ :=
56  pair μ (fun x => ψ x * φ x) - pair μ ψ * pair μ φ
57
58/-- `η°` is a centered Gaussian field on `C_b^1` test functions with covariance `iidCovW μ°`
59(`B:ex:iid`): every `η°(ψ)` is a random variable and every finite family is jointly centered Gaussian
60with covariance matrix `(μ°(ψ_aψ_b) - μ°(ψ_a)μ°(ψ_b))_{ab}`. -/
61def IsGaussianBridgeW {Ω : Type*} [MeasurableSpace Ω] (P : Measure Ω) (μ : Measure (Euc d))
62    (η : Ω → (Euc d → ℝ) → ℝ) : Prop :=
63  (∀ ψ : Euc d → ℝ, MemCb 1 ψ → Measurable fun ζ => η ζ ψ) ∧
64  ∀ (p : ℕ) (ψ : Fin p → Euc d → ℝ), (∀ a, MemCb 1 (ψ a)) →
65    law P (fun ζ => (WithLp.toLp 2 fun a => η ζ (ψ a) : EuclideanSpace ℝ (Fin p))) =
66      multivariateGaussian 0 (Matrix.of fun a b => iidCovW μ (ψ a) (ψ b))
67
68/-- The amplitude `A_N = σ_N/κ_N` for `κ_N = √N`, `β_N⁻¹ = invβ` (`H:eq:intro-scales`). -/
69def fieldAmp (N : ℕ) (invβ : ℝ) : ℝ := Ascale N (Real.sqrt N) invβ
70
71/-- The adjoint input of the selected field density `(𝒳, Γ)` for one coefficient `C` (S L11213-11217,
72the estimates "`H^Γ → C_b^0`" and "`H^Γ → C_b^1`" for `U^{0,t}`) on `[0,T]`: for every `t ∈ [0,T]` and
73every smooth `φ ∈ H^Γ` the classical adjoint solution with terminal datum `φ` exists, `φ ↦ U^{r,t}φ`
74is linear on the test class (`propagatorW` is a `choose`; the classical adjoint solution is unique, and
75this linearity is that uniqueness), and `‖U^{0,t}φ‖_{C_b^1} ≤ K ‖φ‖_{H^Γ}` (the project's SUM convention
76of `C_b^1`, `HRS.cbNorm`). -/
77def AdjointInputOne (Γ : ℝ) (C : WholeCoeff d) (T K : ℝ) : Prop :=
78  ∀ t ∈ Set.Icc (0 : ℝ) T,
79    (∀ φ : Euc d → ℝ, IsSobolevTest Γ φ → ∃ f, IsClassicalAdjointW C t φ f) ∧
80    (∀ φ₁ φ₂ : Euc d → ℝ, IsSobolevTest Γ φ₁ → IsSobolevTest Γ φ₂ → ∀ c : ℝ,
81      ∀ r ∈ Set.Icc (0 : ℝ) t,
82        propagatorW C r t (φ₁ + c • φ₂) = propagatorW C r t φ₁ + c • propagatorW C r t φ₂) ∧
83    ∀ φ : Euc d → ℝ, IsSobolevTest Γ φ →
84      MemCb 1 (propagatorW C 0 t φ) ∧ cbNorm 1 (propagatorW C 0 t φ) ≤ K * sobolevNorm Γ φ
85
86/-- The uniform adjoint input of the selected field density for the family `(Cf N)_{N ≥ 1}`:
87`AdjointInputOne` for every `N ≥ 1`, with `K` independent of `N` and `t`. -/
88def AdjointFieldInput (Γ : ℝ) (Cf : ℕ → WholeCoeff d) (T K : ℝ) : Prop :=
89  ∀ N : ℕ, 1 ≤ N → AdjointInputOne Γ (Cf N) T K

94`x_1°,…,x_N°` i.i.d. with law `μ°` (`law X = (μ°)^{⊗N}`), `m_2° = ∫|x|²dμ° < ∞`, `κ_N = √N`, `η°` the
95centered Gaussian bridge of `B:ex:iid`, `(𝒳, Γ)` a selected whole-space field density (index `Γ` and

97representatives of `φ ↦ A_N⟨U_N^{0,t}φ, κ_N Fluc_N^0⟩ = A_N √N (μ_N^0(U_N^{0,t}φ) - μ°(U_N^{0,t}φ))`

191/-- The intrinsic kernels `K_{N,j}^{r,t}(x) ∈ H^{-Γ}` of Lemma S.A.20 `B:lem:adjoint-field-kernel`
192(S L10562-10581), for the coefficients `C` on `[0,T]`: `⟨φ, K_j^{r,t}(x)⟩_{H^Γ,H^{-Γ}} = ∂_j U^{r,t}φ(x)`
193for `φ ∈ H^Γ` (here: smooth tests), strong measurability in `(r,t,x)` and the uniform bound
194`‖K_j^{r,t}(x)‖_{H^{-Γ}} ≤ B` (the case `α = 0` of `B:eq:intrinsic-kernel-bound`).  The existence and
195uniqueness of `K` is S.A.20 (not stated here): this predicate is its conclusion. -/

199    IsSobolevTest Γ φ → HNeg.pairing φ (Kern r t x j) = gradient (propagatorW C r t φ) x j
200  measurable : ∀ j : Fin d, Measurable fun p : ℝ × ℝ × Euc d => Kern p.1 p.2.1 p.2.2 j
201  bound : ∀ r t : ℝ, 0 ≤ r → r ≤ t → t ≤ T → ∀ (x : Euc d) (j : Fin d), ‖Kern r t x j‖ ≤ B

203/-- Proposition S.B.7(ii) (`B:prop:limit-field`, TeX S L11474-11485): on `ℝ^d`, for the selected field
204density (index `Γ`), coefficients `C` (the density `μ^r = C.ρ r dx`, probability densities) and noise
205level `q = σ_N²/(Nβ_N) ≥ 0`, the intrinsic kernels define the positive trace-class covariance
206`Q_N^t = 2q ∫_0^t ∫ ∑_j K_j^{r,t}(x) ⊗ K_j^{r,t}(x) dμ^r(x) dr` and the centered Gaussian
207`G_N^t ~ N(0, Q_N^t)` is an `H^{-Γ}`-valued random variable with covariance `B:eq:surrogate-cov` on
208`H^Γ`, realized on an extension independent of the initial `σ`-field `𝓕_0^{in}`.  Formally: there is a
209centered Gaussian probability measure `ν` on `H` with (a) `E‖G‖² = Tr Q_N^t = 2q ∫_0^t ∫ ∑_j ‖K_j‖² dμ^r dr`

211kernel form of `Q_N^t` and `noiseCovW C q t t φ ψ = 2q ∫_0^t ⟨∇U^{r,t}φ·∇U^{r,t}ψ, μ^r⟩ dr` for
212smooth `φ, ψ ∈ H^Γ`, (c) for every probability space carrying any random element `Y` (the generator of
213`𝓕_0^{in}`) there is an extension on which a random element `G` of law `ν` is independent of `Y`.
214The hypotheses are the whole-space field theorem's (`B:thm:main-rd-field`, represented by the intrinsic
215kernel input) and `0 ≤ t ≤ T`. -/

236/-- The transported initial field `A η°(U^{0,t}·)` is `H^{-Γ}`-valued (the transported initial-field
237hypothesis `B:ass:init-field`(F-rd) for the limit coefficients): for every `t ∈ [0,T]` there is a

239def HasTransportedField {Ω : Type*} [MeasurableSpace Ω] (P : Measure Ω) (C : WholeCoeff d)
240    (Γ A T : ℝ) (η₀ : Ω → (Euc d → ℝ) → ℝ) : Prop :=
241  ∀ t ∈ Set.Icc (0 : ℝ) T, ∃ I : Ω → HNeg d Γ, Measurable I ∧

245/-- The adjoint-duality solution `η` of `B:eq:adjoint-duality-limit-rd` (S L11487-11490), for terminal
246tests `φ ∈ H^Γ` (smooth): `⟨φ, η^t⟩ = A ⟨U^{0,t}φ, η°⟩ + √(2q) ∫_0^t ⟨√μ^r ∇U^{r,t}φ, dW_r^ξ⟩`, `q = 1/β_*`
247(`2/β_*`), `W^ξ` a cylindrical Wiener process independent of `η°`.  As in the project's
248`IsLinearFluctuationSolutionW`, the Wiener integral is characterised by its law: for every finite
249family of times and tests the vector `(⟨φ_a, η^{t_a}⟩ - A η°(U^{0,t_a}φ_a))_a` is centered Gaussian,
250independent of `η°`, with covariance `noiseCovW C q t_a t_b φ_a φ_b = 2q ∫_0^{t_a∧t_b}⟨∇U^{r,t_a}φ_a ·
