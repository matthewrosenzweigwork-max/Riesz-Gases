12Differences, all handled below (checked exactly):

141. *Normalisation of the kernel.*  The repository's `rieszKernel d s = |x|^{-s}` (`s > 0`), `-log|x|`
15   (`s = 0`) equals `rieszScale s • kern s` with `rieszScale s = s` (`s > 0`), `1` (`s = 0`);
16   hence `rieszModulatedEnergy = rieszScale s · F_N`, `commN = rieszScale s · 𝖠₁`
17   (`rieszEnergy_eq`, `commN_eq`).  The additive constant is `C₀' = rieszScale s · C₀`.
182. *Transport norm.*  S.B.5(ii) has `a ∈ (d, d+2)` and `‖|∇|^{a/2}v‖_{L^{2d/(a-2)}}`;
19   `[N] (1.regularity-embedding)` (`sobolev_embedding_frac`) bounds `C(v) ≲_{d,s,a} ‖∇v‖_∞ +
20   ‖|∇|^{a/2}v‖`, so `C_a = C · C_emb(a)` (quantified before `Λ, N, ρ, X, v`, as in S.B.5(ii)).
213. *Error term.*  S.B.5(ii) uses `o_N = oNΛ d s C₀ Λ N` with `Λ ≥ ‖ρ‖_∞` arbitrary, `Λ ≥ 1`,
22   `N ≥ 2`; the note uses `λ = (N‖ρ‖_∞)^{-1/d}`.  Since `‖ρ‖_∞ ≤ Λ`:
23   `-log λ/(2N) = log(N‖ρ‖_∞)/(2dN) ≤ log(NΛ)/(2dN)` and
24   `‖ρ‖_∞ λ^{d-s} = ‖ρ‖_∞^{s/d} N^{s/d-1} ≤ Λ^{s/d} N^{s/d-1}`, so `[N]`'s bracket is `≤ F_N + o_N`
25   after multiplication by `rieszScale s`.
264. *Log hypothesis.*  S.B.5(ii) assumes the log moment `∫ log(2+|x|) dμ ≤ L` (constants quantified after
27   `L`); `[N]` assumes `(1.loghyp)`, which follows (`logIntegrable_of_logMoment`), and its constants do
28   *not* depend on `L`.  So `[N]` is stronger.
295. *Representation.*  `μ = withDensityReal ρ` (a measure) versus the function `ρ`; `IsProbDensity`
30   implies `Integrable ρ`, `MemLp ρ ∞`, `∫ρ = 1`; absolute convergence (`CommIntegrableW`).
