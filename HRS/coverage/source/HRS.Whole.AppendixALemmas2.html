39  with the smooth tests*** `IsSobolevTest q` (a.s. at each fixed time), exactly as in `AppendixBField.lean`
40  (S.B.2): the TeX defines `𝓘_{N,emp}^t, 𝓘_N^t, 𝕄_N^t, ℝ_N^t` by the functionals they extend, and the

66/-- `Zc` is a family of *continuous versions* of the processes `Z_N` on `[0,T]` with a uniform temporal
67modulus in probability, to which the tightness criterion `path_tightness_criterion` applies: for
68`N ≥ 1` and `t ∈ [0,T]`, `Zc N t = Z N t` a.s.; `Zc N` has a.s. continuous paths on `[0,T]` and
69measurable path map; for every `ε > 0`, `lim_{δ↓0} sup_N P(ω_E(Zc N, δ) > ε) = 0`; and if the
70fixed-time marginals `{Z_N^t : N ≥ 1}` are tight in `E` for every `t ∈ [0,T]`, then the laws of the
71paths `Zc N` are tight in `C([0,T]; E)`. -/
72def ContVersionTight {E : Type*} [NormedAddCommGroup E] [MeasurableSpace E] [BorelSpace E]
73    (T : ℝ) {Ω : ℕ → Type*} [∀ N, MeasurableSpace (Ω N)] (P : ∀ N, Measure (Ω N))
74    (Z Zc : ∀ N, ℝ → Ω N → E) : Prop :=
75  (∀ N : ℕ, 1 ≤ N → ∀ t ∈ Set.Icc (0 : ℝ) T, ∀ᵐ ζ ∂(P N), Zc N t ζ = Z N t ζ) ∧
76  (∀ N : ℕ, 1 ≤ N → ∀ᵐ ζ ∂(P N), Continuous fun t : Set.Icc (0 : ℝ) T => Zc N t ζ) ∧
77  (∀ N : ℕ, 1 ≤ N → Measurable fun ζ => contPathOf T (fun t => Zc N t ζ)) ∧
78  (∀ ε : ℝ, 0 < ε → Tendsto (fun δ : ℝ =>
79      ⨆ N : ℕ, ⨆ (_ : 1 ≤ N), P N {ζ | ENNReal.ofReal ε < omegaE (fun t => Zc N t ζ) T δ})
80    (𝓝[>] 0) (𝓝 0)) ∧
81  ((∀ t ∈ Set.Icc (0 : ℝ) T, IsTightMeasureSet {μ | ∃ N : ℕ, 1 ≤ N ∧ μ = (P N).map (Z N t)}) →
82    IsTightMeasureSet {μ | ∃ N : ℕ, 1 ≤ N ∧
83      μ = (P N).map (fun ζ => contPathOf T (fun t => Zc N t ζ))})
