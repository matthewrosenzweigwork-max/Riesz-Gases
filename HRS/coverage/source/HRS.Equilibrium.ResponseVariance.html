33/-- **Fixed-density linear variance bound** (`A:eq:variance-transfer`, second inequality, source
34lines 3531-3533; also `P:eq:static-linear` 3990, `R:eq:linear-input` 4187,
35`Q:eq:linear-input` 4485; "holds for every `L²(μ)` test, not just smooth tests", line 2756):
36for a smooth positive probability density `ρ` (the standing "smooth positive background", source
37lines 3388-3394, not tied to a potential), `β > 0`, there is `C` with
38`N Var_{Q_{N,β}(μ)}[μ_N(f)] ≤ C ‖f‖²_{L²(μ)}` for all `N ≥ 2` and all `f ∈ L²(μ)`,
39`μ = ρ dx`, `Q_{N,β}(μ) = modulatedGibbs (periodicRiesz d s) N β μ`.
40
41This is the linear analogue of `quadStat_variance` (`QuadraticVariance.lean`, whose hypotheses
42`2 ≤ d`, `0 ≤ s < d`, `0 < β`, `SmoothPosDensity ρ` it copies; the TeX of Appendix A is stated in
43the range of Prop 4.3, not just `d/2 ≤ s < d`).  Representation decisions:
44* the variance is the extended-real `evariance` (as in `quadStat_variance`), so there is no
45  `variance`-of-non-`L²` junk (`variance` would be `0`); `μ_N(f) = N⁻¹ ∑ f(x_i)`;
46* the right side is `ofReal (C * ∫ f² dμ)`; to keep the Bochner integral non-junk we assume
47  `MemLp f 2 μ` (otherwise `∫ f² = 0` and the claim would be false); `Measurable f` makes
48  `X ↦ f (X i)` measurable, so no `Measure.map`/`AEStronglyMeasurable` junk;
49* constant `C` is chosen before `N` and `f` (it may depend on `d, s, β, ρ`).
50Ambiguity: the TeX writes `‖f‖_{L²(μ)}` for the bound but does not say whether `f` is real
51bounded measurable or `L²(μ)`; the `L²` reading is the stronger one and is the one the TeX
52asserts (line 2756). -/

275Proof sketch of `response_subGaussian` from the statements above (TeX lines 5248-5268).
276Fix `a b` and let `C` be the constant of `rateVarN_uniform_bound` for `[a - 1, b + 1]`; put
277`D = max 2 C`.  Fix `N ≥ 2`, `θ ∈ [a,b]`.  By `finite_response_rates` (proved first display) the
278function `L_N(θ) := log (respA k gm β N 0 θ)` (the log-normaliser of the exponential tilt
279`resp_rateGibbs_eq`, `resp_respA_contDiff`, `resp_respA_hasDerivAt`) is smooth with
280`L_N' = N * rateMeanN`, `L_N'' = N * rateVarN` (`hMderiv`: `(rateMeanN)' = rateVarN`), so the log-mgf
281`Ψ(t) = L_N(θ + t/√N) - L_N(θ) - t √N rateMeanN θ` of `Y = rateY d s k β N θ` has
282`Ψ(0) = Ψ'(0) = 0` and `Ψ''(t) = rateVarN d s k β N (θ + t/√N) ≤ D` for `|t| ≤ √N`, because
283`θ + t/√N ∈ [a-1, b+1]` (`rateVarN_uniform_bound`).  Hence (Taylor with Lagrange remainder, e.g.
284`taylor_mean_remainder_lagrange`) `Ψ(t) ≤ D t²/2` for `|t| ≤ √N`; the mgf identity
285`E exp(t Y) = exp(Ψ(t))` is `resp_rateGibbs_eq` + `resp_integral_sum_cos`-type change of density
286(`mgf`, `ProbabilityTheory.mgf`).  Exponential Markov (`ProbabilityTheory.measure_ge_le_exp_mul_mgf`)
287with `t = ± x / D ≤ √N` for `0 ≤ x ≤ 2√N` gives `P(Y > x) ≤ exp(-x²/(2D))` and the same for `-Y`,
288so `P(|Y| > x) ≤ 2 exp(-x²/(2D))` (`measure_union_le`); for `x ≥ 2√N` the event `{|Y| > x}` is
289empty since `|Y| ≤ 2√N` (`Torus.norm_cosMode_le`, `rateMeanN` bounded by `1`).  For the Gaussian
290term, `susceptibilityCov_cosMode_le_one` gives variance `v := C(θ).toNNReal ≤ 1 ≤ D`, and
291`gaussianReal 0 v {z | x < |z|} ≤ 2 exp(-x²/(2v)) ≤ 2 exp(-x²/(2D))` (Gaussian tail bound:
292`gaussianReal` mgf `mgf_id_gaussianReal`, again exponential Markov; `v = 0` is the Dirac mass at `0`,
293tail `0`).  Adding the two bounds gives `4 exp(-x²/(2D))`, `ENNReal.ofReal` conversion by
294`ENNReal.ofReal_add`.
