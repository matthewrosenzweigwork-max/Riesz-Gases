14## Representation decisions
15
16* Weighted sup norms (`W:r2:decay-norm`, `‖f‖_{k,b} = max_{|α|≤k} sup_x ⟨x⟩^{b+|α|}|∂^α f(x)|`) are
17  `ℝ≥0∞`-valued (`decayNormE`; `∂^α f` as the iterated Fréchet derivative applied to coordinate
18  vectors), so that "infinite norm" is `⊤`, never a junk `0`; bounds read `‖·‖ ≤ C ‖·‖` in `ℝ≥0∞`.
19  Statements apply them to smooth functions, and assert the needed smoothness in the conclusion.
20* The uniformly local norm `‖f‖_{H^r_ul} = sup_{z∈ℤ^d} ‖θ(·-z) f‖_{H^r(ℝ^d)}` (S lines 3192-3198) is
21  `ulNormE` (`ℝ≥0∞`, `⊤` when some `θ(·-z)f ∉ H^r`), with the Fourier definition of `H^r` of
22  `HRS.PDE.ToolboxRd` (`sobolevNormSq`); the cutoff `θ` is a fixed parameter satisfying
23  `IsUlCutoff` and the constants may depend on it (the norm changes by equivalent constants
24  with `θ`, S line 3197).  The supplement's `H^m_uloc` (S line 9637, sup over `z ∈ ℝ^d`) of
25  S4.12/S4.14 is the same space with an equivalent norm.
26* "`|D|^α v ∈ L^p`" for a function `v` with only algebraic decay is understood distributionally
27  (`IsFracDerivRep`: `∫ v |D|^α φ = ∫ w φ` for all Schwartz `φ`, `|D|^α φ = 𝓕⁻[(2π|ξ|)^α 𝓕φ]`);
28  the Fourier transform of `v` itself may not exist (`v ∉ L¹`), so Mathlib's `fracGradPow` (junk
29  `0` for non-integrable `v`) would make S4.13 trivially true and is not used.
30* "The whole-space uniformly local adjoint theorem applies, uniformly in `0 ≤ ν ≤ ν_*`, through
31  derivative order `j` in `C_b`" (S4.12, S lines 3068-3070, and S5 hypotheses) is the predicate
32  `UlAdjointInput`: for every smooth terminal test `φ` with finite `H^{j+1+⌈d/2⌉}_ul` norm
33  (the index used in the proof, S lines 3098-3101) the classical adjoint solution exists and
34  `‖U(r,t)φ‖_{C_b^j} ≤ K ‖φ‖_{H^{j+1+⌈d/2⌉}_ul}`, `K` independent of `ν` and of `r ≤ t ≤ T`.
35  This replaces the regime/theorem citations (`B:thm:adjoint-rd`, `B:thm:adjoint-lp`), which are
36  not formalized here.

50/-- `⟨x⟩ = (1+|x|²)^{1/2}`. -/
51def jbracket (x : Euc d) : ℝ := Real.sqrt (1 + ‖x‖ ^ 2)
52
53/-- The partial derivative `∂_{i_1}⋯∂_{i_j} f(x) = D^j f(x)[e_{i_1},…,e_{i_j}]`. -/
54def partialDeriv {j : ℕ} (i : Fin j → Fin d) (f : Euc d → ℝ) (x : Euc d) : ℝ :=
55  iteratedFDeriv ℝ j f x (fun l => EuclideanSpace.single (i l) 1)
56
57/-- `max_{|α|≤k} sup_x ⟨x⟩^{w(|α|)} |∂^α f(x)|` in `ℝ≥0∞` (derivatives of order `j ≤ k`,
58all index tuples; a multi-index `α` with `|α| = j` is a symmetric class of index tuples). -/
59def derivSupE (k : ℕ) (w : ℕ → ℝ) (f : Euc d → ℝ) : ℝ≥0∞ :=
60  ⨆ j : Fin (k + 1), ⨆ i : Fin (j : ℕ) → Fin d, ⨆ x : Euc d,
61    ENNReal.ofReal (jbracket x ^ w j * |partialDeriv i f x|)
62
63/-- The decay norm `‖f‖_{k,b} = max_{|α|≤k} sup_x ⟨x⟩^{b+|α|}|∂^α f(x)|`
64(`W:r2:decay-norm`, S lines 2951-2953). -/
65def decayNormE (k : ℕ) (b : ℝ) (f : Euc d → ℝ) : ℝ≥0∞ := derivSupE k (fun j => b + j) f
66
67/-- `max_{|α|≤k} sup_x ⟨x⟩^{L}|∂^α f(x)|` (S lines 2962-2964: the weight exponent does not grow with
68`|α|`). -/
69def weightedSupE (k : ℕ) (L : ℝ) (f : Euc d → ℝ) : ℝ≥0∞ := derivSupE k (fun _ => L) f
70
71/-- `‖v‖_{k,b}` of a vector field, componentwise ("a vector-valued function is treated
72componentwise", S line 2955). -/
73def decayNormVecE (k : ℕ) (b : ℝ) (v : Euc d → Euc d) : ℝ≥0∞ :=
74  ⨆ i : Fin d, decayNormE k b fun x => v x i

76/-- `Σ_j ∂_j g * G_j` for a vector field `G` (the contracted convolution `Div g*G`, plain
77Bochner integral; absolutely convergent when `s + 1 < d` and `G` is bounded and integrable, which is
78the case in S4.10 where `s ≤ d - 2`). -/
79def divGConvPlain (d : ℕ) (s : ℝ) (G : Euc d → Euc d) (x : Euc d) : ℝ :=
80  ∑ j : Fin d, ∫ y, rieszKernelGrad d s (x - y) j * G y j
81
82/-- `∇g * h (x) = ∫ ∇g(x-y) h(y) dy` for a scalar `h` (plain Bochner integral). -/
83def gradGConvPlain (d : ℕ) (s : ℝ) (h : Euc d → ℝ) (x : Euc d) : Euc d :=
84  ∫ y, h y • rieszKernelGrad d s (x - y)

101/-- The cell centres `⌈√d⌉⁻¹ • ℤ^d`: the closed balls of radius `1` about them cover `ℝ^d` (every point is within

106/-- `‖f‖_{H^r_ul} = sup_{z∈ℤ^d} ‖θ(·-z) f‖_{H^r(ℝ^d)}` (S lines 3195-3198), `r` a natural number. -/

114/-- The closure of `C_c^∞` (constants adjoined) in the `H^k_ul` norm (S lines 3199-3201: "we take

116`C²` (for `k > d/2 + 2` every element has a `C²` representative). -/

121/-- `u : [0,t] → H^k_ul` is a backward evolution with terminal datum `f` for the generator `C`

131/-- The adjoint input "the whole-space uniformly local adjoint theorem applies through derivative
132order `j` in `C_b`" with constant `K` (see the module docstring): for `0 ≤ r ≤ t ≤ T` and every
133`φ ∈ C^{j+1+⌈d/2⌉}` with finite `H^{j+1+⌈d/2⌉}_ul` norm the classical adjoint solution
134(`IsClassicalAdjointW`, with the repaired growth condition on `∂_r f`, see there) exists and
135`‖U(r,t)φ‖_{C_b^j} ≤ K ‖φ‖_{H^{j+1+⌈d/2⌉}_ul}`.  The data class is finitely smooth, not `C^∞`:
136S5.5 (S L3914-3919) applies the adjoint estimate to `L_N^t φ_j`, which is only
137`C^{k+6+⌈d/2⌉}` (the density `ρ` has finitely many derivatives).  The TeX (S L3199-3202, "every
138function to which the evolution is applied belongs to the closure of `C_c^∞` in `H^k_ul`") restricts
139the data to that closure for strong continuity; for the *existence/bound* statement here the
140`C^{j+1+⌈d/2⌉} ∩ H_ul` class is what is used (this contains the closure's elements of that
141smoothness). -/
142def UlAdjointInput (θ : Euc d → ℝ) (C : WholeCoeff d) (T : ℝ) (j : ℕ) (K : ℝ) : Prop :=
143  ∀ r t : ℝ, 0 ≤ r → r ≤ t → t ≤ T → ∀ φ : Euc d → ℝ,
144    ContDiff ℝ ((j + 1 + ⌈(d : ℝ) / 2⌉₊ : ℕ) : WithTop ℕ∞) φ →
145    ulNormE (j + 1 + ⌈(d : ℝ) / 2⌉₊) θ φ < ⊤ →
146    (∃ f, IsClassicalAdjointW C t φ f) ∧ MemCb j (propagatorW C r t φ) ∧
147      cbNorm j (propagatorW C r t φ) ≤ K * (ulNormE (j + 1 + ⌈(d : ℝ) / 2⌉₊) θ φ).toReal

247/-- Proposition S4.12 (S:W:r2:adjoint-decay, TeX S L3066-3084).  Under `AdjointDecayHyp`
248(`0 ≤ s ≤ d-2`, the uniformly local adjoint theorem through order `k+1` uniformly in `ν ∈ [0,ν_*]`,
249uniform weighted bounds on the derivatives of `ρ_t` through order `k+1` with a common exponent
250`L > d + k + s + 4`, `V = xᵀQx/2 + c·x`, `Q` symmetric) the full adjoint evolution satisfies
251`‖U(r,t)φ‖_{k,s+1} ≤ C_T(‖φ‖_{k,s+1} + ‖φ‖_{H^{k+2+⌈d/2⌉}_ul})`, `C_T` independent of the support of
252`φ`, of `r, t` and of the viscosity in its interval.  The constant is quantified before the family
253`(ν, ρ)` and depends only on `d, s, k, L, Λ, K, T, ν_*, M, Q, c` and the cutoff `θ`.  The matrix `M`
254is arbitrary (S lines 3081-3083); `U(r,t)φ` is `propagatorW` (existence is part of the adjoint
255input); smoothness `C^k` of `U(r,t)φ` is part of the conclusion.  Technical hypotheses: `φ` is
256`C^{k+2+⌈d/2⌉}` with finite `H^{k+2+⌈d/2⌉}_ul` norm (so the adjoint solution exists and the `C^k`
