171/-- The scalar exactly-centred central limit theorem at the critical exponent, for the single test
172`ρ_β`: `√N(μ_N(ρ_β) - m_N(ρ_β)) ⇒ N(0, V_ρ)` under `P_{N,β}` (`m_N = E μ_N` the first marginal).  This is the
173scalar content of S4.5 `quadratic_static_field` (feature family `φ_0 = ρ_β`, `φ_j = 0`), which is not proved. -/
174def ScalarCLT (d : ℕ) (s a β : ℝ) : Prop :=
175  ∀ f : ℝ →ᵇ ℝ, Tendsto (fun N : ℕ => ∫ X, f (Real.sqrt N * (linStat (thermalDensity d s a β) X -
176      pair (firstMarginal (canonicalGibbs (rieszKernel d s) (confinement a) N β)) (thermalDensity d s a β)))
177    ∂(canonicalGibbs (rieszKernel d s) (confinement a) N β)) atTop
178    (𝓝 (∫ y, f y ∂(gaussianReal 0 (Real.toNNReal (scoreVariance d s β (thermalDensity d s a β))))))
