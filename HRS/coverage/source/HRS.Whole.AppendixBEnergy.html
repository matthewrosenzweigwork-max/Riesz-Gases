21## Representation decisions (consequential; all mirror the torus statements `HRS.mfe_uniform`,
22`HRS.commutator_estimate` of `HRS/Energy/Coercivity.lean`)
23
24* `𝖤_N(f, μ) = β⁻¹ 𝖧_N(f | μ^{⊗N}) + ∫ 𝖥_N(X_N, μ) f(dX_N)` with `𝖧_N = N⁻¹ H` (`modulatedFreeEnergyW`):
25  the same reading as the torus (the manuscripts use `𝖤_N` without a definition, ISSUES §C).
26  Finiteness is the separate predicate `MFEFiniteW` and part of the conclusion.
27* `o_N` of S.B.1 and S.B.5 is `HRS.oNΛ d s C₀ Λ N` with the constant `C₀` chosen before everything
28  (`o_N = o_N(Λ)` of `H:eq:energy-completion`, as in the torus statements); `Λ` is the bound of the
29  "stated bounded reference densities" (S.B.5) / of the regularity `S:eq:mf-regularity-whole`.
30* Norms of the transport are represented by *upper bounds* `K` (any `K ≥` the norm): `‖∇v‖_{L^∞}` by a
31  Lipschitz constant (`LipschitzWith`), `‖|∇|^{α}v‖_{L^p}` by a distributional representative
32  (`IsFracDerivRep`, `HRS/Whole/Adjoint.lean`, never Mathlib's junk-valued `fracGradPow`) with
33  `eLpNorm ≤ F`.  The time integrals `L_T = ∫_0^T ‖·‖ dt` are `∫_0^T K` for an integrable `K`
34  dominating the norm (as the torus `mfe_uniform`).
35* Commutators are `HRS.Whole.commN` (deleted particle diagonal, `Comm_N = 𝖢_N`); the integrals defining
36  them converge absolutely and this is part of the conclusion (`CommIntegrableW`), as on the torus.

48/-! ### Modulated free energy -/
49
50/-- The modulated free energy `𝖤_N(f, μ) = β⁻¹ 𝖧_N(f | μ^{⊗N}) + ∫ 𝖥_N(X_N, μ) f(dX_N)` on `ℝ^d`,
51`β⁻¹ = invβ`, `𝖧_N = N⁻¹ H` (the torus `HRS.modulatedFreeEnergy`); a real number meaningful under
52`MFEFiniteW`. -/
53def modulatedFreeEnergyW (d : ℕ) (s invβ : ℝ) {N : ℕ} (f : Measure (EucConfig d N))
54    (μ : Measure (Euc d)) : ℝ :=
55  invβ * (relEntropy f (Measure.pi fun _ : Fin N => μ) / (N : ℝ≥0∞)).toReal +
56    ∫ X, rieszModulatedEnergy d s X μ ∂f
57
58/-- `𝖤_N(f, μ) < ∞`: finite relative entropy and integrable interaction energy. -/
59def MFEFiniteW (d : ℕ) (s : ℝ) {N : ℕ} (f : Measure (EucConfig d N)) (μ : Measure (Euc d)) :
60    Prop :=
61  relEntropy f (Measure.pi fun _ : Fin N => μ) ≠ ⊤ ∧
62    Integrable (fun X => rieszModulatedEnergy d s X μ) f
63
64/-- `u_0 = β⁻¹ ∇ log μ + ∇g * μ` (`B:prop:mfe-confined-rd-gradient` L11098-11100), with `∇g*μ` by the
65cancellation convention (`convGradConvW`). -/
66def mfeTransport0W (D : WholeDyn d) (ρ : Euc d → ℝ) (x : Euc d) : Euc d :=
67  D.invβ • gradient (fun y => Real.log (ρ y)) x + convGradConvW (rieszKernelGrad d D.s) ρ x
68
69/-- `u_V = β⁻¹ ∇ log μ + ∇g * μ + ∇V` (S L11083-11085, `B:eq:uV-periodic` of M). -/
70def mfeTransportW (D : WholeDyn d) (ρ : Euc d → ℝ) (x : Euc d) : Euc d :=
71  mfeTransport0W D ρ x + gradient D.V x
72
73/-- The weighted regularity `‖ρ‖_{C_b^r} + max_{j≤r} ‖⟨x⟩^{d+3} ∇^{⊗j}ρ‖_∞ ≤ Λ` of one density
74(`S:eq:mf-regularity-whole`, S L9662-9665); the weighted sup is `ℝ≥0∞`-valued (`weightedSupE`). -/
75def IsRegularDensityW (r : ℕ) (Λ : ℝ) (ρ : Euc d → ℝ) : Prop :=
76  ContDiff ℝ r ρ ∧ MemCb r ρ ∧
77    ENNReal.ofReal (cbNorm r ρ) + weightedSupE r ((d : ℝ) + 3) ρ ≤ ENNReal.ofReal Λ
78
79/-- `(r,Λ)`-regularity of a whole-space mean-field trajectory on `[0,T]`
80(`S:eq:mf-regularity-whole`, S L9662-9665, for one value of `N`):
81`sup_{t≤T} (‖ρ^t‖_{C_b^r} + max_{j≤r} ‖⟨x⟩^{d+3} ∇^{⊗j}ρ^t‖_∞) ≤ Λ`. -/
82def IsRegularMFW (r : ℕ) (Λ T : ℝ) (ρ : ℝ → Euc d → ℝ) : Prop :=
83  ∀ t ∈ Set.Icc 0 T, IsRegularDensityW r Λ (ρ t)
84
85/-- `‖v‖_{Lip} ≤ K`, i.e. `‖∇v‖_{L^∞} ≤ K` for a Lipschitz field (the Lipschitz constant). -/
86def HasLipBoundW (v : Euc d → Euc d) (K : ℝ) : Prop :=
87  ∃ L : ℝ≥0, LipschitzWith L v ∧ (L : ℝ) ≤ K
88
89/-- `‖∇v‖_{L^∞} + ‖|∇|^α v‖_{L^p} ≤ K` (the transport seminorms of S.B.1(ii), S.B.5(ii),(iii)):
90`v` is Lipschitz with constant `L` and the distributional fractional derivative `|∇|^α v`
91(`IsFracDerivRep`, componentwise) has a representative `w` with `‖ |w| ‖_{L^p} ≤ F`, `L + F ≤ K`. -/
92def HasFracTransportBound (α p : ℝ) (v : Euc d → Euc d) (K : ℝ) : Prop :=
93  ∃ (L : ℝ≥0) (F : ℝ), 0 ≤ F ∧ LipschitzWith L v ∧
94    (∃ w : Euc d → Euc d, (∀ i, IsFracDerivRep α (fun x => v x i) (fun x => w x i)) ∧
95      eLpNorm (fun x => ‖w x‖) (ENNReal.ofReal p) volume ≤ ENNReal.ofReal F) ∧
96    (L : ℝ) + F ≤ K
97
98/-- Absolute convergence of the integrals defining `Comm_N(v; X_N, μ)`:
99`∫ h_v(x_i, y) dμ(y)` and `∬ h_v dμ dμ`, `h_v(x,y) = (v(x)-v(y))·∇g(x-y)`. -/
100def CommIntegrableW (d : ℕ) (s : ℝ) {N : ℕ} (v : Euc d → Euc d) (X : EucConfig d N)
101    (μ : Measure (Euc d)) : Prop :=
102  (∀ i, Integrable (fun y => commutatorKernel d s v (X i) y) μ) ∧
103    Integrable (fun p : Euc d × Euc d => commutatorKernel d s v p.1 p.2) (μ.prod μ)

107/-- The standing hypotheses of Proposition S.B.1 `B:prop:mfe-confined-rd-gradient` (S L11080-11082),
108common to both alternatives: `𝔻 = ℝ^d`, `M = -I`, `β_N < ∞` (`invβ > 0`); the initial particle law has
109finite Gibbs entropy `B:eq:selected-initial-gibbs-entropy` (relative entropy with respect to the
110canonical Gibbs law `G_{N,β_N,V}`) and `𝖤_N(f_N^0, μ°) < ∞`; `μ = μ_{β_N}` (`ρ`) is a *regular
111solution* of `H:eq:meanfield` on `[0,T]` (`IsWholeMeanFieldSolution` plus the `(r,Λ)`-regularity
112`S:eq:mf-regularity-whole`, `Λ ≥ 1`, and `ρ^t > 0` so that `∇ log μ` is defined; AMBIGUITY: the
113supplement does not define "regular"); `X` is the selected particle process (the collision-free
114strong solution of the whole-space particle system, `IsWholeStrongSolution`, S L9698-9724, with `X_0`
115independent of the noise). -/

124  Λ_ge : 1 ≤ Λ
125  pos_density : ∀ t ∈ Set.Icc 0 T, ∀ x, 0 < ρ t x
126  gibbs_entropy :

129  brownian : IsVectorBrownian P W

133  `RdStanding.filtered`): `IsWholeStrongSolution.adapted` is only measurability of each `X t`, whereas the Itô/entropy calculus
134  needs `X` adapted and `W` Brownian for a common filtration. -/

211/-- Proposition S.B.5(i) (`S:prop:whole-commutators`, `B:item:comm-rd-super`, TeX S L11371-11381;
212external: Rosenzweig-Serfaty, *Sharp commutator estimates*, Thm 1.1): on `ℝ^d`, for
213`s ≥ max{0, d-2}` (and `s < d`), for every probability density `ρ` with `‖ρ‖_∞ ≤ Λ` (the "stated
214bounded reference densities"; `Λ ≥ 1`), every `N ≥ 2`, every pairwise distinct `X_N` and every
215Lipschitz `v` (`‖∇v‖_∞ ≤ K`; no decay of `v`):
216`|Comm_N(v; X_N, μ)| ≤ C ‖∇v‖_∞ (𝖥_N(X_N, μ) + o_N)`, `o_N = oNΛ d s C₀ Λ N`; the integrals defining
217`Comm_N` converge absolutely.  For `s = 0` ("the usual logarithmic integrability assumption")
218`∫ log(2+|x|) dμ ≤ L` (`HasLogMoment`), `L` quantified before the constants (as the log-moment
219parameter `L` of `HRS.Whole.euclidean_pressure`; AMBIGUITY: the TeX does not say how the constants
220depend on this assumption).
221Technical hypotheses: `1 ≤ d`, `2 ≤ N`, `1 ≤ Λ` (as `HRS.commutator_estimate`).  PLAN: external
222results, cited in the TeX, not proved in the repository. -/

228      (s = 0 → HasLogMoment (withDensityReal ρ) L) →

230      ∀ (v : Euc d → Euc d) (K : ℝ), HasLipBoundW v K →
231        CommIntegrableW d s v X (withDensityReal ρ) ∧
232        |commN d s v X (withDensityReal ρ)| ≤
233          C * K * (rieszModulatedEnergy d s X (withDensityReal ρ) + oNΛ d s C₀ Λ N) := by

255/-- The long-range error `e_N^{lr} = (1 + 1_{s=0} log N) N^{-2/((s+1)(s+2))}`
256(`B:eq:old-comm-error`, S L11396-11398). -/
