25/-- An isonormal Gaussian process on the real Hilbert space `H`: `W h` are random variables whose finite
26families are centred Gaussian vectors with covariance the Gram matrix `⟪h_i, h_j⟫` (`W` is then a.e. linear). -/
27def IsIsonormal (P : Measure Ω) (W : H → Ω → ℝ) : Prop :=
28  ∀ (n : ℕ) (h : Fin n → H),
29    law P (fun ω => (WithLp.toLp 2 fun i : Fin n => W (h i) ω : EuclideanSpace ℝ (Fin n))) =
30      multivariateGaussian 0 (Matrix.of fun i j : Fin n => inner ℝ (h i) (h j))
31
32/-- The finite sections `½ ∑_{i,j<L} ⟪e_i, A e_j⟫ (W(e_i) W(e_j) - δ_{ij})` of the centred quadratic chaos of the
33operator `A`, computed in the basis `e`. -/
34def isoSection (A : H →L[ℝ] H) (W : H → Ω → ℝ) (e : ℕ → H) (L : ℕ) (ω : Ω) : ℝ :=
35  (1 / 2) * ∑ i ∈ Finset.range L, ∑ j ∈ Finset.range L,
36    inner ℝ (e i) (A (e j)) * (W (e i) ω * W (e j) ω - if i = j then 1 else 0)
37
38/-- (b3) Proposition 7.18, "has a basis-independent Gaussian quadratic-chaos meaning" (TeX L9829-9835: "Finite-dimensional
39orthogonal changes of basis preserve the centered quadratic polynomial.  Approximation then gives its basis-independent
40meaning for an isonormal Gaussian process, with the process transformed along with the basis"): let `A` be a
41symmetric Hilbert-Schmidt operator on a (separable) real Hilbert space, `W` an isonormal Gaussian process, and `e, e'` two
42orthonormal bases (Hilbert bases indexed by `ℕ`).  If `A` is Hilbert-Schmidt in the basis `e` (`∑‖A e_i‖² < ∞`;
43this is basis independent), then the sections computed in `e` and in `e'` converge in `L²(P)` to one and the same
44limit `Q`. -/
45theorem chaos_isonormal_basis_independent [CompleteSpace H]
46    (P : Measure Ω) [IsProbabilityMeasure P] (W : H → Ω → ℝ) (hW : IsIsonormal P W)
47    (A : H →L[ℝ] H) (hA : ∀ x y, inner ℝ (A x) y = inner ℝ x (A y))
48    (e e' : HilbertBasis ℕ ℝ H) (hHS : Summable fun i => ‖A (e i)‖ ^ 2) :
49    ∃ Q : Ω → ℝ, HRS.TendstoL2 P (isoSection A W e) Q ∧ HRS.TendstoL2 P (isoSection A W e') Q := by
50  sorry
