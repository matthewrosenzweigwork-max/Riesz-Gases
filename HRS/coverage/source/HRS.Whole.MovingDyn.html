79/-- The conclusions of S6.6 for the preparations (S L4559-4571), uniform in `t ≥ 0`, for the particle
80law `f_N^t = P∘(X_t)⁻¹` and the moving reference `Q_N^t = Q_{N,β}(μ^t)`, `μ^t = ρ^t dx`:
81`H(f_N^t|Q_N^t) ≤ C N δ_N` (`W:r2mov:H-bound`), `E_{f_N^t}|F_N^g(X_N,μ^t)| ≤ C δ_N`
82(`W:r2mov:F-bound`), `H(f_N^t|(μ^t)^{⊗N}) ≤ C N δ_N` (`W:r2mov:product-bound`),
83`E_{f_N^t} e_N ≤ C o_N` (`e_N = F_N^g + o_N`, "in particular"), and the normalized second moment is
84at most `C`.  Expectations of nonnegative quantities are lower integrals in `ℝ≥0∞` (no junk). -/

88    relEntropy (P.map (X t.toNNReal))
89        (modulatedGibbs (rieszKernel d s) N β (withDensityReal (ρ t))) ≤
90      ENNReal.ofReal (C * N * deltaN d s N) ∧
91    ∫⁻ Z, ENNReal.ofReal |rieszModulatedEnergy d s Z (withDensityReal (ρ t))|
92        ∂(P.map (X t.toNNReal)) ≤ ENNReal.ofReal (C * deltaN d s N) ∧
93    relEntropy (P.map (X t.toNNReal)) (Measure.pi fun _ => withDensityReal (ρ t)) ≤
94      ENNReal.ofReal (C * N * deltaN d s N) ∧
95    ∫⁻ Z, ENNReal.ofReal (rieszModulatedEnergy d s Z (withDensityReal (ρ t)) + oN d s C₀ N)
96        ∂(P.map (X t.toNNReal)) ≤ ENNReal.ofReal (C * oN d s C₀ N) ∧
