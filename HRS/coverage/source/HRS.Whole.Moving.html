18## Representation decisions
19
20* `Σ^r` is the Hermite-coefficient scale of `Oscillator.lean` (`MemOsc`, `oscNorm`, valid for every
21  real index, also negative).  The operators `P`, `B` of S6.1 are *unbounded differential
22  operators defined on the dense core `𝒮(ℝ^d)`* (Schwartz functions); "maps `Σ^r` to `Σ^{r-a}`"
23  is stated as the boundedness estimate on this core (its unique continuous extension is the
24  operator of the source).  For `v ∈ 𝒮`, `√ρ_* v` is a smooth Gaussian-decaying function.
25* `∇g*h` is the force by the cancellation convention `B:eq:nabla-g-convolution` (`convGradConvW`,
26  M L10091-10101, valid on `ℝ^d`), which is the distributional `∇(g*h)` for the `C¹` functions
27  with Gaussian decay used here; `Δg*h := div(∇g*h)`.
28* The mean-field equation `∂_tρ = νΔρ + div(ρ(qx + ∇g*ρ))` is the gradient case `M = -I` of
29  `H:eq:meanfield`; its solutions are the weak solutions `IsWholeMeanFieldSolution` for
30  `quadraticGradientDyn d s q β` (W1, `Dynamics.lean`).
31* The "small Gaussian weighted mild class" of S6.3 (S L4349) is not defined in the TeX beyond its
32  proof (S L4380-4395, norm `sup_{t≥0} e^{c₀t}‖v_t‖_{Σ^m}` on a small ball, `0 < c₀ < c`).  It is
33  represented by `MovInSmallClass`: global weak solutions with `v_t = (ρ^t-ρ_*)/√ρ_*` continuous
34  into `Σ^m` and `‖v_t‖_{Σ^m} ≤ r e^{-c₀t}`; the radius `r > 0` is existentially quantified in S6.3
35  (small-ball uniqueness), `c₀ ≥ 0` is arbitrary in the uniqueness clause
36  (decision M7: exponent `0` covers all).  AMBIGUITY: the source says *mild* solutions
37  (Duhamel formula with the semigroup of S6.2); in this regularity class mild and weak solutions
38  coincide (S L4396-4401 "repeated positive-time smoothing gives the classical equation"), and
39  the Duhamel formula needs the semigroup `T(t)` which is itself only stated existentially.

157/-- "`(T(t))_{t≥0}` is the strongly continuous semigroup on `L²_0 = {⟨v,√ρ_*⟩=0}` whose generator
158is `-S̄`, `S̄` the closure of `S` on the Schwartz core": `T(0) = I`, `T(a+b) = T(a)T(b)`, strong
159continuity on `[0,∞)`, and for every Schwartz `φ ∈ L²_0` there is `w ∈ L²_0` with `w = Sφ` a.e.
160such that `(d/dt)T(t)φ = -T(t)w` (right derivative) for all `t ≥ 0`.  A strongly continuous
161semigroup whose generator extends `-S|_core` has generator `-S̄` as soon as `-S̄` is a generator, so
162`MovIsSemigroup` pins `T` down uniquely when it exists. -/
163structure MovIsSemigroup (d : ℕ) (s β : ℝ) (ρ : Euc d → ℝ)
164    (T : ℝ → (MovL2Zero ρ →L[ℝ] MovL2Zero ρ)) : Prop where
165  zero : T 0 = 1
166  add : ∀ a b : ℝ, 0 ≤ a → 0 ≤ b → T (a + b) = T a * T b
167  cont : ∀ v : MovL2Zero ρ, ContinuousOn (fun t => T t v) (Set.Ici 0)
168  generator : ∀ (φ : SchwartzMap (Euc d) ℝ) (v : MovL2Zero ρ),
169    (∀ᵐ x ∂(volume : Measure (Euc d)), movFun v x = φ x) →
170      ∃ w : MovL2Zero ρ, (∀ᵐ x ∂(volume : Measure (Euc d)), movFun w x = movS d s β ρ φ x) ∧
171        ∀ t : ℝ, 0 ≤ t → HasDerivWithinAt (fun τ => T τ v) (-(T t w)) (Set.Ici t) t

173/-- The two estimates `W:r2mov:linear-smoothing` (S L4286-4291) for a family `U(t)` of operators on
174`L²_0`: `‖U(t)‖_{Σ^m→Σ^m} ≤ C e^{-ct}` (`t ≥ 0`) and `‖U(t)‖_{Σ^{m-a}→Σ^m} ≤ C(1+t^{-a/2})e^{-ct}`
175(`t > 0`), on `L²_0 ∩ Σ^m` resp. `L²_0 ∩ Σ^{m-a}`, including `U(t)v ∈ Σ^m`. -/
176def MovSmoothingBounds (d : ℕ) (s : ℝ) (ρ : Euc d → ℝ) (m c C : ℝ)
177    (U : ℝ → (MovL2Zero ρ →L[ℝ] MovL2Zero ρ)) : Prop :=
178  (∀ t : ℝ, 0 ≤ t → ∀ v : MovL2Zero ρ, MemOsc m (movFun v) →
179    MemOsc m (movFun (U t v)) ∧
180      oscNorm m (movFun (U t v)) ≤ C * Real.exp (-c * t) * oscNorm m (movFun v)) ∧
181  (∀ t : ℝ, 0 < t → ∀ v : MovL2Zero ρ, MemOsc (m - movA d s) (movFun v) →
182    MemOsc m (movFun (U t v)) ∧
183      oscNorm m (movFun (U t v)) ≤
184        C * (1 + t ^ (-(movA d s) / 2)) * Real.exp (-c * t) * oscNorm (m - movA d s) (movFun v))

186/-- Lemma 6.2 (S:W:lem:r2mov-linear, TeX S L4278-4293).  On `⟨v,√ρ_*⟩ = 0` let `S` be the closure of

232/-- The small Gaussian weighted solution class of S6.3 (S L4349; see the module docstring):
233a global weak solution of the mean-field equation of the quadratic gradient dynamics with initial
234datum `ρ_*(1+f^0)`, whose perturbation `v_t = (ρ^t-ρ_*)/√ρ_*` lies in `Σ^m`, is continuous into
235`Σ^m` on `[0,∞)` and satisfies `‖v_t‖_{Σ^m} ≤ r e^{-c₀t}` (ball of radius `r` in the weighted norm
236`sup_{t≥0} e^{c₀t}‖v_t‖_{Σ^m}`).
237Technical hypothesis `regular` (`ρ^t` continuous in `x`): the other conditions only see `ρ^t` through
238integrals / `Σ^m` coefficients, i.e. up to null sets; in the TeX class (`m > d/2`, so `v_t` is
239continuous by Sobolev embedding) the continuous representative is canonical, and without `regular`
240the uniqueness clause `ρ' t = ρ t` of `MovNonlinearConclusion` would be false pointwise.
241Limitation: `IsWholeMeanFieldSolution` forces `ρ^t ≥ 0`, whereas the TeX mild class allows signed `v`
242(positivity is proved afterwards, S L4378-4387); so uniqueness here is among nonnegative solutions
243only (AMBIGUITY / weaker than the TeX; stating it for signed solutions needs a separate weak
244formulation of the equation for signed densities).
245Statement change (S6.3 review, decision M7): the exponent `c₀` is allowed to be `0` (`c₀ ≥ 0`); the class with `c₀ = 0`
246is the ball `sup_{t≥0}‖v_t‖_{Σ^m} ≤ r`, which contains every class with `c₀ ≥ 0` (`MovInSmallClass.mono_rate`), and the
247uniqueness clause of `MovNonlinearConclusion` is stated there. -/
248structure MovInSmallClass (d : ℕ) (s q β : ℝ) (ρ₀ : Euc d → ℝ) (m : ℕ) (r c₀ : ℝ)
249    (f0 : Euc d → ℝ) (ρ : ℝ → Euc d → ℝ) : Prop where
250  solution : ∀ T : ℝ, IsWholeMeanFieldSolution (quadraticGradientDyn d s q β) T ρ
251  init : ∀ x, ρ 0 x = ρ₀ x * (1 + f0 x)
252  weighted : ∀ t : ℝ, 0 ≤ t → MemOsc (m : ℝ) (movV ρ₀ ρ t) ∧
253    oscNorm (m : ℝ) (movV ρ₀ ρ t) ≤ r * Real.exp (-c₀ * t)
254  cont : ContinuousOn (fun t => OscSpace.ofFun (d := d) (m : ℝ) (movV ρ₀ ρ t)) (Set.Ici 0)
255  regular : ∀ t : ℝ, 0 ≤ t → Continuous (ρ t)

257/-- Monotonicity in the exponent: a solution of the class with exponent `c₀ ≥ 0` is in the class with exponent `0`
258(the ball `sup_{t≥0}‖v_t‖_{Σ^m} ≤ r`). -/
259theorem MovInSmallClass.mono_rate {d : ℕ} {s q β : ℝ} {ρ₀ : Euc d → ℝ} {m : ℕ} {r c₀ : ℝ}
260    {f0 : Euc d → ℝ} {ρ : ℝ → Euc d → ℝ} (h : MovInSmallClass d s q β ρ₀ m r c₀ f0 ρ)
261    (hc : 0 ≤ c₀) : MovInSmallClass d s q β ρ₀ m r 0 f0 ρ := by
262  refine ⟨h.solution, h.init, fun t ht => ⟨(h.weighted t ht).1, ?_⟩, h.cont, h.regular⟩
263  have h1 := (h.weighted t ht).2
264  have hn : 0 ≤ oscNorm (m : ℝ) (movV ρ₀ ρ t) := by unfold oscNorm; exact Real.sqrt_nonneg _
265  have hr : 0 ≤ r := by
266    by_contra hr
267    rw [not_le] at hr
268    have := mul_neg_of_neg_of_pos hr (Real.exp_pos (-c₀ * t))
269    linarith
270  exact h1.trans (mul_le_mul_of_nonneg_left (Real.exp_le_exp.2 (by nlinarith)) hr)

279/-- The decay conclusions of S6.3 with amplitude `K` (`ε_*` in the displayed bounds, or the actual
