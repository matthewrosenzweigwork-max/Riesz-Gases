16## Representation decisions
17
18* `K_g ∈ {∂_i g *}` (order `θ - 1 = s + 1 - d`) acts on functions through the distributional
19  convolution `∂_i g * v := ∂_i (g * v)`: `IsGradKernelRep d s i v w` says `w` represents it
20  (`∫ w φ = -∫ v (g * ∂_iφ)` for Schwartz `φ`); for `s < d-1` this is the absolutely convergent
21  integral.  Far-field terms (kernel nonsingular) use the plain Bochner integral `gradGConvPlain`
22  with integrability asserted in the conclusion.
23* The *advected cutoffs* `χ_z^τ, χ̂_z^τ` (`B:eq:advected-cutoffs`, S L10082-10090) are
24  `advCutoff χ Ψ τ z = χ(Ψ_τ^{-1}(·) - z)` where `Ψ` is any flow of `-b` (`IsNegDriftFlow`) of a drift
25  `b` satisfying the bounds `B:eq:drift-bounds-rd` (`IsAdvectingDrift`, with constant `Cb`).  The drift
26  of the supplement, `b^τ = M ∇g * μ^{t-τ} - ∇V`, satisfies these bounds with `Cb = Cb(d, s, m, |M|, Λ,
27  Λ_V, |∇V(0)|)` (Lemma `B:lem:coefficient-bounds`), so the constants "`C_T` depending on
28  `(d,s,m,|M|,Λ,Λ_V,|∇V(0)|,ν̄,T)`" are represented as constants depending on `(d, s, m, Λ, Cb, T)`; the
29  statements hold for every drift with these bounds (the proof uses nothing else).  The lattice
30  `z ∈ ℤ^d` indexes the cells (`latticePt`).  `ω_z = ⟨z⟩^{-(d+3)}` is `cellWeight`.
31* Norms are in `ℝ≥0∞` where the quantity may be infinite (`sobolevNormE`, `eLpNorm`); the weighted sup
32  `‖⟨·⟩^{d+3}a‖_∞ ≤ Λ` is the pointwise bound.
33* `θ - 1 = s + 1 - d` is the order of `∂_i g *`, so `(θ-1)^+ = max (s + 1 - d) 0`.

47/-- `w` represents `∂_i g * v = ∂_i (g * v)` in the sense of distributions: for every Schwartz `φ`,
48`∫ w φ = -∫ v (g * ∂_iφ)` (both integrals absolutely convergent), `g` the Riesz kernel `rieszKernel d s`
49(even, so `(g * ∂_iφ)(y) = ∫ g(x-y) ∂_iφ(x) dx`). -/
50def IsGradKernelRep (d : ℕ) (s : ℝ) (i : Fin d) (v w : Euc d → ℝ) : Prop :=
51  ∀ φ : SchwartzMap (Euc d) ℝ,
52    Integrable (fun x => w x * φ x) ∧
53    Integrable (fun y => v y * convFun (rieszKernel d s)
54      (fun x => fderiv ℝ φ x (EuclideanSpace.single i 1)) y) ∧
55    ∫ x, w x * φ x = -∫ y, v y * convFun (rieszKernel d s)
56      (fun x => fderiv ℝ φ x (EuclideanSpace.single i 1)) y
57
58/-- The drift bounds `B:eq:drift-bounds-rd` (S L10078-10080) of the advecting drift `b^τ` on `[0,T]`:
59`b` continuous in `(τ,x)`, `C^{m+1}` in `x`, `‖∇^{⊗j}b^τ‖_∞ ≤ Cb` for `1 ≤ j ≤ m+1`,
60`|b^τ(x)| ≤ Cb (1+|x|)`. -/
61structure IsAdvectingDrift (m : ℕ) (Cb T : ℝ) (b : ℝ → Euc d → Euc d) : Prop where
62  cont : ContinuousOn (fun p : ℝ × Euc d => b p.1 p.2) (Set.Icc 0 T ×ˢ Set.univ)
63  smooth : ∀ τ ∈ Set.Icc 0 T, ContDiff ℝ (m + 1) (b τ)
64  deriv_bdd : ∀ τ ∈ Set.Icc 0 T, ∀ j : ℕ, 1 ≤ j → j ≤ m + 1 → ∀ x,
65    ‖iteratedFDeriv ℝ j (b τ) x‖ ≤ Cb
66  growth : ∀ τ ∈ Set.Icc 0 T, ∀ x, ‖b τ x‖ ≤ Cb * (1 + ‖x‖)
67
68/-- `Ψ` is the flow of `-b` on `[0,T]`: `∂_τ Ψ_τ(x) = -b^τ(Ψ_τ(x))`, `Ψ_0 = id`, each `Ψ_τ` a
69bijection (a bi-Lipschitz diffeomorphism by `B:lem:uloc-bilip`). -/
70structure IsNegDriftFlow (T : ℝ) (b : ℝ → Euc d → Euc d) (Ψ : ℝ → Euc d → Euc d) : Prop where
71  init : ∀ x, Ψ 0 x = x
72  ode : ∀ x, ∀ τ ∈ Set.Icc 0 T,
73    HasDerivWithinAt (fun τ' => Ψ τ' x) (-(b τ (Ψ τ x))) (Set.Icc 0 T) τ
74  bij : ∀ τ ∈ Set.Icc 0 T, Function.Bijective (Ψ τ)

76/-- The cutoff pair of `B:eq:advected-cutoffs` (S L10083): `χ ∈ C_c^∞(B(0,2);[0,1])` with `χ ≡ 1` on
77`B̄(0,1)` and `χ̂ ∈ C_c^∞(B(0,8);[0,1])` with `χ̂ ≡ 1` on `B̄(0,6)`. -/
78def IsCutoffPair (χ χh : Euc d → ℝ) : Prop :=
79  (ContDiff ℝ ∞ χ ∧ HasCompactSupport χ ∧ tsupport χ ⊆ Metric.ball 0 2 ∧
80    (∀ x, χ x ∈ Set.Icc (0 : ℝ) 1) ∧ ∀ x ∈ Metric.closedBall (0 : Euc d) 1, χ x = 1) ∧
81  (ContDiff ℝ ∞ χh ∧ HasCompactSupport χh ∧ tsupport χh ⊆ Metric.ball 0 8 ∧
82    (∀ x, χh x ∈ Set.Icc (0 : ℝ) 1) ∧ ∀ x ∈ Metric.closedBall (0 : Euc d) 6, χh x = 1)
83
84/-- The advected cutoff `χ_z^τ(x) = χ(Ψ_τ^{-1}(x) - z)` (`B:eq:advected-cutoffs`). -/
85def advCutoff (χ : Euc d → ℝ) (Ψ : ℝ → Euc d → Euc d) (τ : ℝ) (z : Euc d) (x : Euc d) : ℝ :=
86  χ (Function.invFun (Ψ τ) x - z)

88/-- The cell weight `ω_z = ⟨z⟩^{-(d+3)}`, `z ∈ ℤ^d` (`B:eq:screened-cell-kernel`). -/
89def cellWeight (d : ℕ) (z : Fin d → ℤ) : ℝ := jbracket (latticePt z) ^ (-((d : ℝ) + 3))

91/-- The cell `Q_{z'}^τ = Ψ_τ(z' + [0,1]^d)` of the bounded-overlap cover of `ℝ^d`
92(`B:lem:uloc-bilip`(iv), S L11013-11020; `B:lem:screened` proof, S L11336-11338). -/
93def flowCell (Ψ : ℝ → Euc d → Euc d) (τ : ℝ) (z : Fin d → ℤ) : Set (Euc d) :=
94  Ψ τ '' {y | ∀ i, 0 ≤ (y - latticePt z) i ∧ (y - latticePt z) i ≤ 1}

97def kgOrder (d : ℕ) (s : ℝ) : ℝ := max (s + 1 - d) 0

101/-- Lemma S.B.4(i) (`B:lem:screened`, `B:item:screened-far`, TeX S L11313-11326): far field and weighted
102cell kernel.  `0 ≤ s < d`, `m ≥ 0`, `μ` satisfying `S:eq:mf-regularity-whole` at level `m+3` (the
103decay part is what is used; `IsRegularDensityW (m+3) Λ μ`), an advecting drift `b` with its flow `Ψ`,
104`0 ≤ τ ≤ T`, and the cutoffs `χ_z^τ, χ̂_z^τ`.  There are nonnegative coefficients `K^τ_{zz'}`
105(`z,z' ∈ ℤ^d`) with `sup_z ∑_{z'} K^τ_{zz'} ≤ C_T`, `∑_z ω_z K^τ_{zz'} ≤ C_T ω_{z'}`
106(`B:eq:screened-cell-kernel`) such that for every `0 ≤ j ≤ m+1`, every derivative `∂^α` of order `j`
107and every `ψ`,
108`‖χ_z^τ K_g((1-χ̂_z^τ) ∂^αμ ψ)‖₂² ≤ C_T Λ² ∑_{z'} K^τ_{zz'} ‖1_{Q_{z'}^τ} ψ‖₂²` (TeX: `‖χ_{z'}^τ ψ‖₂²`, see SUSPECTED ISSUE)
109(`B:eq:screened-cell-estimate`), `K_g = ∂_i g *` (plain absolutely convergent integral on the support of
110`χ_z^τ`: integrability is part of the conclusion whenever the right side is finite).  `C_T` depends only
111on `d, s, m, Λ, Cb, T` (quantified first); `K^τ` depends on `τ` and the data but not on `j, α, ψ, i`.
112Technical hypotheses: `ψ` measurable; `Λ ≥ 0` (implied).  The cutoff pair `χ, χ̂` is fixed *before* the
113constant (TeX S L10081: the cutoffs are fixed once, `C_T` may depend on them).  The "in particular"
114clause (`LHS ≤ C_T Λ² sup_{z'} ‖ψ‖_{L²(cell z')}²`) follows from the row-sum bound and is not restated.
115SUSPECTED ISSUE (S L11322-11326, proof L11336-11346): the TeX right side is `∑_{z'} K^τ_{zz'}
116‖χ_{z'}^τ ψ‖₂²` with `χ_{z'}^τ` supported in `Ψ_τ(z'+B(0,2))`, but the proof applies Cauchy-Schwarz on the
117*cells* `Q_{z'}^τ = Ψ_τ(z'+[0,1]^d)` (S L11337-11340), which are not contained in `{χ_{z'}^τ = 1}` (the
118cube `[0,1]^d` has diameter `√d`), and for `d ≥ 16` the supports `B(z',2)`, `z' ∈ ℤ^d`, do not even cover
119`ℝ^d` (`√d/2 ≥ 2`), so the cutoff form fails (take `ψ` supported in a gap).  The statement is therefore
120drafted with what the proof proves: `‖1_{Q_{z'}^τ} ψ‖₂²` (`flowCell`) on the right.  (A lattice fine
121enough for the cutoff would also repair it.) -/

126      ∀ μ : Euc d → ℝ, IsRegularDensityW (m + 3) Λ μ →

132        ∀ (j : ℕ), j ≤ m + 1 → ∀ (idx : Fin j → Fin d) (i : Fin d) (ψ : Euc d → ℝ), Measurable ψ →
133          ∀ z : Fin d → ℤ,

236/-- Lemma S.B.4(iv), cell-sum part (`B:lem:screened`, `B:item:screened-comm`, TeX S L11331), for
237`s < d - 1` (kernels locally integrable, so the plain integrals converge absolutely): for the kernels
238`χ_z^τ(x)(χ̂_z^τ(y) - χ_z^τ(y))` and `(χ_z^τ(x) - χ_z^τ(y))` applied to `∂^αμ ψ`, the same cell estimate as

240`C(τ) = C e^{Cdτ}`.  Same hypotheses, quantifiers (the cutoff pair `χ, χ̂` is fixed first, S L10081) and
241cell convention as `screened_far` (the coefficients are those of the respective kernel; the right side
242uses the cells `Ψ_τ(z'+[0,1]^d)`, see `SUSPECTED ISSUE` there).  Both outputs are localised to the cell
243`χ_z^τ(x)` (the sup-cell bound of S L11329, as in (i)): the global `L²(dx)` norm of the commutator
244`(χ_z(x)-χ_z(y))`-operator is infinite when `2(s+1) ≤ d` (its far tail is `χ_z(y)`-weighted
