28/-- **Lemma C.6 `M:B:lem:sqrt-lipschitz`, gradient clause on `𝕋^d`** (TeX L12311-12313: "If
29`0 ≤ a ∈ C^{1,1}(𝕋^d)`, then `√a` is Lipschitz with `‖∇√a‖_{L^∞} ≤ √(‖∇^{⊗2}a‖_{L^∞}/2)`").
30
31The Lipschitz clause is `HRS.PDE.R2Aux.sqrt_isLipschitz` (torus) and `HRS.sqrt_lipschitz` (Euclidean);
32this theorem states the remaining claim `‖∇√a‖_{L^∞} ≤ √(L/2)`.  The hypotheses are exactly those of
33`sqrt_isLipschitz`: `L` is a real number with `0 ≤ L`, `a ≥ 0` everywhere, and `IsC11 L a` (`a ∈ C¹`
34with `∇a` `L`-Lipschitz on the lift, i.e. `‖∇^{⊗2}a‖_{L^∞} ≤ L`; the source quantity `‖∇^{⊗2}a‖_∞` is
35the smallest such `L`, so quantifying over all admissible `L` is equivalent and no hypothesis is
36added).  `L` and `a` are quantified before the conclusion, `0 ≤ L` is the only range restriction (it
37is forced for `IsC11 L a` to be meaningful through `Real.toNNReal`, and is needed for `√(L/2)`).
38
39Representation of `∇√a`.  `√a` is only Lipschitz, not differentiable at the zeros of `a`, so the
40gradient is the almost-everywhere gradient of the periodic lift `f = lift √a` on `ℝ^d` (Rademacher),
41which for Lipschitz `f` coincides with the weak gradient.  The conclusion has three conjuncts:
42(i) at *every* point where `f` is differentiable, `‖∇f(x)‖ ≤ √(L/2)` (operator norm of `fderiv`, equal
43to the Euclidean norm of the gradient); (ii) `f` is differentiable almost everywhere; (iii) the
44essential supremum of `‖fderiv f‖` w.r.t. Lebesgue measure on `ℝ^d` is `≤ √(L/2)`, i.e. the
45`L^∞` bound of the source (the lift is periodic, so a.e. on `ℝ^d` is a.e. on `𝕋^d`).
46
47Junk-value check.  `fderiv` is `0` where `f` is not differentiable, so (iii) alone could hold
48vacuously on the non-differentiability set; conjunct (ii) shows that set is null, hence (iii) is the
49genuine `L^∞` norm of the a.e. gradient, and (i) is stated only under `DifferentiableAt`.  No division
50(`L / 2` has a numeral denominator), `Real.sqrt` is applied to the nonnegative `a x` and `L / 2`
51(`L = 0` gives `a` constant and the bound `0`, which is correct), no measure map, no Bochner or lower
52integral, no `limUnder`, `d : ℕ` arbitrary (`d = 0` is trivial and true), `Type` levels are
53irrelevant. `eLpNormEssSup` is in `ℝ≥0∞` and the comparison uses `ENNReal.ofReal` of a nonnegative
54real. -/
55theorem torus_sqrt_gradient_le {a : Torus d → ℝ} {L : ℝ} (hL : 0 ≤ L) (ha : ∀ x, 0 ≤ a x)
56    (hC11 : PDE.IsC11 L a) :
57    (∀ x : Euc d, DifferentiableAt ℝ (Torus.lift fun y => Real.sqrt (a y)) x →
58        ‖fderiv ℝ (Torus.lift fun y => Real.sqrt (a y)) x‖ ≤ Real.sqrt (L / 2)) ∧
59    (∀ᵐ x : Euc d ∂volume, DifferentiableAt ℝ (Torus.lift fun y => Real.sqrt (a y)) x) ∧
60    eLpNormEssSup (fun x => fderiv ℝ (Torus.lift fun y => Real.sqrt (a y)) x) volume
61      ≤ ENNReal.ofReal (Real.sqrt (L / 2)) := by
62  sorry
63
64end Sqrt

72/-- Unnormalised density, with respect to `μ^{⊗n}`, of the free coordinates of
73`ℝ_{N,τ}` with `N = n + 1` after pinning coordinate `p` at the value `y`: the weight
74`pairWeight q (n+1) b μ` of the full ensemble (`b = τβ`, so `pairWeight = exp(-τβ N F_N^q)`)
75evaluated at the configuration obtained by inserting `y` at position `p` into the free
76configuration `Z`.  Its normalised version is the conditional law of the other `n` coordinates given
77the pin, and by `N:eq:weak-spec` (TeX L6177-6180) it equals, up to a constant factor, the specification
78with one-body field `τβ q*μ - (τβ/N) q(·,y)` and pair coefficient `τβ/N`. -/
79def pinnedWeight (q : Torus d → Torus d → ℝ) (μ : Measure (Torus d)) (b : ℝ) (n : ℕ)
80    (p : Fin (n + 1)) (y : Torus d) (Z : Config d n) : ℝ≥0∞ :=
81  pairWeight q (n + 1) b μ (Fin.insertNth (α := fun _ => Torus d) p y Z)
82
83/-- Unnormalised density, with respect to `μ^{⊗n}`, of the **cavity law** (TeX L6202-6204,
84"deleting one particle, while retaining the same denominator `N` in the interaction", and L6206-6209):
85`n` coordinates, pair coefficient `b/N` and one-body field `b · (q*μ)`, i.e.
86`exp(b ∑ᵢ ∫ q(Zᵢ,y) μ(dy) - (b/N) ∑_{i<j} q(Zᵢ,Zⱼ))` (the pair sum is written `½ ∑_{i≠j}`, as in
87`pairWeight`).  Here `N` is a separate parameter (in the theorem `N = n + 1`), `b = τβ`.
88`∫ q(z,y) μ(dy)` is a Bochner integral; under the row bound of the theorem it is the honest integral of
89a nonnegative integrable function. -/
90def cavityWeight (q : Torus d → Torus d → ℝ) (μ : Measure (Torus d)) (b : ℝ) (N : ℕ) {n : ℕ}
91    (Z : Config d n) : ℝ≥0∞ :=
92  ENNReal.ofReal (Real.exp (b * ∑ i, ∫ y, q (Z i) y ∂μ
93    - (b / N) * ((1 / 2) * ∑ i, ∑ j ∈ Finset.univ.erase i, q (Z i) (Z j))))
94
95/-- The two Dobrushin-type conclusions of Lemma 5.6 for a weight `W` on `n` coordinates:
96the one-coordinate conditional laws `siteKernel μ W i x` are bounded by `C μ`, and there are
97interdependence coefficients `c i j ∈ [0, κ]` with row and column sums `< 1/2` such that changing the
98`j`-th coordinate of the conditioning configuration changes the `i`-th conditional law, evaluated on any
99measurable set, by at most `c i j` (for `i ≠ j`; the diagonal coefficients are not constrained and may
100be taken `0`).  `κ` will be `C τ β a / N`. -/
101def WeakConditionalBounds (μ : Measure (Torus d)) [IsProbabilityMeasure μ] {n : ℕ}
102    (W : Config d n → ℝ≥0∞) (C κ : ℝ) : Prop :=
103  (∀ (i : Fin n) (x : Config d n), External.siteKernel μ W i x ≤ ENNReal.ofReal C • μ) ∧
104  ∃ c : Fin n → Fin n → ℝ, (∀ i j, 0 ≤ c i j ∧ c i j ≤ κ) ∧
105    (∀ i, ∑ j, c i j < 1 / 2) ∧ (∀ j, ∑ i, c i j < 1 / 2) ∧
106    ∀ i j : Fin n, i ≠ j → ∀ x y : Config d n, (∀ k, k ≠ j → x k = y k) →
107      ∀ S : Set (Torus d), MeasurableSet S →
108        |(External.siteKernel μ W i x).real S - (External.siteKernel μ W i y).real S| ≤ c i j
109
110/-- **Lemma 5.6 `M:N:lem:weak`, the pinned and cavity clause** (TeX L6156-6172: "These bounds also hold
111after one pin and for the cavity law retaining pair coefficient `τβ/N` and one-body field `τβ q*μ`";
112the proof, TeX L6174-6269, states at L6204 that "these conclusions are uniform in the pin").  "These bounds" are
113the first two sentences of the lemma: the one-coordinate conditional densities are bounded by `Cμ`, the
114interdependence coefficients are at most `C τ β a / N`, and the row and column sums are below `1/2`.
115The other clauses (`N:eq:weak-marginal`, `N:eq:weak-pi`) concern the unpinned law only and are in
116`HRS.weak_reference_estimates`.
117
118Parameters.  Everything before `∃ a₀ C` and the hypotheses on `ρ, q, a` are verbatim those of
119`HRS.weak_reference_estimates`; `a₀` and `C` are chosen after `(d, s, c_*, β_±, c₀, Λ, A)` and before
120`ρ, q, a, N, β, τ`, and in particular before the pin position `p` and pin value `y`, which are
121quantified last (uniformity in the pin).  Because every conclusion is monotone in `C` (the row/column
122sums are `< 1/2` for a witness `c` independent of `C`) and in `a₀`, the constants of this theorem and of
123`weak_reference_estimates` can be combined by taking the maximum of the `C`'s and the minimum of the
124`a₀`'s.  `N = n + 1` with `n ≥ 1` (that is, `2 ≤ N` as in `weak_reference_estimates`); the pinned ensemble
125has `n = N - 1` free coordinates and the pin is inserted at any position `p : Fin N` (`pinnedWeight`,
126whose normalised law is the conditional law of the other coordinates, derived from `pairWeight` itself,
127not from a transcribed formula); the cavity ensemble has the same `n = N - 1` free coordinates, the pair
128coefficient `τβ/N` with the original denominator `N = n + 1`, and the one-body field `τβ q*μ`
129(`cavityWeight`).  The coefficient bound is `C τ β a / (n+1)` and the conditional density bound is `C μ`,
130exactly as in the unpinned statement; the "row and column sums below `1/2`" are stated as a witness
131matrix `c` of coefficients (`WeakConditionalBounds`) instead of the proxy `C τ β a < 1/2` used in the
132unpinned Lean statement.
133
134Junk-value check.  `1/2` and `a / (n+1)` have nonzero denominators (`n ≥ 1`).  `siteKernel μ W i` is a
135`Kernel.withDensity`, which is `0` for a non-measurable density; here the density is
136`z ↦ W (update x i z) * (∫⁻ W (update x i ·) dμ)⁻¹`, and `W` is measurable (`q` measurable, and the
137row integral `x ↦ ∫ q(x,y) dμ(y)` of a measurable nonnegative kernel is measurable), the normaliser is
138positive (the weights are `ofReal exp > 0`) and finite (the exponent is bounded above, using `q ≥ 0`
139and the row bound), so the kernel is the true conditional law, not a junk value.  The row integral in
140`cavityWeight` is a Bochner integral of a nonnegative function with `∫⁻ ofReal q ≤ ofReal a < ∞`
141(hypothesis `hrow`), hence integrable.  No `Measure.map` of a non-measurable map occurs (the
142bounds are about the kernels, not marginals), no lower integral, no `limUnder`.  `τ = 0` is allowed:
143all weights are then constant, every kernel equals `μ`, and the bounds hold with `c = 0`.
144`β ∈ [βm, βp]` with `βm > 0` (so `β > 0`).  `Type` universe: all spaces are `Torus d`.
145`IsProbabilityMeasure (withDensityReal ρ)` is a hypothesis (as in the unpinned statement), which
146makes `siteKernel` available. -/
147theorem weak_reference_pinned_cavity (hd : 1 ≤ d) (s : ℝ) (hs0 : 0 ≤ s) (hsd : s < d)
148    (cstar : ℝ) (hw : ∀ z : Torus d, z ≠ 0 → 1 ≤ periodicRiesz d s z + cstar)
149    (βm βp : ℝ) (hβm : 0 < βm) (c₀ : ℝ) (hc₀ : 0 < c₀) (Λ : ℕ → ℝ) (A : ℝ) :
150    ∃ a₀ C : ℝ, 0 < a₀ ∧
151      ∀ ρ : Torus d → ℝ, IsProbDensity ρ → ∀ [IsProbabilityMeasure (withDensityReal ρ)],
152        Torus.IsSmooth ρ → (∀ x, c₀ ≤ ρ x) →
153        (∀ k : ℕ, Torus.cbNorm k ρ ≤ Λ k) →
154      ∀ q : Torus d → Torus d → ℝ, Measurable (Function.uncurry q) → (∀ x y, q x y = q y x) →
155        (∀ x y, 0 ≤ q x y) → (∀ x y, q x y ≤ A * (periodicRiesz d s (x - y) + cstar)) →
156      ∀ a : ℝ, 0 ≤ a → a < a₀ →
157        (∀ x, ∫⁻ y, ENNReal.ofReal (q x y) ∂(withDensityReal ρ) ≤ ENNReal.ofReal a) →
158      ∀ n : ℕ, 1 ≤ n → ∀ β ∈ Set.Icc βm βp, ∀ τ ∈ Set.Icc (0 : ℝ) 1,
159        (∀ (p : Fin (n + 1)) (y : Torus d),
160          WeakConditionalBounds (withDensityReal ρ)
161            (pinnedWeight q (withDensityReal ρ) (τ * β) n p y) C (C * τ * β * a / ((n + 1 : ℕ) : ℝ))) ∧
162        WeakConditionalBounds (withDensityReal ρ)
163          (cavityWeight q (withDensityReal ρ) (τ * β) (n + 1) (n := n)) C
164          (C * τ * β * a / ((n + 1 : ℕ) : ℝ)) := by
165  sorry
166
167end Weak
