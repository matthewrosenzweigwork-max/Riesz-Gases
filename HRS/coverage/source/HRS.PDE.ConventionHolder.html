24/-- The force `∇g * μ` of `B:eq:nabla-g-convolution` (M L10091-10093) **literally as printed**:
25two separate integrals, the increment integral over the Euclidean ball `|x-y| ≤ 1/4` (here
26`tdist x y`, the norm of the centred representative of `x-y`) and the far-field integral over
27`|x-y| > 1/4` against `dμ(y) = ρ(y) dy`.  (`HRS.convGradConv` is the same thing with the sup-norm
28cube `‖x-y‖ ≤ 1/4` and a single integral.) -/
29def convGradHolder (G : Torus d → Euc d) (ρ : Torus d → ℝ) (x : Torus d) : Euc d :=
30  (∫ y, if Torus.tdist x y ≤ 1 / 4 then (ρ y - ρ x) • G (x - y) else 0) +
31    ∫ y, if 1 / 4 < Torus.tdist x y then ρ y • G (x - y) else 0
32
33/-- **The cube convention equals the printed ball convention** (M L10091-10096, "the subtracted
34constant contributes zero by oddness").  For a measurable odd kernel `G` with the order
35`|z|^{-s-1}` bound (`KernelGrad.GoodKernel`), a bounded measurable density `ρ`, and a point `x` at
36which the near-field increment integral of the printed formula converges, the printed two-integral
37formula equals `HRS.convGradConv`.  The convergence hypothesis is necessary: otherwise the printed
38first integral is the junk `0`. -/
39theorem convGradConv_eq_convGradHolder {s C : ℝ} {G : Torus d → Euc d}
40    (hG : KernelGrad.GoodKernel d s C G) {ρ : Torus d → ℝ} (hρm : Measurable ρ)
41    (hρb : ∃ B, ∀ y, |ρ y| ≤ B) (x : Torus d)
42    (hint : Integrable (fun y => if Torus.tdist x y ≤ 1 / 4 then (ρ y - ρ x) • G (x - y) else 0)) :
43    convGradConv G ρ x = convGradHolder G ρ x := by

46/-- **Well-definedness for Hölder densities** (M L10089-10097: "defined for `μ ∈ C^{0,α}`,
47`α > s+1-d` ... Near the origin, the Hölder increment makes the integrand locally integrable
48precisely when `α > s+1-d`"; sufficiency direction).  For `0 ≤ s < d`, `0 < α ≤ 1`,
49`α > s+1-d` and `ρ ∈ C^{0,α}` the integrand of the cancellation convolution is integrable, so
50the Bochner integral in `convGradConv` is not a junk value.  (Hölder is with respect to the
51torus norm, as in `MFHolder.Hol0`.) -/
52theorem integrable_convGradConv_integrand_of_holder {s α : ℝ} (hd : 1 ≤ d) (hs0 : 0 ≤ s)
53    (hsd : s < d) (hα0 : 0 < α) (hα1 : α ≤ 1) (hα : s + 1 - d < α) {ρ : Torus d → ℝ}
54    (hρ : PDE.MFHolder.Hol0 α ρ) (x : Torus d) :
55    Integrable (fun y => if ‖x - y‖ ≤ 1 / 4 then (ρ y - ρ x) • periodicRieszGrad d s (x - y)
56      else ρ y • periodicRieszGrad d s (x - y)) := by
57  sorry

59/-- **Agreement with distributional convolution for Hölder densities** (M L10098-10101: "The
60formula is therefore well defined and agrees with distributional convolution").  For
61`0 ≤ s < d`, `0 < α ≤ 1`, `α > s+1-d` and `ρ ∈ C^{0,α}`, the Fourier coefficients of the `i`-th
62component of `∇g * ρ` (cancellation convention) are `2πi k_i ĝ(k) ρ̂(k)` (`PDE.gradRieszCoeff`).
63This extends `PDE.convGradConv_coeff_of_one_le` from `ρ ∈ C¹` to the Hölder class actually used
64in the printed definition (needed for `s ≥ d-1`, where `C¹` is stronger than the source). -/
