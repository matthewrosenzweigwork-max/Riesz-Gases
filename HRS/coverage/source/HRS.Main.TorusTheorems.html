23## Shape of the statements
24
25* **Constants.**  "There exist `C, Λ_T > 0` depending only on `d, s, |M|, Λ, T, ‖V‖, C_in` (and `ν₀`)"
26  is `∃ C ΛT, 0 < C ∧ 0 < ΛT ∧ ∀ S R …` placed *after* the bounds `(d, s, Rg, ν₀, MB, Λ, T, VB, Cin,
27  C₀, Cc)` and *before* the data `S, R` (so the constants cannot depend on `M, V, κ_N, β_N, ρ_N`, on
28  the sequences `ε_N, 𝔈_N`, nor on the realization).  Dependence on the regime `Rg` (including `λ₀`
29  of R2b) and on the completion pair `(C₀, Cc)` (which depends only on `d, s`) is explicit.
30* "for every `t ∈ [0,T]` and `N ≥ C`" is `t ∈ Icc 0 T` and `C ≤ (N : ℝ)` (`C > 0` forces `N ≥ 1`).
31* The finite family of tests and times on which the initial coupling may depend (A.4) is
32  quantified *before* the realization-dependent hypothesis `InitialFluctuation …` (the realization `R`
33  is quantified before the family but `InitialFluctuation` is imposed for the family), and the
34  conclusion is stated for that family.
35* One real statistic `⟨φ,σ_NΞ_N^t⟩` is the case `ι = Fin 1` (`ℝ^1` and `ℝ` are isometric).  Complex
36  tests are `ι = Fin (n+1) × Bool` (real and imaginary parts), the statistics being viewed in `ℝ^{2p}`;
37  the `H^m` norm of a complex test is `sobolevNormC`.
38* Laws of the linear approximations are the explicit measures of `HRS/Main/Linearization.lean`.

54/-- The transported terminal tests `{U_N^{0,t_a} φ_a}` of the finite family `(φ_a, t_a)` (the
55generators of the finite-dimensional span in A.4, TeX L10208). -/
56def transportedTests (S : MainData d) {ι : Type*} (ts : ι → ℝ) (φ : ι → Torus d → ℝ) (N : ℕ) :
57    Set (Torus d → ℝ) :=
58  Set.range fun a => propagator (S.dyn N) (S.ρ N) 0 (ts a) (φ a)

60/-- A complex test lies in `H^m` iff its real and imaginary parts do. -/
61def MemSobolevC (m : ℝ) (φ : Torus d → ℂ) : Prop :=
62  MemSobolev m (fun x => (φ x).re) ∧ MemSobolev m (fun x => (φ x).im)
63
64/-- The `H^m` norm of a complex test, `‖φ‖²_{H^m} = ‖Re φ‖²_{H^m} + ‖Im φ‖²_{H^m}`
65(`∑_k ⟨k⟩^{2m}|φ̂(k)|²` for `φ = u + iv` with `u, v` real). -/
66def sobolevNormC (m : ℝ) (φ : Torus d → ℂ) : ℝ :=
67  Real.sqrt (sobolevNorm m (fun x => (φ x).re) ^ 2 + sobolevNorm m (fun x => (φ x).im) ^ 2)
68
69/-- The real family `(Re φ_a, Im φ_a)` indexed by `ι × Bool` of a complex family: the statistics of
70complex tests "viewed in `ℝ^{2p}`" (A.8 (c), L10310). -/
71def realImParts {ι : Type*} (φ : ι → Torus d → ℂ) : ι × Bool → Torus d → ℝ :=
72  fun ab x => if ab.2 then (φ ab.1 x).im else (φ ab.1 x).re

74/-- The rates `𝔯_N` and `𝔯'_N` of `B:eq:master-rate` (TeX L10299, L10315):
75`ε + (σ²/(Nβ))^{1/2} (𝔈^{1/4} + N^{-1/(2d)}) + σ E`, with `q = σ²/(Nβ)`, `E = 𝔈_N` (`𝔯_N`, `ε = ε_N`)
76or `E = 𝔈'_N` (`𝔯'_N`, `ε = ε_N^{(2)}`). -/
77def masterRate (d : ℕ) (ε q σ 𝔈 E : ℝ) (N : ℕ) : ℝ :=
78  ε + Real.sqrt q * (𝔈 ^ ((1 : ℝ) / 4) + (N : ℝ) ^ (-(1 : ℝ) / (2 * d))) + σ * E
79
80/-- The rate of `B:eq:thm-torus-field` (TeX L10339-10341):
81`ε^f + σ 𝔈 + (σ²/(Nβ)) (𝔈^{1/2} + N^{-1/d})`. -/
82def fieldRate (d : ℕ) (εf q σ 𝔈 : ℝ) (N : ℕ) : ℝ :=
83  εf + σ * 𝔈 + q * (𝔈 ^ ((1 : ℝ) / 2) + (N : ℝ) ^ (-(1 : ℝ) / d))
84
85/-- The right-hand side `C e^{Λ_T t} X (1 + X) r` of the statistics bounds
86(`B:eq:thm-torus-w1`, `B:eq:thm-torus-dc2`, `B:eq:thm-torus-joint-w2`), `X = ‖φ‖` or `∑_a ‖φ_a‖`. -/
87def statBound (C ΛT t X r : ℝ) : ℝ := C * Real.exp (ΛT * t) * X * (1 + X) * r
