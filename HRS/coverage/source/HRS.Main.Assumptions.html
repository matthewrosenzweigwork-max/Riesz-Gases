22## Representation decisions (all checked by the orchestrator against the TeX)
23
24* **Sequences.**  The TeX works with a sequence in `N` of coefficients and of particle systems.  The
25  deterministic data (`d, s, M, V, T, μ°, β_N⁻¹, κ_N`, and the mean-field solutions `μ_{β_N}`) is the
26  structure `MainData`; the random data at particle number `N` (probability space, `X_N^0`, the
27  Brownian motions, the particle flow `X_N`, and the initial fluctuation functional `η°`) is the
28  structure `Realization d N`, and a sequence is `R : ∀ N, Realization d N` (the probability space
29  may depend on `N`, as the couplings do).  Every per-`N` assumption is imposed for `1 ≤ N` only
30  (for `N = 0` the empirical measure is the zero measure and the assumptions could not hold).
31* `β_N = ∞` is `invβ N = 0` (`DynData`), exactly as in `HRS/Dynamics/Setup.lean`.
32* **`η°`** is a *random real-linear functional on `Y_0 = H^{m_0}`* (A.4, "random real-linear functional
33  `η°` on the test class `Y_0`"): `Realization.η : Ω → (Torus d → ℝ) → ℝ`, jointly measurable (the
34  product σ-algebra), real-linear on `{ψ | MemSobolev m₀ ψ}`.  It is *not* an element of
35  `NegSobolev d m₀`, because `m₀ ≤ m_*` may be `≤ d/2`.  In the field-level assumption A.5 the
36  same `η°` is `H^{-γ}`-valued: `ηF : Ω → NegSobolev d γ` with `η ω ψ = eval (ηF ω) ψ` for mean-zero
37  `ψ ∈ H^γ` (the project's zero-total-mass convention `E_γ = H^{-γ}_0`; the zero mode of `η°` is not
38  recorded, as `⟨1, Ξ_N⟩ = 0`).
39* **Expectations** of possibly non-integrable quantities are `lintegral`s of `ENNReal.ofReal`
40  (as in `HRS/Dynamics/InitialData.lean`), so that no junk Bochner value can make a bound vacuous.
41* **`o_N(Λ)`** of A.6 is `HRS.oNΛ d s C₀ Λ N` (`B:eq:hrs-coercivity-exact-correction`, L2882) with a
42  completion constant `C₀` as in Proposition 3.34 (`IsCoercivityPair`); the corrected energy is
43  `HRS.correctedEnergy`.

132/-- Assumption A.1 `M:B:ass:sde` (TeX L10127-10143), selected empirical semimartingale flow at one
133`N`: `X_N^0` is a.s. pairwise distinct and independent of `(W_i)`, and the flow is one of
134(a)/(d) the pathwise unique collision-free strong solution (the TeX cases (a) "its canonical
135collision-free strong solution" and (d) "a pathwise unique collision-free strong solution has been
136selected" are the same notion and collapse into one disjunct, as in `HRS.SelectedFlow`),
137(b) `d = 1`, `s = 0`, `β_N < ∞`, `M = -a` (`a > 0`): the Cépa–Lépingle flow,
138(c) `d = 1`, `s = 0`, `β_N < ∞`, `M = 0`: the ordinary system of independent confined diffusions
139(a contact-allowing strong solution; with `M = 0` the drift has no singular term).
140This extends `HRS.SelectedFlow`, which omits case (c) (`M = 0`, L10132); the law `P_N^t` and the
141density `f_N^t` of `B:eq:selected-particle-law` are `HRS.selectedLaw`, `HRS.HasSelectedDensity`,
142`HRS.selectedDensity`. -/
143structure SelectedFlowA1 {Ω : Type*} [MeasurableSpace Ω] {N : ℕ} (P : Measure Ω) (D : DynData d)
144    (T : ℝ) (X₀ : Ω → Config d N) (W : ℝ≥0 → Ω → (Fin N → Euc d))
145    (X : ℝ≥0 → Ω → Config d N) : Prop where
146  init_meas : Measurable X₀
147  init_distinct : ∀ᵐ ω ∂P, X₀ ω ∉ collisionSet d N
148  brownian : IsVectorBrownian P W
149  indep : IndepFun X₀ (fun ω => fun t => W t ω) P
150  flow :
151    (IsStrongSolution P D T X₀ W X ∧ PathwiseUnique P D T X₀ W) ∨
152    (d = 1 ∧ D.s = 0 ∧ 0 < D.invβ ∧ (∃ a : ℝ, 0 < a ∧ D.M = -(a • 1)) ∧
153      IsCepaLepingleFlow P D T X₀ W X) ∨
154    (d = 1 ∧ D.s = 0 ∧ 0 < D.invβ ∧ D.M = 0 ∧ IsContactStrongSolution P D T X₀ W X)

189times of the conclusion enters through the sets `Ψ N` of *transported terminal tests* (the
190finite-dimensional span in L10208; for the pair `(φ,t)` the transported test is `U_N^{0,t}φ`,
191see `transportedTests`), and the coupling `(X_N^0, η°)` (the realization `R`) may depend on this
192family.  Data: `m₀ ∈ {1,…,m_*}` (`Y_0 = Y_0' = H^{m₀}`, norm `sobolevNorm m₀`), `C_in ≥ 1`,
193`ε_N ↓ 0` (hence `ε_N ≥ 0`).  `η°` is a random real-linear functional on `Y_0`, one functional of
194fixed law (`fixed_law`); only the coupling depends on `N`.

253/-! ### Assumptions A.6, A.7 (modulated-energy smallness) -/
254
255/-- `C₀` is a valid heat-kernel completion constant with coercivity constant `C` for the torus
256Riesz energy: the conclusion of Proposition 3.34 (`HRS.periodic_coercivity`, TeX L2879-2897) holds
257with `(C₀, C)`: `F_N(X,μ) + o_N(Λ) ≥ 0` and the linear-statistic bound, for all `Λ ≥ 1`, `N ≥ 2`,
258densities `μ ≤ Λ`, collision-free `X`.  This is "`C₀` as in `H:eq:energy-completion`" (TeX L546-555,
259with the `Λ`-dependent correction `B:eq:hrs-coercivity-exact-correction`); `C₀` and `C` depend only
260on `d, s`, so the constants of the theorems may depend on them. -/
261def IsCoercivityPair (d : ℕ) (s C₀ C : ℝ) : Prop :=
262  0 ≤ C₀ ∧ 0 < C ∧
263    ∀ (Λ : ℝ), 1 ≤ Λ → ∀ (N : ℕ), 2 ≤ N →
264    ∀ ρ : Torus d → ℝ, IsProbDensity ρ → (∀ x, ρ x ≤ Λ) →
265    ∀ X : Config d N, X ∉ collisionSet d N →
266      0 ≤ rieszEnergy d s X (withDensityReal ρ) + oNΛ d s C₀ Λ N ∧
267      ∀ (ψ : Torus d → ℝ) (L : ℝ), 0 ≤ L → KernelGrad.IsLipschitz L ψ →
268        HasFiniteHomSobolev (((d : ℝ) - s) / 2) ψ →
269        |∫ x, ψ x ∂(empirical X) - ∫ x, ψ x ∂(withDensityReal ρ)| ≤
270          C * smearScale d N Λ * L +
271            C * homSobolev (((d : ℝ) - s) / 2) ψ *
272              Real.sqrt (rieszEnergy d s X (withDensityReal ρ) + oNΛ d s C₀ Λ N)

275theorem exists_coercivityPair (hd : 1 ≤ d) {s : ℝ} (hs0 : 0 ≤ s) (hsd : s < d) :

280/-- Assumption A.6 `M:B:ass:MF` (TeX L10235-10247): with `𝔬_N(Λ) = HRS.oNΛ d s C₀ Λ N` (a completion

344/-! ### Convergence of the coefficients (`B:eq:deltaN`) -/
345
346/-- The limiting coefficient quadruple `(β_∞, μ_{β_∞}, A, 2/β_*)` of TeX L10285-10290 (`invβ = β_∞⁻¹`,
347`invβstar = β_*⁻¹`, so the limiting noise covariance is `2 β_*⁻¹ ∫ ...`). -/
348structure LimitCoeffs (d : ℕ) where
349  invβ : ℝ
350  hinvβ : 0 ≤ invβ
351  ρ : ℝ → Torus d → ℝ
352  A : ℝ
353  hA : 0 ≤ A
354  invβstar : ℝ
355  hinvβstar : 0 ≤ invβstar
356
357/-- The limiting dynamics data. -/
358def LimitCoeffs.dyn (L : LimitCoeffs d) (S : MainData d) : DynData d :=
359  ⟨S.s, S.M, S.V, L.invβ, S.hs0, S.hsd, L.hinvβ⟩
360
361/-- The full coefficient discrepancy `Δ_N^{(m)}` of `B:eq:deltaN` (TeX L10412-10418):
362`|β_N⁻¹ - β_∞⁻¹| + |2σ_N²/(Nβ_N) - 2/β_*| + |A_N - A| + sup_{r ≤ T} ‖μ_{β_N}^r - μ_{β_∞}^r‖_{𝒞^{m+2}}`
363with the coefficient norm `𝒞^{m+2}` of Proposition 3.15 (`Torus.cbNorm (m+2)`, as in
364`HRS.PDE.propagator_stability`). -/
365def MainData.coeffDiscrepancy (S : MainData d) (L : LimitCoeffs d) (m N : ℕ) : ℝ :=
366  |S.invβ N - L.invβ| + |2 * S.qN N - 2 * L.invβstar| + |S.AN N - L.A| +
367    ⨆ r : Set.Icc (0 : ℝ) S.T, Torus.cbNorm (m + 2) (S.ρ N r - L.ρ r)
368
369/-- "Assume common adjoint regimes and constants and `Δ_N^{(m)} → 0`" (`B:cor:true-limit`,
370TeX L10420-10421): the limit trajectory `μ_{β_∞}` solves the mean-field equation with viscosity
371`β_∞⁻¹` and datum `μ°`, and the adjoint hypotheses of Proposition 3.9 (`HRS.PDE.AdjointData`: same
372regime `Rg`, same `ν₀, MB, Λ, VB`, same `M, V`) hold at the level `lvl` for the limit and for every
373`N`; and `Δ_N^{(m)} → 0`.  (The level `lvl` of the common adjoint regime is not specified by the TeX:
374the theorems use `lvl = m` (A.9) or `lvl = m + 2` (A.11), the level of their own regularity
375hypothesis.) -/
376structure CoeffConvergence (S : MainData d) (L : LimitCoeffs d) (Rg : PDE.Regime)
377    (ν₀ MB Λ VB : ℝ) (lvl m : ℕ) : Prop where
378  limit_solution : IsMeanFieldSolution (L.dyn S) S.T L.ρ
379  limit_datum : withDensityReal (L.ρ 0) = S.μ0
380  limit_adjoint : PDE.AdjointData S.s lvl Rg MB Λ VB (L.dyn S) ν₀ S.T L.ρ
381  seq_adjoint : ∀ N : ℕ, 1 ≤ N → PDE.AdjointData S.s lvl Rg MB Λ VB (S.dyn N) ν₀ S.T (S.ρ N)
382  tendsto : Tendsto (fun N => S.coeffDiscrepancy L m N) atTop (𝓝 0)
