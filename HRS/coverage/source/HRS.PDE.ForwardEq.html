4# Torus PDE layer III: the forward adjoint equation in Fourier form, its solution concept,
5the coefficient hypothesis, and the adjoint regimes
6
7Sources (HRS periodic main paper, Section 3.2 `B:sec:adjoint-torus`, lines 1711–1738):
8* backward problem `B:eq:adjoint-backward` (1715–1717), forward problem after `F(τ) := f(t-τ)`
9  `B:eq:adjoint-forward` (1719–1721): `∂_τ F = νΔF + b^τ·∇F - 𝒢^τ[F]`, `F(0) = φ`, with
10  `ν = β⁻¹ ∈ [0,∞)`, `b^τ = M∇g*μ^{t-τ} - ∇V`, and `𝒢^τ[F] = Div g*(μ^{t-τ} M^*∇F)
11  = ∑_{i,j} M^*_{ij} ∂_i g*(μ^{t-τ} ∂_j F)` (`B:eq:G-def`, 1723–1725);
12* standing coefficient hypothesis `B:eq:coeff-hypothesis` (1727–1729):
13  `μ ∈ C([0,T]; 𝒫(𝕋^d))`, `sup_{[0,T]} ‖μ^r‖_{C^{m+3}} ≤ Λ`, `V ∈ C^{m+3}`;
14* constants depend only on `(d, s, m, |M|, Λ, ‖V‖_{C^{m+3}})` and, where indicated, on `lam0`
15  or `ν₀`; never on `t ∈ [0,T]`, `β`, or `φ` (1730);
16* `θ = s + 2 - d` (1732); Assumption A.2 `B:ass:regime` (10168–10180): regimes R1, R2a, R2b,
17  R2c, R3; `Λ_m` of `B:eq:LambdaM` (1745–1750).
18
19## Representation decisions (SPEC_NOTES §1–2)
20
21* All operators act on coefficient sequences through the multipliers of `HRS/PDE/Fourier.lean`
22  (`forwardGen`).  For `F ∈ H^1` and `μ ∈ C^{m+3}` every term is an absolutely convergent
23  coefficient (`summable_mulCoeff`).
24* "`F` solves `B:eq:adjoint-forward` in the distributional sense with `F(0) = φ`" is represented
25  coefficientwise by the integrated equation `F̂(τ,k) = φc(k) + ∫_0^τ (𝓛^σ F(σ))^(k) dσ` for every
26  `k` and `τ ∈ [0,t]`, with the integrand integrable in `σ` (`IsForwardSolution`).  On the torus this
27  is equivalent to the distributional formulation (test with `η(τ) e_{-k}(x)`; trigonometric
28  polynomials are dense), see SPEC_NOTES §1.  `C_w([0,t];H^m)` and `C([0,t];H^{m'})` are the
29  predicates `WeakContinuousInHs`, `ContinuousInHs` of `Fourier.lean`.
30* The dependence on `|M|` and `‖V‖_{C^{m+3}}` is expressed through bounds (`MB`, `VB`), the regime
31  (including `lam0` in R2b) is a parameter placed before the constant, and `ν₀` (R3) is quantified
32  after it since its dependence is displayed in `Λ_m` (`Regime.lambdaM`).
33-/

47/-! ### The forward generator in Fourier form -/
48
49/-- Coefficients of the `j`-th component of the drift `b = M∇g*ρ - ∇V` (line 1722):
50`b̂_j(k) = ∑_i M_{ji} 2πi k_i ĝ(k) ρ̂(k) - 2πi k_j V̂(k)`. -/
51def driftCoeff (D : DynData d) (ρ : Torus d → ℝ) (j : Fin d) : Coeff d :=
52  fun k => (∑ i : Fin d, ((D.M j i : ℝ) : ℂ) * gradRieszCoeff d D.s i (coeffOf ρ) k) -
53    derivCoeff j (coeffOf D.V) k
54
55/-- Coefficients of the transport term `b·∇F = ∑_j b_j ∂_j F`. -/
56def transportCoeff (D : DynData d) (ρ : Torus d → ℝ) (F : Coeff d) : Coeff d :=
57  fun k => ∑ j : Fin d, mulCoeff (driftCoeff D ρ j) (derivCoeff j F) k
58
59/-- Coefficients of the nonlocal term `𝒢[F] = ∑_{i,j} M^*_{ij} ∂_i g*(ρ ∂_j F)`, `M^* = Mᵀ`
60(`B:eq:G-def`, lines 1723–1725): `∑_{i,j} M_{ji} · 2πi k_i ĝ(k) · (ρ ∂_jF)^(k)`. -/
61def nonlocalCoeff (D : DynData d) (ρ : Torus d → ℝ) (F : Coeff d) : Coeff d :=
62  fun k => ∑ i : Fin d, ∑ j : Fin d, ((D.M j i : ℝ) : ℂ) *
63    gradRieszCoeff d D.s i (mulCoeff (coeffOf ρ) (derivCoeff j F)) k
64
65/-- The forward generator `𝓛 F = νΔF + b·∇F - 𝒢[F]` of `B:eq:adjoint-forward` (line 1720) at a
66frozen density `ρ` (`= μ^{t-τ}`), in Fourier form, `ν = D.invβ`. -/
67def forwardGen (D : DynData d) (ρ : Torus d → ℝ) (F : Coeff d) : Coeff d :=
68  fun k => ((D.invβ : ℝ) : ℂ) * laplaceCoeff F k + transportCoeff D ρ F k - nonlocalCoeff D ρ F k

70/-! ### The solution concept -/
71
72/-- `F` solves `B:eq:adjoint-forward` on `[0,t]` with datum `φc` and coefficient path
73`σ ↦ μ^{t-σ}`, in the integrated coefficient form (distributional sense; SPEC_NOTES §1):
74`F(τ) ∈ H^1` for `τ ∈ [0,t]`, and for every `k`,
75`F̂(τ,k) = φc(k) + ∫_0^τ (𝓛^σ F(σ))^(k) dσ` with an integrable integrand. -/
76structure IsForwardSolution (D : DynData d) (μ : ℝ → Torus d → ℝ) (t : ℝ) (φc : Coeff d)
77    (F : ℝ → Coeff d) : Prop where
78  h1 : ∀ τ ∈ Set.Icc 0 t, MemHs 1 (F τ)
79  integrable : ∀ k, IntegrableOn (fun σ => forwardGen D (μ (t - σ)) (F σ) k) (Set.Icc 0 t)
80  eq : ∀ k, ∀ τ ∈ Set.Icc 0 t,
81    F τ k = φc k + ∫ σ in (0 : ℝ)..τ, forwardGen D (μ (t - σ)) (F σ) k

83open Classical in
84/-- The forward solution operator at level `m`: the unique `F ∈ C_w([0,t];H^m)` solving the forward
85equation with datum `φc` (Proposition 3.9), `0` if there is none.  `U^{r,t} φ` corresponds to
86`propagatorCoeff D μ m t φc (t - r)`. -/
87def propagatorCoeff (D : DynData d) (μ : ℝ → Torus d → ℝ) (m : ℝ) (t : ℝ) (φc : Coeff d) :
88    ℝ → Coeff d :=
89  if h : ∃ F, IsForwardSolution D μ t φc F ∧ WeakContinuousInHs m F t then h.choose
90  else fun _ => 0

92/-! ### The coefficient hypothesis `B:eq:coeff-hypothesis` -/
93
94/-- `B:eq:coeff-hypothesis` (lines 1727–1729) for the density path: `μ^r` is a probability density
95of class `C^{m+3}` with `‖μ^r‖_{C^{m+3}} ≤ Λ` for `r ∈ [0,T]`, and `r ↦ μ^r` is continuous into
96`𝒫(𝕋^d)` (weakly, i.e. against continuous tests).  (The source's `C^{m+3}` norm is the max over
97orders, `cbNorm` is the sum: equivalent up to the factor `m+4`, ISSUES §M3.)  The hypothesis on `V`
98(`V ∈ C^{m+3}`) is carried separately by the theorems. -/
99structure CoeffHyp (m : ℕ) (Λ T : ℝ) (μ : ℝ → Torus d → ℝ) : Prop where
100  prob : ∀ r ∈ Set.Icc 0 T, IsProbDensity (μ r)
101  smooth : ∀ r ∈ Set.Icc 0 T, Torus.IsCk (m + 3) (μ r)
102  bound : ∀ r ∈ Set.Icc 0 T, Torus.cbNorm (m + 3) (μ r) ≤ Λ
103  cont : ∀ ψ : Torus d → ℝ, Continuous ψ →
104    ContinuousOn (fun r => ∫ x, ψ x * μ r x) (Set.Icc 0 T)
105
106/-- The hypotheses on `V` of `B:eq:coeff-hypothesis`: `V ∈ C^{m+3}` with `‖V‖_{C^{m+3}} ≤ VB`. -/
107def VHyp (m : ℕ) (VB : ℝ) (V : Torus d → ℝ) : Prop :=
108  Torus.IsCk (m + 3) V ∧ Torus.cbNorm (m + 3) V ≤ VB

113/-! ### Assumption A.2 `B:ass:regime` (lines 10168–10180) and `Λ_m` -/
114
115/-- The adjoint regimes of Assumption A.2.  `R2b` carries its lower bound `lam0` (constants may
116depend on it, line 1730); the `ν₀` of `R3` is a separate argument of `Regime.Holds`. -/
117inductive Regime
118  | R1
119  | R2a
120  | R2b (lam0 : ℝ)
121  | R2c
122  | R3
123
124/-- The conditions of each regime (Assumption A.2, lines 10171–10178), for a single trajectory
125`μ` on `[0,T]`, with `θ = s+2-d`:
126* R1: `0 ≤ s ≤ d-2`, `M` arbitrary, `β ∈ (0,∞]` arbitrary;
127* R2 (`d-2 < s < d`, `S = ½(M+Mᵀ) ≤ 0`, `β` arbitrary) and one of
128  R2a: `M` antisymmetric (`S = 0`); R2b: `inf_{[0,T]×𝕋^d} μ ≥ lam0 > 0`; R2c: `s ≤ d-1` (`θ ≤ 1`),
129  no positivity condition;
130* R3: `d-2 < s < d`, `M` arbitrary, `ν = β⁻¹ ≥ ν₀ > 0`.
131(`0 ≤ s < d` is a standing hypothesis of the theorems.) -/
132def Regime.Holds (R : Regime) (d : ℕ) (s : ℝ) (M : Matrix (Fin d) (Fin d) ℝ) (invβ ν₀ T : ℝ)
133    (μ : ℝ → Torus d → ℝ) : Prop :=
134  match R with
135  | .R1 => s ≤ (d : ℝ) - 2
136  | .R2a => (d : ℝ) - 2 < s ∧ Torus.symPart M = 0
137  | .R2b lam0 => (d : ℝ) - 2 < s ∧ Torus.SymNonpos M ∧ 0 < lam0 ∧
138      ∀ r ∈ Set.Icc 0 T, ∀ x, lam0 ≤ μ r x
139  | .R2c => (d : ℝ) - 2 < s ∧ s ≤ (d : ℝ) - 1 ∧ Torus.SymNonpos M
140  | .R3 => (d : ℝ) - 2 < s ∧ 0 < ν₀ ∧ ν₀ ≤ invβ
141
142/-- Whether the regime is one of the R2 cases (where the weighted dissipation of
143`B:eq:energy-torus` is retained). -/
144def Regime.IsR2 : Regime → Prop
145  | .R1 => False
146  | .R2a => True
147  | .R2b _ => True
148  | .R2c => True
149  | .R3 => False
150
151instance (R : Regime) : Decidable R.IsR2 := by cases R <;> simp only [Regime.IsR2] <;> infer_instance
152
153/-- `Λ_m` of `B:eq:LambdaM` (lines 1745–1750): `C` in regimes R1 and R2 (uniformly in
154`β ∈ (0,∞]`), `C(1 + ν₀^{-θ/(2-θ)})` in regime R3. -/
155def Regime.lambdaM (R : Regime) (C ν₀ θ : ℝ) : ℝ :=
156  match R with
157  | .R3 => C * (1 + ν₀ ^ (-(θ / (2 - θ))))
158  | _ => C

160/-- The full hypothesis package of Proposition 3.9 for the data `(D, μ)` at level `m` on `[0,T]`
161(everything after the constant quantifier): `D.s = s`, the entrywise bound on `M`, `V ∈ C^{m+3}`
162with norm bound, the coefficient hypothesis, and the regime. -/
163structure AdjointData (s : ℝ) (m : ℕ) (R : Regime) (MB Λ VB : ℝ) (D : DynData d) (ν₀ T : ℝ)
164    (μ : ℝ → Torus d → ℝ) : Prop where
165  hs : D.s = s
166  hM : MatBound MB D.M
167  hV : VHyp m VB D.V
168  hμ : CoeffHyp m Λ T μ
169  hT : 0 < T
170  regime : R.Holds d s D.M D.invβ ν₀ T μ
