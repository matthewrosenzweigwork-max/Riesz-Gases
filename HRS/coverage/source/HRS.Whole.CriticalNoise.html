17## Scope and representation decisions (common)
18
19* **Model.** "The quadratic whole-space model" / "either stationary model" is, in every statement of
20  this file, the critical (`s = d/2`) quadratic model of S8.1: `d ≥ 2`, `V = a|x|²/2`,
21  `μ = μ_β` any `IsThermalEquilibrium d (d/2) a β ρβ`, `ν = β⁻¹`, particles stationary
22  (`IsCanonicalRealization`).  The *torus* alternatives ("in either stationary model", S lines 6599,
23  6653; "the same ... holds on the torus", S line 6563) are **not stated**: the periodic noise/orbit
24  machinery (periodic `𝒦`-space, features, `A`, `L` on `𝕋^d`) has no Lean counterpart yet.
25* `U_t = e^{t𝒜}` of S8.3 is the unique extension `U` of the semigroup of the projected generator
26  `𝒜 = P_μ ℒ` (`IsWeightedSemigroup`, characterised on `C_c^∞` by the classical backward solution of
27  `-∂_r u = 𝒜 u`, `projGeneratorW`).  Spatial gradients and zero-mass pairings do not see the
28  additive constants that separate it from the classical adjoint solution of `ℒ`
29  (`propagatorW`, `S:R:eq:backward-expression` S lines 6555-6559, 6552).
30* The noise features `Γ_{r,a}(x) ∈ 𝒦_H = H¹([0,H];ℓ²) ⊕ ℓ²` are the existing `gradFeature`
31  (Orbits.lean, S5.2); "adapted coupling" statements use the output pattern of
32  `HRS.hilbert_polar_coupling` (Corollary A.23): `IsAdaptedGaussianCoupling` (a measure preserving
33  enlargement `Ω' → Ω` with enlarged filtration, a cylindrical Brownian motion `B` independent of
34  `ℱ₀`, both the empirical martingale `∫ S dB` and a deterministic-covariance Gaussian martingale
35  `∫ Sb dB`).  The reconstruction `𝒯M` is `reconstructPath` (S5.2).
36* `ℓ²`-valued objects are `OscDual d m` (coordinates indexed by `MultiIndex d`) for the Hermite
37  features, and `SeqL2` (`ℓ²(ℕ)`) for the auxiliary space `ℋ_τ` (the coordinates
38  `e^{-τω_ℓ/2} z(e_ℓ)`; the `ℋ_τ` norm is then the `ℓ²` norm).

128/-- `U` is the extension to `C_M` of the semigroup `U_t = e^{t𝒜}` of the projected generator of the
129(time independent) coefficients `C` with invariant measure `μ` (S line 6440 "The semigroup extends to
130`C_M`"): for `t ≥ 0`, `U_t` is a linear operator on `C_M` into `C_M`, bounded uniformly on bounded
131time intervals, `U_0 = id`, `U_{t+s} = U_tU_s`, and on `C_c^∞` it is the classical backward solution
132of `-∂_r u = 𝒜 u` with terminal datum `φ`, evaluated at `0` (this fixes it uniquely, `C_c` being
133dense in `C_M`). -/
134structure IsWeightedSemigroup (C : WholeCoeff d) (μ : Measure (Euc d)) (M : ℝ)
135    (U : ℝ → (Euc d → ℝ) → Euc d → ℝ) : Prop where
136  maps : ∀ t, 0 ≤ t → ∀ f, MemCM M f → MemCM M (U t f)
137  add : ∀ t, 0 ≤ t → ∀ f g, MemCM M f → MemCM M g → U t (f + g) = U t f + U t g
138  smul : ∀ t, 0 ≤ t → ∀ (c : ℝ) f, MemCM M f → U t (c • f) = c • U t f
139  bdd : ∀ T, 0 ≤ T → ∃ K : ℝ, ∀ t ∈ Set.Icc 0 T, ∀ f, MemCM M f →
140    weightedSupE 0 (-M) (U t f) ≤ ENNReal.ofReal K * weightedSupE 0 (-M) f
141  zero : ∀ f, MemCM M f → U 0 f = f
142  semigroup : ∀ t s, 0 ≤ t → 0 ≤ s → ∀ f, MemCM M f → U (t + s) f = U t (U s f)
143  classical : ∀ t, 0 ≤ t → ∀ φ : Euc d → ℝ, ContDiff ℝ ∞ φ → HasCompactSupport φ →
144    ∃ f, IsAdjointSolutionG (projGeneratorW C μ) t φ f ∧ U t φ = f 0

146/-- The weighted space of kernels `R(x,y)`: `C^j` in both variables with
147`⟨x⟩^{-M}⟨y⟩^{-M} ‖D^iR(x,y)‖ → 0` at infinity of `ℝ^d × ℝ^d`, `i ≤ j` (weight `⟨x⟩^M⟨y⟩^M`,
148derivatives in both variables). -/

150  ContDiff ℝ j (Function.uncurry R) ∧ ∀ i ≤ j,

152      jbracket z.1 ^ (-M) * jbracket z.2 ^ (-M) * ‖iteratedFDeriv ℝ i (Function.uncurry R) z‖)
153      (cocompact (Euc d × Euc d)) (𝓝 0)

155/-- The norm `sup_{i≤j} sup_{x,y} ⟨x⟩^{-M}⟨y⟩^{-M}‖D^iR(x,y)‖` of `MemCMpair`, in `ℝ≥0∞`. -/
