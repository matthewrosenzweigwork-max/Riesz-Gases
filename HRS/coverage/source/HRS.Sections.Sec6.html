15* The periodic gradient diffusion `O:eq:screen-particles` (M L7566-7569) is the gradient dynamics with
16  `V = 0` at inverse temperature `β_N` (`PDE.mfData`, `M = -I`, `invβ = β_N⁻¹`), started from independent
17  uniform (Haar) positions, with global collision-free strong solutions driven by independent Brownian
18  motions independent of the initial positions (`IsVectorBrownian`, `IndepFun`).
19* The mesoscopic test `φ_ℓ(x) = ℓ^{-d/2} ∑_z φ((x - x₀ + z)/ℓ)` (`O:eq:meso-test`) is `mesoTest` (the
20  sum over `ℤ^d` is a finite sum for compactly supported `φ`, `x₀ ∈ ℝ^d`); `Z_{N,ℓ}^t(φ) =
21  √N(μ_N^t - dx)(φ_ℓ)` is `linCoord volume (mesoTest ..) (X t)`.
22* The limiting Gaussian evolution `Z` (`O:eq:meso-limit-cov`) is the centered Gaussian family with
23  covariance `mesoCovMatrix` (`E[Z^t(φ)Z^u(ψ)] = ∫ φ̂ conj(ψ̂) e^{-(t-u)a_b}[S_b + (1-S_b)e^{-2ua_b}] dξ`
24  for `t ≥ u ≥ 0`, symmetric extension otherwise); the Fourier transform is Mathlib's `𝓕`
25  (`φ̂(ξ) = ∫ φ(x) e^{-2πi⟨x,ξ⟩} dx`, the convention of the source, `r = 2π|ξ|`) and the integral is real (its
26  real part is taken).  The stationary Gaussian evolution with spectral density `S_b` is `mesoStatCovMatrix`.
27* `o_N = C₀ N^{-q/d} + 1_{s=0} log N/(2dN)` is `HRS.oN` (the same expression, `q = d - s`).  The source
28  fixes `C₀` "sufficiently large" so that `F_N^γ(X_N, dx) + o_N ≥ 0` (`O:eq:meso-o`); this is part of the
29  conclusion (`∃ C₀ ≥ 0, ...`).  The two further pointwise inputs `O:eq:meso-comm`, `O:eq:meso-coer` are the
30  periodic commutator/coercivity estimates of Propositions 3.32-3.33 and are not restated.
31* Constants: `C` depends on `d, s, p`, the tests and the compact interval `[b₋,b₊] ⊂ (0,∞)` containing
32  `b_N` and `b`; it is chosen before `N`, `β_N`, `ℓ_N`, `b`, the times and the particle system.

44/-- The multiplier `a_b(ξ) = b⁻¹ r² + c_{d,s} r^{2-q}`, `r = 2π|ξ|`, `q = d - s` (`O:eq:meso-multipliers`,
45M L7586-7589). -/
46def mesoRate (d : ℕ) (s b : ℝ) (ξ : Euc d) : ℝ :=
47  b⁻¹ * (2 * Real.pi * ‖ξ‖) ^ 2 + rieszConst d s * (2 * Real.pi * ‖ξ‖) ^ (2 - ((d : ℝ) - s))

49/-- The equal-time spectral density `S_b(ξ) = r^q/(r^q + b c_{d,s})` (`O:eq:meso-multipliers`). -/
50def mesoSpectral (d : ℕ) (s b : ℝ) (ξ : Euc d) : ℝ :=
51  (2 * Real.pi * ‖ξ‖) ^ ((d : ℝ) - s) /
52    ((2 * Real.pi * ‖ξ‖) ^ ((d : ℝ) - s) + b * rieszConst d s)

54/-- The covariance integral `O:eq:meso-limit-cov` (M L7594-7598) for `t ≥ u ≥ 0`:
55`∫_{ℝ^d} φ̂(ξ) conj(ψ̂(ξ)) e^{-(t-u)a_b(ξ)}[S_b(ξ) + (1 - S_b(ξ)) e^{-2u a_b(ξ)}] dξ` (real part). -/
56def mesoCovIntegral (d : ℕ) (s b t u : ℝ) (φ ψ : Euc d → ℝ) : ℝ :=
57  (∫ ξ : Euc d, 𝓕 (fun x => (φ x : ℂ)) ξ * (starRingEnd ℂ) (𝓕 (fun x => (ψ x : ℂ)) ξ) *
58    (((Real.exp (-(t - u) * mesoRate d s b ξ) *
59      (mesoSpectral d s b ξ + (1 - mesoSpectral d s b ξ) *
60        Real.exp (-2 * u * mesoRate d s b ξ)) : ℝ) : ℂ))).re

62/-- The covariance matrix of the centered Gaussian evolution `Z` at times `t_a` and tests `φ_a`:
63`E[Z^{t_a}(φ_a) Z^{t_c}(φ_c)]` is `mesoCovIntegral` with the later time first. -/
64def mesoCovMatrix (d : ℕ) (s b : ℝ) {p : ℕ} (t : Fin p → ℝ) (φ : Fin p → Euc d → ℝ) :
65    Matrix (Fin p) (Fin p) ℝ :=
66  Matrix.of fun a c =>
67    if t c ≤ t a then mesoCovIntegral d s b (t a) (t c) (φ a) (φ c)
68    else mesoCovIntegral d s b (t c) (t a) (φ c) (φ a)

83/-- The periodized mesoscopic test `φ_ℓ(x) = ℓ^{-d/2} ∑_{z∈ℤ^d} φ((x - x₀ + z)/ℓ)` (`O:eq:meso-test`,
84M L7576-7578) as a function on the torus (any representative of `x` gives the same value). -/
85def mesoTest (d : ℕ) (ℓ : ℝ) (x₀ : Euc d) (φ : Euc d → ℝ) : Torus d → ℝ :=

257/-- Proposition 6.1, last paragraph (M L7639-7642): for every `u_N → ∞`, the vector at rescaled times
258`u_N + t_i` (fixed nonnegative lags `t_i`) converges to the stationary Gaussian evolution with spectral
259density `S_b`, in the smooth distance `d_{C³}` (finitely many tests and times).  Regime: `ℓ_N = N^{-κ}`,
260`0 < κ < kappaMax d s` (the regime in which the error terms of `O:eq:screening-bound` vanish),
