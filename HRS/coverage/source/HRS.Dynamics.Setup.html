29## Representation decisions (consequential; see `docs/ISSUES.md` §D1-D4 and `docs/SPEC_AUDIT.md`)
30
31* **The particle SDE has additive noise**, so a strong solution is represented *pathwise*
32  (no Itô integral needed): `X_t = X_0 + ∫_0^t b(X_s) ds + √(2/β_N) W_t` on the covering
33  space `(ℝ^d)^N`, projected to the torus by `Torus.mk`.  `W_i` are `d`-dimensional Brownian
34  motions built from Mathlib's `IsBrownianReal` coordinatewise with joint independence.
35  `β_N = ∞` is represented by `invβ = 0` (`invβ = β_N⁻¹ ∈ [0,∞)`), as in the source
36  ("`1/β := 0` when `β = ∞`", line 1592).  The drift uses `∇g` *off the diagonal*; a solution
37  is required to be collision-free (`B:eq:particle-uniform-separation`).
38* **The force `∇g * ρ`** is the cancellation-convention integral `B:eq:nabla-g-convolution`
39  (`convGradConv`), which is the absolutely convergent integral the source prescribes for all
40  `0 ≤ s < d` (for `s < d-1` and bounded `ρ` it is the plain integral).  A plain Bochner
41  integral would be the junk value `0` for `d-1 ≤ s < d` (`docs/SPEC_AUDIT.md` A8(3)).
42* The mean-field solution is a density `ρ : ℝ → Torus d → ℝ` with the weak formulation
43  `B:eq:mf-weak` holding for every `C²` test, plus `(r,Λ)`-regularity as a hypothesis.
44* The adjoint propagator `U^{r,t}φ` is the classical adjoint solution (Definition 3.5), when
45  it exists; `IsClassicalAdjointSolution` is the defining predicate.  Its existence is
46  Proposition 3.9 (package ADJ-01), *not* assumed in definitions.
47* The linear SPDE solution `Y` (`H:eq:linear-equation`) is characterised through its mild form
48  `Y^t(φ) = Y^0(U^{0,t}φ) + Gaussian stochastic convolution` by the law of the Gaussian part,
49  tested on `C^∞` functions (`Torus.IsSmooth`, not `IsCk ⊤`, which is analyticity):
50  `IsLinearFluctuationSolution` requires that `(Y^t(φ) - Y^0(U^{0,t}φ))_φ` be a centered
51  Gaussian family independent of `Y^0` with covariance `2q ∫_0^t μ^r(∇U^{r,t}φ·∇U^{r,t}ψ) dr`
52  (`B:eq:surrogate-cov`, line 10272, with `2σ_N²/(Nβ_N) = 2q_N`).  This is the characterisation
53  the source itself uses (`B:eq:surrogate-def`, `B:eq:surrogate-field-torus`, A.33); building the
54  solution from a cylindrical Wiener process is package SPDE-01.
55* **Theorem 2.1** is stated with the constant quantified *before* the setup: `∃ C, ∀ S` with
56  `S` ranging over all setups sharing the stated bounds `GeneralBounds` (M L543-544, L605-607).
57  The heat-kernel completion constant `C₀` is constrained by `GeneralSetup.energy_nonneg`
58  (M L546-555, "chosen so that `𝓔_N^t ≥ 0`"), and the energy moments `𝔈_N`, `𝔈_{N,2}` are
59  assumed finite (`EnergyMomentFinite`, `EnergyMoment2Finite`), so that the real-valued
60  `energyMoment`/`energyMoment2` are the source's quantities (M L556-561).

85/-- The particle drift `b_i(X) = N⁻¹ ∑_{j≠i} M ∇g(x_i - x_j) - ∇V(x_i)` (line 171). -/
86def particleDrift (D : DynData d) (X : Config d N) (i : Fin N) : Euc d :=
87  (1 / (N : ℝ)) • ∑ j ∈ Finset.univ.erase i, Torus.matVec D.M (periodicRieszGrad d D.s (X i - X j))
88    - Torus.grad D.V (X i)
89
90/-- The force `∇g * ρ` by the cancellation convention `B:eq:nabla-g-convolution`
91(source lines 10091-10101):
92`∫ ∇g(x-y)(ρ(y)-ρ(x)) 1_{|x-y|≤1/4} dy + ∫ ∇g(x-y) 1_{|x-y|>1/4} ρ(y) dy`.
93The subtracted constant contributes zero by oddness of `∇g` and symmetry of the cube
94(line 10096), so for `0 ≤ s < d-1` and bounded `ρ` this is the plain integral; for
95`d-1 ≤ s < d` and Hölder `ρ` it is the absolutely convergent integral the source prescribes. -/
96def convGradConv (G : Torus d → Euc d) (ρ : Torus d → ℝ) (x : Torus d) : Euc d :=
97  ∫ y, (if ‖x - y‖ ≤ 1 / 4 then (ρ y - ρ x) • G (x - y) else ρ y • G (x - y))
98
99/-- The mean-field drift `M ∇g*ρ - ∇V` (convention convolution). -/
100def meanFieldDrift (D : DynData d) (ρ : Torus d → ℝ) (x : Torus d) : Euc d :=
101  Torus.matVec D.M (convGradConv (periodicRieszGrad d D.s) ρ x) - Torus.grad D.V x

105/-- `W : ℝ≥0 → Ω → (Fin N → Euc d)` is a family of `N` independent `d`-dimensional standard
106Brownian motions: each real coordinate is a Brownian motion and all `N·d` coordinates are
107jointly independent. -/
108def IsVectorBrownian {Ω : Type*} [MeasurableSpace Ω] (P : Measure Ω)
109    (W : ℝ≥0 → Ω → (Fin N → Euc d)) : Prop :=
110  (∀ i j, ProbabilityTheory.IsBrownianReal (fun t ω => W t ω i j) P) ∧
111    ProbabilityTheory.iIndepFun (fun (ij : Fin N × Fin d) ω => fun t : ℝ≥0 => W t ω ij.1 ij.2) P

113/-- Lift of a configuration path to the covering space: a path `Y : ℝ≥0 → Ω → (Fin N → Euc d)`
114projects to the torus configuration `X t ω i = Torus.mk (Y t ω i)`. -/
115def projectPath {Ω : Type*} (Y : ℝ≥0 → Ω → (Fin N → Euc d)) : ℝ≥0 → Ω → Config d N :=
116  fun t ω i => Torus.mk (Y t ω i)

118/-- A collision-free strong solution of the particle system `H:eq:intro-particles` on `[0,T]`
119driven by `W`, with initial configuration `X₀`, in integrated (pathwise) form on the covering
120space:
121`Y_t = Y_0 + ∫_0^t b(mk Y_s) ds + √(2 invβ) W_t`, `X_t = mk Y_t`, with `X_0 = X₀`, the drift
122integrable in time, and no collisions on `[0,T]` a.s. (`B:eq:particle-uniform-separation`). -/
123structure IsStrongSolution {Ω : Type*} [MeasurableSpace Ω] (P : Measure Ω) (D : DynData d)
124    (T : ℝ) (X₀ : Ω → Config d N) (W : ℝ≥0 → Ω → (Fin N → Euc d))
125    (X : ℝ≥0 → Ω → Config d N) : Prop where
126  lift : ∃ Y : ℝ≥0 → Ω → (Fin N → Euc d),
127    (∀ᵐ ω ∂P, ∀ t : ℝ≥0, (t : ℝ) ≤ T →
128      (∀ i, IntegrableOn (fun s : ℝ => particleDrift D (projectPath Y (Real.toNNReal s) ω) i)
129        (Set.Icc 0 (t : ℝ))) ∧
130      ∀ i, Y t ω i = Y 0 ω i + (∫ s in Set.Icc (0 : ℝ) t, particleDrift D (projectPath Y (Real.toNNReal s) ω) i)
131        + Real.sqrt (2 * D.invβ) • (W t ω i - W 0 ω i)) ∧
132    X = projectPath Y
133  init : ∀ᵐ ω ∂P, X 0 ω = X₀ ω
134  cont : ∀ᵐ ω ∂P, ∀ i, Continuous fun t => X t ω i
135  adapted : ∀ t : ℝ≥0, Measurable (X t)
136  no_collision : ∀ᵐ ω ∂P, ∀ t : ℝ≥0, (t : ℝ) ≤ T → X t ω ∉ collisionSet d N

168/-- The symmetrised interaction pairing
169`½ ∬ (∇ψ(x) - ∇ψ(y)) · M ∇g(x - y) dν(x) dν'(y)` off the diagonal
170(`B:eq:mf-weak`, right-hand side; `B:eq:B-symmetrized`). -/
171def interactionPairing (D : DynData d) (ψ : Torus d → ℝ) (ν ν' : Measure (Torus d)) : ℝ :=
172  (1 / 2) * ∫ x, ∫ y, (if x = y then 0 else
173    inner ℝ (Torus.grad ψ x - Torus.grad ψ y) (Torus.matVec D.M (periodicRieszGrad d D.s (x - y)))) ∂ν' ∂ν
174
175/-- A weak solution of the mean-field equation `H:eq:meanfield` on `[0,T]` with viscosity
176`invβ`: a time-dependent probability density `ρ`, continuous in time as a measure, satisfying
177`B:eq:mf-weak` for every `C²` test, in integrated form. -/
178structure IsMeanFieldSolution (D : DynData d) (T : ℝ) (ρ : ℝ → Torus d → ℝ) : Prop where
179  density : ∀ t ∈ Set.Icc 0 T, IsProbDensity (ρ t)
180  weak : ∀ ψ : Torus d → ℝ, Torus.IsCk 2 ψ → ∀ t ∈ Set.Icc 0 T,
181    pair (withDensityReal (ρ t)) ψ - pair (withDensityReal (ρ 0)) ψ =
182      ∫ r in Set.Icc 0 t,
183        (pair (withDensityReal (ρ r)) (fun x => D.invβ * Torus.laplacian ψ x -
184            inner ℝ (Torus.grad D.V x) (Torus.grad ψ x)) +
185          interactionPairing D ψ (withDensityReal (ρ r)) (withDensityReal (ρ r)))

187/-- `(r,Λ)`-regularity on `[0,T]` (`B:eq:mf-regularity`, line 10082):
188`sup_{t ≤ T} ‖ρ^t‖_{C^r} ≤ Λ`. -/
189def IsRegularMF (r : ℕ) (Λ T : ℝ) (ρ : ℝ → Torus d → ℝ) : Prop :=
190  ∀ t ∈ Set.Icc 0 T, Torus.IsCk r (ρ t) ∧ Torus.cbNorm r (ρ t) ≤ Λ

194/-- The backward generator `𝓛_r φ = β⁻¹Δφ + (M∇g*ρ^r - ∇V)·∇φ - ∑_j ∂_j g*(ρ^r (Mᵀ∇φ)_j)`
195(`H:eq:backward-generator`, lines 476-483; `B:eq:adjoint-def`, line 1590), with both
196convolutions by the convention `B:eq:nabla-g-convolution` (`convGradConv`). -/
197def backwardGenerator (D : DynData d) (ρ : Torus d → ℝ) (φ : Torus d → ℝ) (x : Torus d) : ℝ :=
198  D.invβ * Torus.laplacian φ x + inner ℝ (meanFieldDrift D ρ x) (Torus.grad φ x) -
199    ∑ j : Fin d, (convGradConv (periodicRieszGrad d D.s)
200      (fun y => ρ y * (Torus.matVec D.M.transpose (Torus.grad φ y)) j) x) j

202/-- A classical adjoint solution on `[0,t]` with terminal datum `φ` (Definition 3.5, lines
2031633-1635): `f ∈ C([0,t]; C²_b)`, `∂_r f ∈ C([0,t]; C⁰_b)`, `f(t) = φ`,
204`-∂_r f = 𝓛_r f` pointwise.  Time regularity is expressed through the lift. -/
205structure IsClassicalAdjointSolution (D : DynData d) (ρ : ℝ → Torus d → ℝ) (t : ℝ)
206    (φ : Torus d → ℝ) (f : ℝ → Torus d → ℝ) : Prop where
207  c2 : ∀ r ∈ Set.Icc 0 t, Torus.IsCk 2 (f r)
208  cont_c2 : ∀ j ≤ 2, Continuous fun p : Set.Icc (0 : ℝ) t × Euc d =>
209    iteratedFDeriv ℝ j (Torus.lift (f p.1)) p.2
210  terminal : f t = φ
211  time_deriv : ∀ x : Torus d, ∀ r ∈ Set.Ioo 0 t,
212    HasDerivAt (fun r' => f r' x) (-(backwardGenerator D (ρ r) (f r) x)) r
213  cont_time_deriv : Continuous fun p : Set.Icc (0 : ℝ) t × Torus d =>
214    backwardGenerator D (ρ p.1) (f p.1) p.2

217/-- The adjoint propagator `U^{r,t} φ`: the classical adjoint solution at time `r` when it
218exists (`0` otherwise; existence is Proposition 3.9, package ADJ-01). -/
219def propagator (D : DynData d) (ρ : ℝ → Torus d → ℝ) (r t : ℝ) (φ : Torus d → ℝ) : Torus d → ℝ :=

222/-- The noise covariance `2q ∫_0^t μ^r(∇U^{r,t}φ · ∇U^{r,t}ψ) dr` of the linear equation
223(`H:eq:linear-mild`, line 498; `B:eq:surrogate-cov`, line 10272). -/
224def noiseCovariance (D : DynData d) (ρ : ℝ → Torus d → ℝ) (q t : ℝ) (φ ψ : Torus d → ℝ) : ℝ :=
225  2 * q * ∫ r in Set.Icc 0 t, ∫ x, inner ℝ (Torus.grad (propagator D ρ r t φ) x)
226    (Torus.grad (propagator D ρ r t ψ) x) * ρ r x

228/-- A solution `Y` of the linear fluctuation equation `H:eq:linear-equation` with noise level
229`q ≥ 0` and initial value `Y⁰` (an `E_m`-valued random variable), on `[0,T]`, in mild form
230(`H:eq:linear-mild`): for all `C^∞` tests `φ`, `Y^t(φ) - Y^0(U^{0,t}φ)` is a centered Gaussian
231family independent of `Y^0`, jointly over finitely many tests and times, with covariance
232`noiseCovariance` at equal times and the corresponding cross-covariance
233`2q ∫_0^{t∧t'} μ^r(∇U^{r,t}φ·∇U^{r,t'}ψ) dr` at different times; paths are continuous in `E_m`. -/
234structure IsLinearFluctuationSolution {Ω : Type*} [MeasurableSpace Ω] (P : Measure Ω)
235    (D : DynData d) (ρ : ℝ → Torus d → ℝ) (m q T : ℝ) (Y₀ : Ω → NegSobolev d m)
236    (Y : ℝ → Ω → NegSobolev d m) : Prop where
237  init : ∀ᵐ ω ∂P, Y 0 ω = Y₀ ω
238  cont : ∀ᵐ ω ∂P, ContinuousOn (fun t => Y t ω) (Set.Icc 0 T)
239  meas : ∀ t, Measurable (Y t)
240  gaussian_part : ∀ (p : ℕ) (ts : Fin p → ℝ) (φ : Fin p → Torus d → ℝ),
241    (∀ a, ts a ∈ Set.Icc 0 T) → (∀ a, Torus.IsSmooth (φ a)) →
242    let G : Ω → EuclideanSpace ℝ (Fin p) := fun ω => WithLp.toLp 2 fun a =>
243      NegSobolev.eval (Y (ts a) ω) (φ a) - NegSobolev.eval (Y₀ ω) (propagator D ρ 0 (ts a) (φ a))
244    ProbabilityTheory.IndepFun G Y₀ P ∧
245    law P G = ProbabilityTheory.multivariateGaussian 0 (Matrix.of fun a b =>
246      2 * q * ∫ r in Set.Icc 0 (min (ts a) (ts b)), ∫ x,
247        inner ℝ (Torus.grad (propagator D ρ r (ts a) (φ a)) x)
248          (Torus.grad (propagator D ρ r (ts b) (φ b)) x) * ρ r x)

252/-- `σ_N = min{κ_N, √(Nβ_N)}`, with `(σ_N, A_N, q_N) = (κ_N, 1, 0)` when `β_N = ∞`
