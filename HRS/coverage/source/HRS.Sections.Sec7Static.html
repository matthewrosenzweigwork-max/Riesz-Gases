14## Representation decisions
15* `Q_{N,β}(μ)` is `HRS.modulatedGibbs (periodicRiesz d s) N β μ`; at `β = 0` it is `μ^{⊗N}` by definition
16  (`gibbsNormalizer` is `1`), which is the convention `Q_{N,0}(μ) = μ^{⊗N}` of the lemma.
17* The one-body resolvent `R_{β,μ}P_μ φ` is `HRS.responseInverse (periodicRiesz d s) μ β φ` (an a.e.-class,
18  the solution of the response equation `h + β K_μ h = P_μ φ`, `μ(h) = 0`).  Where a point value is needed
19  (Proposition 7.7, `ℓ_x`), the continuous representative `responseRep` is used.
20* `C_b^k(B)` is `HRS.MemCb k` (all derivatives of order `≤ k` bounded) with norm `HRS.cbNorm k`
21  (sum of suprema, TeX L510), and the unit ball `HRS.CbUnitBall`.
22* Gaussian laws on `ℝ^p` are `ProbabilityTheory.multivariateGaussian 0 C` (the covariance matrix is positive
23  semidefinite in all uses, so no junk value occurs); semidefinite covariances are allowed.
