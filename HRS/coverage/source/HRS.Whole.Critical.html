20## Representation decisions
21
22* The stationary quadratic model is `quadraticGradientDyn d s a β` (Headline.lean) started from the
23  canonical law `canonicalGibbs` (`IsCanonicalRealization`: a strong solution on all of `[0,∞)`,
24  independent Brownian motion, `S:eq:stationary-SDE`, S lines 6121-6126; and the invariance of
25  `canonicalGibbs` for the dynamics, `GibbsInvariant`).  Every statement is "for
26  every such realization".  `μ_β = ρ_β dx` is any `IsThermalEquilibrium d s a β ρ_β` (S3.4).
27* The stationary Gaussian field `Z` (`S:eq:Gaussian-covariance`) is a process satisfying
28  `IsLinearGaussianEvolutionW` along the constant reference `ρ_β`, noise level `q = β⁻¹`, initial
29  covariance `susceptibilityCov` (`IsStationaryGaussianField`), for every horizon.
30* The bias `b_{β,μ}` is an element of `B_m` through `OscDual.ofFun` applied to the density of `b`
31  with respect to Lebesgue measure (`bias density × ρ`); the embedding `u ↦ uμ` of
32  `S:eq:field-embedding` (S lines 6081-6087).  The constant path `𝐛(t) = b` is `constPath`.
33* `r_N = (log N)/√N`; "`W_p/r_N → ‖𝐛‖`" (S8.1) is stated through `ℝ≥0∞`-valued `wassersteinE`
34  with explicit two-sided `ofReal` bounds (no real-valued junk when infinite).
35* The adjoint propagator `U_{t-r}` is `propagatorW C r t` (classical adjoint solution of the
36  unprojected generator).  It differs from the semigroup of the projected generator `𝒜 = P_μ ℒ` by an
37  additive constant, which every pairing with a zero-mass field (`μ_N - m_N`, `μ_N - μ`) ignores
38  (S line 6552).  Its existence is part of the conclusion of the statements that use it.

52/-- The data of a stationary realization of the canonical quadratic model (S lines 6121-6126,
53`S:eq:canonical-law`, `S:eq:stationary-SDE`): independent vector Brownian motion `W`, initial law
54`P_{N,β}` (`canonicalGibbs`), and a collision-free strong solution of the gradient dynamics with
55`V = a|x|²/2` and `ν = β⁻¹` on every horizon.
56Statement repair `Supplement repair P7` (docs/ISSUES.md): the solution is moreover filtered (`filtered`: some filtration
57makes `W` Brownian and `X` adapted and progressive; the completed filtration of `(X₀, W)` is one).
58Statement change M1b (2026-10-22): the realization carries the invariance of the canonical Gibbs law for this dynamics at this `N` (`invariant : GibbsInvariant d s a β N`; S L7901 "the canonical law
59is invariant"), which is what makes the stationary claims (`law (X t) = canonicalGibbs`) available; it is a true property of the dynamics (it does not constrain `P, X₀, W, X`), to be removed
60if the invariance is proved. -/
61structure IsCanonicalRealization (d : ℕ) (s a β : ℝ) (N : ℕ) {Ω : Type} [mΩ : MeasurableSpace Ω]
62    (P : Measure Ω) (X₀ : Ω → EucConfig d N) (W : ℝ≥0 → Ω → (Fin N → Euc d))
63    (X : ℝ≥0 → Ω → EucConfig d N) : Prop where
64  brownian : IsVectorBrownian P W
65  indep : IndepFun X₀ (fun ζ t => W t ζ) P
66  init : law P X₀ = canonicalGibbs (rieszKernel d s) (confinement a) N β
67  solution : ∀ T' : ℝ, IsWholeStrongSolution P (quadraticGradientDyn d s a β) T' X₀ W X
68  filtered : ∃ (ℱ : Filtration ℝ mΩ) (W' : ℝ≥0 → Ω → (Fin N × Fin d) → ℝ),
69    IsWholeFilteredSolution P ℱ W' W X
70  invariant : GibbsInvariant d s a β N

72/-- The stationary Gaussian linearized field `Z_β` (`S:eq:Gaussian-covariance`): a linear
73Gaussian evolution on every horizon along the constant reference `ρ_β`, noise level `q = β⁻¹`, with
74initial covariance the susceptibility form `⟨P_μφ, R_{β,μ}P_μψ⟩_{L²(μ)}`. -/
75def IsStationaryGaussianField (d : ℕ) (s a β : ℝ) (m : ℝ) (ρβ : Euc d → ℝ) {Ω' : Type}
76    [MeasurableSpace Ω'] (P' : Measure Ω') (Z : ℝ → Ω' → OscDual d m) : Prop :=
77  ∀ T' : ℝ, IsLinearGaussianEvolutionW P' ((quadraticGradientDyn d s a β).coeff (fun _ => ρβ))
78    m β⁻¹ T' (susceptibilityCov (rieszKernel d s) (withDensityReal ρβ) β) Z

83  (quadraticGradientDyn d ((d : ℝ) / 2) a β).coeff (fun _ => ρβ)

89/-- The bias `b_{β,μ} = 2A_{d,s}β^p (R_{β,μ}P_μρ) μ` as an element of `B_m`
90(`S:eq:bias-measure`, `S:eq:field-embedding`): the embedding of the density `biasDensity · ρ`
91with respect to Lebesgue measure. -/
92def biasField (m : ℝ) (d : ℕ) (s β : ℝ) (ρ : Euc d → ℝ) : OscDual d m :=
93  OscDual.ofFun m fun x => biasDensity d s β ρ x * ρ x

95/-- The density of the critical bias `b_{β,μ} = β²|S^{d-1}|/d (R_{β,μ}P_μρ) μ` relative to `μ`
96(`S:eq:critical-whole-bias`, S lines 6220-6222), `s = d/2`. -/
97def critBiasDensity (d : ℕ) (β : ℝ) (ρ : Euc d → ℝ) (x : Euc d) : ℝ :=
98  β ^ 2 * sphereArea d / d *
99    responseInverse (rieszKernel d ((d : ℝ) / 2)) (withDensityReal ρ) β ρ x

102def critBiasField (m : ℝ) (d : ℕ) (β : ℝ) (ρ : Euc d → ℝ) : OscDual d m :=
103  OscDual.ofFun m fun x => critBiasDensity d β ρ x * ρ x
