7`adjoint_decay_proof : type_of% @HRS.Whole.adjoint_decay` (the frozen statement, `HRS/Whole/Adjoint.lean`).
8
9Route (S4_PLAN section 2.2, "verify, do not construct").  Let `f_u := propagatorW C u t φ` (`C = D.coeff ρ`),
10the classical adjoint solution given by `UlAdjointInput` (`MemCb (k+1) f_u`, `cbNorm (k+1) f_u ≤ K ‖φ‖_ul`).
11Its equation reads `∂_u f + νΔf + b_u·∇f = S_u` with `b_u = M(∇g*ρ_u) - Qx - c` and
12`S_u = Div g*(ρ_u Mᵀ ∇f_u)` (`ad_generator_split_hyp`, `ad_drift_eq`).  The Ito/chain-rule verification
13(`ad_verification_sg` for `ν > 0`, `ad3_verification_zero` for `ν = 0`) gives
14`f_r x = lcSg r t φ x - ∫_r^t lcSg r u (S_u) x du` with the LC engine `lcSg`.  The engine `lc_engine` bounds the first
15term by `C decayNormE k (s+1) φ`, and `ad3_int_engine` bounds the Duhamel integral (all derivatives, via
16differentiation under the product integral `du ⊗ dP`) by `C ‖S‖` where `‖S_u‖_{k,s+1} ≤ C K ‖φ‖_ul` is
17`ad_source_bound` (`far_derivatives_proof` (b) with `f = f_u`).  The data on `[0,T]` are clamped
18(`lcHyp_clamp`, `lcDecay_clamp`) to satisfy the engine hypotheses for all times.
19
20The conclusion constant is `max (max Ce (Ci * Cs * max K 0)) 1`, with `Ce` the engine constant, `Ci` the constant of
21`ad3_int_engine`, `Cs` the constant of `ad_source_bound`; all depend only on `d, s, k, L, Λ, K, T, ν*, M, Q, c`
22(and not on `ν, ρ, r, t, φ`).  Statement adjustments relative to the frozen file: none (`hk2` is not needed
23by the proof).  Standing facts used: `0 ≤ s ≤ d - 2`, `L > d + k + s + 4`, `0 ≤ ν ≤ ν*` (the case in which
24the hypothesis `AdjointDecayHyp` can hold at all; otherwise the statement is vacuous and `C = 0`).

39/-- The representation formula for every viscosity `ν ≥ 0` (`ad_verification_sg` if `ν > 0`,
40`ad3_verification_zero` if `ν = 0`). -/
41theorem ad3_representation {Ω : Type u} [mΩ : MeasurableSpace Ω] (P : Measure Ω)
42    [IsProbabilityMeasure P] (ℱ : Filtration ℝ mΩ) (W : ℝ≥0 → Ω → Fin d → ℝ)
43    (hW : IsBrownianFiltration P ℱ W) (Q : Matrix (Fin d) (Fin d) ℝ) (k : ℕ) (Λc ΛB : ℝ)
44    (c : ℝ → Euc d) (B : ℝ → Euc d → Euc d) (H : LcHyp Q k Λc ΛB c B)
45    (C : WholeCoeff d) (hν : 0 ≤ C.ν) {t : ℝ}
46    (hdrift : ∀ u ∈ Icc 0 t, ∀ y, C.drift u y = B u y - lcQ Q y - c u)
47    {φ : Euc d → ℝ} {f : ℝ → Euc d → ℝ} (hf : IsClassicalAdjointW C t φ f)
48    (S : ℝ → Euc d → ℝ)
49    (hS : ∀ u ∈ Icc 0 t, ∀ y, generatorW C u (f u) y = C.ν * Laplacian.laplacian (f u) y +
50      inner ℝ (C.drift u y) (gradient (f u) y) - S u y)
51    {r : ℝ} (hr : 0 ≤ r) (hrt : r ≤ t) (x : Euc d) :
52    IntervalIntegrable (fun u => lcSg P W (fun _ => C.ν) Q c B r u (S u) x) volume r t ∧
53    f r x = lcSg P W (fun _ => C.ν) Q c B r t φ x -
54      ∫ u in r..t, lcSg P W (fun _ => C.ν) Q c B r u (S u) x := by
55  rcases hν.eq_or_lt with h | h
56  · exact ad3_verification_zero P ℱ W hW Q k Λc ΛB c B H C h.symm hdrift hf S hS hr hrt x
57  · exact ad_verification_sg P ℱ W hW Q k Λc ΛB c B H C h hdrift hf S hS hr hrt x

59/-- A single derivative term of `decayNormE` is bounded by the norm. -/
60theorem ad3_term_le {k : ℕ} {b : ℝ} {g : Euc d → ℝ} {j : ℕ} (hj : j ≤ k) (I : Fin j → Fin d)
61    (x : Euc d) :
62    ENNReal.ofReal (jbracket x ^ (b + (j : ℝ)) * |partialDeriv I g x|) ≤ decayNormE k b g := by
63  unfold decayNormE derivSupE
64  refine le_trans ?_ (le_iSup _ (⟨j, Nat.lt_succ_of_le hj⟩ : Fin (k + 1)))
65  refine le_trans ?_ (le_iSup _ I)
66  exact le_iSup (fun x => ENNReal.ofReal (jbracket x ^ (b + (j : ℝ)) * |partialDeriv I g x|)) x
