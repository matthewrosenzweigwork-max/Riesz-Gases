26## Representation decisions (to be checked by the orchestrator)
27
28* **Collision-free vs contact flows.**  The Cépa-Lépingle flow is `IsCepaLepingleFlow` (a
29  contact-allowing strong solution of the integrated equations, cyclically ordered, with Lebesgue-null
30  contact occupation); "the boundary finite-variation process vanishes" is encoded by the absence of any
31  reflection term in the integrated equation.  Its uniqueness is stated within that class.
32* **Brownian drivers of the canonical flow.**  The TeX (L11664-11665) assigns to a label the Brownian
33  motion of its *initial cyclic rank*.  `cepa_log_flow` is stated for an *arbitrary* vector Brownian
34  motion `W` independent of `X₀`; the TeX convention is the special case `W̃_i = W_{rank(i)}`, which is
35  again a vector Brownian motion independent of `X₀` (the rank is `X₀`-measurable), so the two are
36  equivalent.
37* **Gibbs entropies** are `EReal`-valued, `𝓗_G(P) = H(P | Z_G⁻¹ G dX) - log Z_G` exactly as in
38  `B:eq:gibbs-entropy-measure-convention`, with `Z_G` a `lintegral` (so no Bochner junk) and `H = relEntropy`
39  (Mathlib `klDiv`, `⊤` unless `P ≪ Q` with integrable log-likelihood ratio).
40* **Fisher information** `𝓘_G(P)` is the lower-semicontinuous extension given by the variational formula
41  `B:eq:selected-fisher-variational` (L12205-12209), as a supremum in `ℝ≥0∞` over smooth vector fields
42  with compact support in `Ω_N = 𝔇_N^c`; `∇ log G = -β ∇U` on `Ω_N`, computed by differentiating the
43  lift of the potential `U`.  The supremum includes `ζ = 0`, so no real `iSup` junk arises.
44* The time integral `∫ 𝓘_G(P_N^r) dr` is a `lintegral` (measurability of `r ↦ 𝓘_G(P_N^r)` is provable:
45  supremum of narrowly continuous functionals of a narrowly continuous curve).

105/-- The forward Kolmogorov operator `f ↦ β⁻¹ Δ_X f - div_X(b f)` of the particle system, applied at
106`(r, X)`, computed through the lift to the covering space `(ℝ^d)^N` at `Y = rep ∘ X`;
107`b = particleDrift` (the drift of `H:eq:intro-particles`) and `e_k = configBasis d N k`.
108The classical forward equation of B.4 is `∂_r f = fkeForward D f r X` (the adjoint of the generator
109whose weak form is `B:eq:selected-law-fke`, L11680-11686). -/
110def fkeForward (D : DynData d) (f : ℝ → Config d N → ℝ) (r : ℝ) (X : Config d N) : ℝ :=
111  let Y : Fin N → Euc d := fun i => Torus.rep (X i)
112  D.invβ * ∑ k : Fin N × Fin d,
113      fderiv ℝ (fderiv ℝ (configLift f r)) Y (configBasis d N k) (configBasis d N k)

115      fderiv ℝ (fun Z : Fin N → Euc d =>
116        (particleDrift D (fun i => Torus.mk (Z i)) k.1) k.2 * configLift f r Z) Y
117        (configBasis d N k)

201/-! ### The Gibbs weight, entropy and Fisher information (`B:eq:particle-total-potential` ff.) -/
202
203/-- The `N`-particle potential `U_{N,V}(X_N) = (1/2N) ∑_{i≠j} g(x_i - x_j) + ∑_i V(x_i)` on `𝕋^d`
204(`B:eq:particle-total-potential`, TeX M L12006), `g = periodicRiesz d s`. -/
205def totalPotential (D : DynData d) (X : Config d N) : ℝ :=
206  (1 / (2 * (N : ℝ))) * ∑ i, ∑ j ∈ Finset.univ.erase i, periodicRiesz d D.s (X i - X j)
207    + ∑ i, D.V (X i)
208
209open Classical in
210/-- The unnormalised Gibbs weight `G_{N,β_N,V} = exp(-β_N U_{N,V}) 1_{𝔇_N^c}`
211(`B:eq:particle-total-potential`, TeX M L12008), `β_N = invβ⁻¹` (used only with `0 < invβ`). -/
212def gibbsWeight (D : DynData d) (X : Config d N) : ℝ :=
213  if X ∈ collisionSet d N then 0 else Real.exp (-(D.invβ⁻¹) * totalPotential D X)
214
215/-- The partition function `Z_G = ∫ G dX` as a `lintegral` (the TeX convention, L12016, requires
216`0 < Z_G < ∞`, which holds in the situations of B.14 and B.15; the `lintegral` avoids Bochner junk). -/
217def gibbsPartition (D : DynData d) (N : ℕ) : ℝ≥0∞ :=
218  ∫⁻ X : Config d N, ENNReal.ofReal (gibbsWeight D X)
219
220/-- The normalised Gibbs reference measure `Z_G⁻¹ G dX` (TeX M L12018). -/
221def gibbsRef (D : DynData d) (N : ℕ) : Measure (Config d N) :=
222  (gibbsPartition D N)⁻¹ •
223    (volume : Measure (Config d N)).withDensity fun X => ENNReal.ofReal (gibbsWeight D X)
224
225/-- The relative entropy `𝓗_G(P) = H(P | Z_G⁻¹ G dX) - log Z_G` of a probability measure
226(`B:eq:gibbs-entropy-measure-convention`, TeX M L12018), `EReal`-valued: `+∞` when `P` is not
227absolutely continuous with respect to the normalised Gibbs measure. -/
228def gibbsEntropy (D : DynData d) (P : Measure (Config d N)) : EReal :=
229  ((relEntropy P (gibbsRef D N) : ℝ≥0∞) : EReal) - ((Real.log (gibbsPartition D N).toReal : ℝ) : EReal)
230
231/-- Test fields of the variational formula `B:eq:selected-fisher-variational` (TeX M L12205-12209):
232`ζ ∈ C_c^∞(Ω_N; ℝ^{dN})`, i.e. smooth (through the periodic lift) with compact support in the
233collision-free configuration space `Ω_N = 𝔇_N^c`. -/
234structure IsFisherTestField (ζ : Config d N → (Fin N → Euc d)) : Prop where
235  smooth : ContDiff ℝ ((⊤ : ℕ∞) : WithTop ℕ∞)
236    (fun Y : Fin N → Euc d => ζ (fun i => Torus.mk (Y i)))
237  support : ∃ K : Set (Config d N), IsCompact K ∧ Disjoint K (collisionSet d N) ∧
238    ∀ X, X ∉ K → ζ X = 0
239
240/-- The divergence `Div ζ = ∑_{i,j} ∂_{x_{ij}} ζ_{ij}` of a vector field on `𝕋^{dN}`, through the lift
241at `Y = rep ∘ X`. -/
242def configDiv (ζ : Config d N → (Fin N → Euc d)) (X : Config d N) : ℝ :=
243  let Y : Fin N → Euc d := fun i => Torus.rep (X i)
244  ∑ k : Fin N × Fin d,
245    fderiv ℝ (fun Z : Fin N → Euc d => (ζ (fun i => Torus.mk (Z i)) k.1) k.2) Y
246      (configBasis d N k)
247
248/-- The relative Fisher information `𝓘_G(P)` as the lower-semicontinuous extension given by the
249variational formula `B:eq:selected-fisher-variational` (TeX M L12205-12209):
250`sup_ζ ∫ (-2 Div ζ - 2 ζ·∇log G - |ζ|²) dP`, over `ζ ∈ C_c^∞(Ω_N; ℝ^{dN})`, where on `Ω_N`
251`∇ log G = -β_N ∇U_{N,V}`, so that `-2 ζ·∇ log G = 2 β_N D U[ζ]` (`β_N = invβ⁻¹`; `DU[ζ]` computed by
252differentiating the lift of `totalPotential`).  `ζ = 0` is admissible, so the supremum is `≥ 0`;
253it is `+∞` for measures without a (Sobolev) density.  Used with `0 < invβ`. -/
254def fisherInfo (D : DynData d) (N : ℕ) (P : Measure (Config d N)) : ℝ≥0∞ :=
255  ⨆ (ζ : Config d N → (Fin N → Euc d)) (_ : IsFisherTestField ζ),
256    ENNReal.ofReal (∫ X : Config d N,
257      (-2 * configDiv ζ X
258        + 2 * D.invβ⁻¹ * fderiv ℝ (fun Z : Fin N → Euc d => totalPotential D (fun i => Torus.mk (Z i)))
259            (fun i => Torus.rep (X i)) (ζ X)
260        - ∑ i, ‖ζ X i‖ ^ 2) ∂P)
261
262/-- The weak forward equation of Proposition B.3 (`B:eq:selected-law-fke`, TeX M L11680-11686) for a
263family of laws `μ`, in the form of `selected_law_fke`: for every `Φ ∈ C_c^{1,2}([0,T) × Ω_N)`,
264`-∫ Φ(0,·) dμ_0 = ∫_0^T ∫ (fkeGenerator + fkeInteraction) dμ_r dr`. -/
265def SolvesSelectedFKE (D : DynData d) (T : ℝ) (μ : ℝ → Measure (Config d N)) : Prop :=
266  ∀ Φ : ℝ → Config d N → ℝ, IsFKETest T Φ →
267    - ∫ x, Φ 0 x ∂(μ 0)
268      = ∫ r in (0 : ℝ)..T, ∫ x, (fkeGenerator D T Φ r x + fkeInteraction D Φ r x) ∂(μ r)

270/-! ### Propositions B.14 and B.15: entropy admissibility -/
271
272/-- Proposition B.14 (`M:B:prop:cepa-entropy-confined`, TeX M L12020-12032): entropy admissibility on the
273circle.  `𝔻 = 𝕋`, `X_N` the canonical Cépa-Lépingle flow of B.2 with `a = 1` (`M = -I`), `0 < invβ`,
274`V ∈ C²` (`‖V''‖_∞ < ∞` is automatic on the compact torus), initial law with a density `f_N^0` of finite
275Gibbs entropy `𝓗_G(f_N^0) < ∞` (`B:eq:cepa-initial-entropy`).  Then for every deterministic `t ∈ [0,T]`
276the law `P_N^t` has a density; the family solves the forward equation of B.3 (distributionally, away
277from `𝔇_N`); and `𝓗_G(P_N^t) + β_N⁻¹ ∫_0^t 𝓘_G(P_N^r) dr ≤ 𝓗_G(P_N^0)` (`B:eq:cepa-entropy-inequality`),
278in `EReal`.  No labelled forward equation across the collision boundary is asserted.
279Technical hypotheses: `2 ≤ N`, `0 < T` (as in B.3), `hF` (Brownian filtration, as in B.3, needed to
280make the forward-equation clause the one of B.3).  The standing initial-data hypotheses of Assumption
