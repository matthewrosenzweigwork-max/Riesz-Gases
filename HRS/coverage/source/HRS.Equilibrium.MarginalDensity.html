8

101. `Q_{N,β}(μ) = cavityLaw g μ N λ β` (`MarginalCavity.modulatedGibbs_eq_cavity`); exact cavity equation
11   (`MarginalCavity.firstMarginal_cavity_eq`): `dπ/dμ = exp(β g*μ + log Φ_x - c)`, `Φ_x = E_{P₀} e^{-λ∑g(x-y_j)}`.
122. `log Φ_x = D_N(x) - λ n ∫ g(x-y) dν`, `0 ≤ D_N ≤ C δ_N` (`MarginalPole.insDefect_le`).
133. With `p = dπ/dμ`, `q = dν/dμ`, `z = p - 1`: `log(1+z) + β g*(z μ) = D_N + e_N - c_N`,
14   `e_N = β g*((p-q) μ) + λ g*(q μ)`, and `‖p - q‖_{L¹(μ)} ≤ C √(δ_N/N)` (`MarginalPole.cavity_tv`);
15   the convolution estimate (`MarginalKernel.conv_L2`) gives `‖e_N‖_{L²(μ)} ≤ C δ_N`.

195. Absorption: test the cavity equation against `z`; `∬ z g z ≥ 0` (Fourier positivity,
20   `MarginalKernel.Kt_nonneg`) and `z log(1+z) ≥ z²/(1+‖z‖_∞)` give `‖z‖₂ ≤ (1+ε)‖D_N + e_N‖₂`.
