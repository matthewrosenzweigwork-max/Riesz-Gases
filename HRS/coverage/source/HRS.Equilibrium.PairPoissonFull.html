4# Proposition 4.13 with all clauses (packet PX-FID, specification 2026-10-15)
5
6`HRS.pair_poisson` (proved as `pair_poisson_proof`) encodes the pointwise off-diagonal equation, the
7bounds `Q:eq:psi-size`, the `𝒥ψ` clauses and the `a_f` bounds of Proposition 4.13 (`M:Q:prop:poisson`,
8TeX L4729-4735).  The source also asserts (L4734):
9* the equation `-(𝒜_x + 𝒜_y)ψ_f = H_f` **in distributions** (not only off the diagonal), and
10* the bounds `Q:eq:psi-size` with constant `C|f|_K` for **tangential derivatives up to order four**.
11
12Both are stated here in `pair_poisson_full`, which contains `pair_poisson` verbatim as its first conjuncts.
13
14Representation decisions (orchestrator; ISSUES §I):
15* Tangential derivative: `∂^tan_e ψ(x,y) = d/dt ψ(x + te, y + te)|_{t=0}`, i.e. differentiation in `x`
16  at fixed relative coordinate `x - y` (the source's usage, L4815, L4837), through the lift `lift2`;
17  iterated along a list of directions, with constant `C|f|_K ∏‖e_i‖` (multilinearity).
18* Distributions: the weak form against smooth test kernels `φ` on `𝕋^d × 𝕋^d`, with respect to `μ ⊗ μ`
19  (`μ = ρ dx`, `ρ` smooth positive, so this is equivalent to testing against Lebesgue).  The local part `B`
20  is `μ`-symmetric for a thermal density (`∇ρ = -βρ(∇V + F_μ)`), so `∫(B_xψ)φ dμ = -β⁻¹∫∇_xψ·∇_xφ dμ`
21  and the distributional `μ`-mean of `B_xψ(·,y)` is `0`; the nonlocal and projected part is
22  `𝒥ψ = (P_xJ_x + P_yJ_y)ψ` (`Jpair`), an integrable function.  Together with the pointwise equation
23  this excludes a diagonal flux.  Integrability conjuncts rule out junk Bochner values.
24* `gradFst`, `Jpair`, `Hsource` take junk values only on the diagonal, a `μ ⊗ μ`-null set; the tangential
25  clause bounds the full gradient and Hessian (`PsiSize`) of each `∂^tan` derivative, off the diagonal only.
26* Independent statement review (2026-10-15): ACCEPT.

42/-- Tangential derivative `∂^tan_e ψ(x,y) = D(lift2 ψ)(x̃,ỹ)·(e,e)`, `x̃, ỹ` the representatives. -/
43def tanDeriv (e : Euc d) (ψ : Torus d → Torus d → ℝ) (x y : Torus d) : ℝ :=
44  fderiv ℝ (lift2 ψ) (Torus.rep x, Torus.rep y) (e, e)
45
46/-- Iterated tangential derivative `∂^tan_{e₁} ⋯ ∂^tan_{e_k} ψ`. -/
47def tanIter : List (Euc d) → (Torus d → Torus d → ℝ) → Torus d → Torus d → ℝ
48  | [], ψ => ψ
49  | e :: es, ψ => tanDeriv e (tanIter es ψ)

51/-- The equation `-(𝒜_x + 𝒜_y)ψ = H_f` in distributions on `𝕋^d × 𝕋^d` (weak form w.r.t. `μ ⊗ μ`). -/
52structure IsWeakPairPoisson (d : ℕ) (s : ℝ) (β : ℝ) (ρ : Torus d → ℝ) (f : Torus d → ℝ)
53    (ψ : Torus d → Torus d → ℝ) : Prop where
54  int_grad : Integrable (fun p : Torus d × Torus d => ‖gradFst ψ p.1 p.2‖ + ‖gradSnd ψ p.1 p.2‖)
55    ((withDensityReal ρ).prod (withDensityReal ρ))
56  int_J : Integrable (fun p : Torus d × Torus d => Jpair d s ρ ψ p.1 p.2)
57    ((withDensityReal ρ).prod (withDensityReal ρ))
58  int_H : Integrable (fun p : Torus d × Torus d => Hsource d s ρ f p.1 p.2)
59    ((withDensityReal ρ).prod (withDensityReal ρ))
60  weak : ∀ φ : Torus d → Torus d → ℝ, ContDiff ℝ ∞ (lift2 φ) →
61    ∫ p : Torus d × Torus d, (β⁻¹ * (inner ℝ (gradFst ψ p.1 p.2) (gradFst φ p.1 p.2) +
62        inner ℝ (gradSnd ψ p.1 p.2) (gradSnd φ p.1 p.2)) - Jpair d s ρ ψ p.1 p.2 * φ p.1 p.2)
63      ∂((withDensityReal ρ).prod (withDensityReal ρ)) =
64    ∫ p : Torus d × Torus d, Hsource d s ρ f p.1 p.2 * φ p.1 p.2
65      ∂((withDensityReal ρ).prod (withDensityReal ρ))
